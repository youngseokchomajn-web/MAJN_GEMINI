## ⚠️ 발주 시 확인 필요

### 1. U3(MP3426DL) LCSC 번호 — 확정됨
- BOM에 **C133224** 사용 = 정답. SSOT(`mcp_design_flow.json` v1.9.2)에 이미 정정 기록: **"C2909511은 잘못된 번호(404, JLCPCB Process 500에러 원인)로 확인 → C133224(MP3426DL-LF-Z, QFN-14-EP, 재고766)로 정정, 2026-07-03"**. 지난 발주에서도 C133224로 JLC 승인·조립됨.
- **⚠️ 단, EasyEDA 스키매틱에는 아직 옛 `C2909511`(오류번호)이 남아있음** → 네이티브 BOM export가 이걸 뽑아서, 리스크 없는 C133224로 수동 교체함. **다음 편집 시 EDA 스키매틱 U3도 C133224로 동기화 권장**(안 하면 재-export 때 또 C2909511이 나옴).
- → 발주 시 U3 매칭에서 C133224 확인.

### 2. 재고부족 대체 (지난 발주 때 실적 — 재고 실시간 변동, 발주 시 재확인)
- **R2 (16kΩ, C22818)**: 부품이 "SMT业务专用" 표기 + 지난번 재고부족 → **C4210**(0603WAF1602T5E, ±1%)로 대체했었음.
