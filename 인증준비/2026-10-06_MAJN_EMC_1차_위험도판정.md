# MAJN EMC 1차 설계 위험도 판정

- 기준일: 2026-10-06
- 기준 설계: PCB1 / rev-B 계열
- 선행 문서: 인증준비/2026-10-06_MAJN_EMC_설계검토_계측장비_시험전략.md
- 목적: 실제 회로도/BOM/PCB 검증 결과를 바탕으로 EMC Pre-test 전에 우선 검토할 위험경로를 정리한다.

## 1. 현재 결론

현재 단계에서는 EMC 계측장비를 추가 구매하지 않는다.

진행 순서:
1. 멀티미터 기반 기본 브링업
2. 회로도/PCB/BOM 기반 EMC 설계검토
3. PCB 수정·검증
4. 시제품 제작
5. EMC Pre-test
6. 실패 시 원인별 대책 수정

오실로스코프와 Spectrum Analyzer는 현재 선구매 필요성이 낮다. 실제 Pre-test에서 특정 노이즈 원인이 확인된 뒤 필요 장비를 추가 조달하거나 대여하는 방향을 우선한다.

## 2. 현재 설계의 주요 EMC 블록

- U1: ESP32-WROOM-32E, 2.4 GHz RF
- U2: AP2112K-3.3, 3.3 V LDO
- U3: MP3426DL, Boost converter
- L1: 4.7 uH boost inductor
- U4: TAS5805M, Class-D amplifier
- U5: LSM6DSOX, IMU
- D1: SMAJ5.0A
- D3: SS34
- FB1~FB4: UPZ2012E221-3R0TF
- USB-C 외부 전원/통신 인터페이스
- J1/J2: actuator 출력 커넥터

## 3. 1차 위험도 판정

| 경로 | 판정 | 판단 근거 | 다음 검토 |
|---|---|---|---|
| MP3426 BOOST_SW 및 입력/출력 switching loop | HIGH | 고속 스위칭 전류와 높은 di/dt가 발생하는 핵심 전원 블록 | SW node 면적, L1/U3/Cin/Cout 배치, GND return 확인 |
| TAS5805M Class-D BTL 출력 | HIGH | 고주파 PWM 출력이 외부 부하로 연결됨 | 출력 pair, return path, 커넥터 주변 GND 확인 |
| Actuator 외부 케이블 | HIGH | PCB 밖으로 나가는 긴 도선이 방사/공통모드 경로가 될 가능성 | 케이블 길이·배치·출력 필터/공통모드 경로 확인 |
| 4 actuator 동시 구동 | HIGH | 출력단 전류 및 switching activity가 최대가 되는 worst-case 조건 | 최대 출력/최대 동시구동 조건에서 Pre-test |
| Boost + AMP 동시 동작 | HIGH | 전원 switching noise와 Class-D noise가 동시에 발생 | 동시 활성화 시 전원/그라운드 coupling 확인 |
| ESP32 RF와 power/audio 영역 간 coupling | MEDIUM~HIGH | 2.4 GHz RF와 noisy power/audio block이 동일 PCB에 존재 | 안테나 keep-out, GND, noisy trace와 거리 확인 |
| USB-C VBUS/GND 및 외부 케이블 | MEDIUM | 외부 케이블이 보드의 noise를 외부로 전달할 수 있음 | 커넥터 진입부 보호/필터/return path 확인 |
| 3.3 V LDO 및 MCU/IMU 전원 | LOW~MEDIUM | 자체 noise source는 상대적으로 작지만 전원/ground coupling 영향 가능 | local decoupling과 return path 확인 |
| LSM6DSOX IMU | LOW | 주요 EMC source라기보다 주변 switching noise에 민감한 수신 블록 | 전원 안정성 및 GND 분리/return 확인 |

## 4. 현재 설계에서 긍정적으로 확인된 사항

- 4-layer PCB 구조.
- GND plane이 4개 layer에 구성된 설계 이력이 있음.
- 회로도→PCB 핀 단위 검증에서 204/204 일치.
- 38개 net 집합 일치.
- GND member 47/47 일치.
- ERC Fatal 0 / Error 0 / Warning 2였던 검증 이력 존재.
- USB-C, ESP32, Boost, Class-D 등 주요 블록의 회로 구조가 문서화되어 있음.
- 실제 #0005 보드에서 VBUS_5V, VCC_3V3 등의 기본 전원 레일은 멀티미터로 정상 확인됨.

위 결과는 EMC 적합성을 의미하지 않는다. 회로/전기적 연결이 정상이라는 것과 방사·전도 EMI 적합성은 별도 문제다.

## 5. 가장 중요한 worst-case 조건

### Worst-case A — 최대 actuator 동시 구동
- actuator 4개 모두 연결
- TAS5805M 출력 활성
- 실제 사용 가능한 최대 진동/출력 조건
- 케이블은 실제 제품 사용 길이와 동일

### Worst-case B — Boost + Class-D 동시 동작
- MP3426 boost 활성
- PVDD가 정상 목표 전압에 도달한 상태
- TAS5805M가 실제 부하를 구동
- ESP32 제어/통신도 정상 동작

### Worst-case C — RF + Power/Audio 동시 동작
- ESP32의 2.4 GHz 통신 활성
- Boost 활성
- Class-D 출력 활성

### Worst-case D — 외부 USB 연결 상태
- USB-C 전원 입력
- ESP32/USB-UART 또는 실제 사용 인터페이스 조건
- 외부 케이블 연결 상태

실제 시험에서는 모든 조합을 무작정 시험하는 것이 아니라 제품의 정상 사용 모드 중 방사/전도 noise가 최대가 될 가능성이 높은 상태를 우선 선정한다.

## 6. PCB 실제 레이아웃 검토 항목

다음 단계에서는 회로도만으로 판단을 끝내지 않고 PCB copper를 직접 확인한다.

### U3 MP3426
- SW node 면적
- U3-L1-Cin-Cout 고전류 loop 면적
- SW trace가 다른 신호 아래/옆으로 지나가는지
- power GND return이 짧고 직접적인지
- switching node가 USB/ESP32/IMU 영역으로 뻗지 않는지

### U4 TAS5805M
- BTL 출력 pair의 길이/대칭
- 출력 trace와 GND plane 관계
- J1/J2까지의 경로
- 외부 actuator cable 시작점
- 출력 switching node가 MCU/RF 영역과 coupling하는지

### FB1~FB4
- 실제 삽입 위치
- 어느 noise path를 차단하도록 배치됐는지
- ferrite 전후의 GND/return path
- connector와 noisy block 사이에 의도대로 위치하는지

### USB-C
- VBUS/GND 진입 경로
- TVS/보호부품 위치
- 외부 cable → board return path
- USB connector 주변 GND stitching
- plated slot 주변 routing 및 plane continuity

### ESP32
- 안테나 keep-out
- antenna 주변 GND 조건
- Boost/Class-D와의 물리적 거리
- RF trace 주변 다른 switching trace 존재 여부

## 7. 현재 장비 전략

현재 보유:
- 멀티미터

현재 선구매하지 않을 장비:
- Oscilloscope
- Spectrum Analyzer
- EMI receiver

이유:
- 아직 실제 PCB routing에서 위험경로를 먼저 줄일 수 있음.
- 설계 단계에서는 회로도/PCB/GND/current-loop 분석이 선행되어야 함.
- Spectrum Analyzer만 구매해도 공인 EMC 시험을 대체할 수 없음.
- 실제 실패 주파수와 원인을 확인한 후 필요한 계측장비를 선정하는 편이 비용 효율적임.

## 8. 인증/Pre-test 전략

목표는 자체 측정으로 인증을 대체하는 것이 아니라 다음 단계의 실패 가능성을 줄이는 것이다.

설계 검토 → 시제품 → EMC Pre-test → 실패 원인 확인 → PCB/필터/케이블 대책 → 재시험 → 공식 인증

Pre-test 결과에서 특정 방사 또는 전도 문제가 확인되면 그 주파수와 동작 조건을 기준으로 원인 후보를 좁힌다.

## 9. 현재 판단의 한계

현재 HIGH/MEDIUM/LOW는 회로도 + BOM + 기존 PCB 검증 기록을 이용한 1차 위험도다.

다음 항목은 실제 PCB layout/copper를 직접 열어 보기 전까지 최종 판정하지 않는다.
- MP3426 switching loop 면적
- TAS5805M 출력 loop 및 pair 배치
- ferrite 실제 위치와 연결 방식
- USB-C 주변 plane/return
- ESP32 antenna keep-out
- noisy block과 sensitive block 사이 거리
- actuator connector에서 cable로 빠지는 common-mode 경로

따라서 이번 문서의 HIGH 판정은 인증 실패 확정이 아니라 우선 검사 순위를 HIGH로 올린다는 의미다.
