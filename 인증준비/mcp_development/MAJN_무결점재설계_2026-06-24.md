# 마중 스마트 배시넷 — 회로도→PCB 무결점 재설계 계획
*작성 2026-06-24. 이 문서가 권위 계획서. 기존 [MAJN_PCB6_POWER_FIRST_PLAN.md], [MAJN_PCB_FROMSCRATCH_빌드플랜.md]의 교훈을 통합 + 인증 제약 + SSOT 모순 수정까지 반영한 단일 문서.*

대상: 마중 진동 모듈(어린이용 **액세서리**, 국내 KC). 4층 PCB, EasyEDA Pro. 단일 USB-C 5V 입력으로 10W/8Ω 진동 트랜스듀서 구동.

## 1. 목표 & 제약
- 전원: USB-C 5V → MP3426 부스트 **12.12V**(앰프 PVDD) + SGM2036 LDO 3.3V(ESP32/IMU).
- 트랜스듀서: 8Ω, 10W RMS급 베이스셰이커, 실사용 앰프 ~8W.
- 4층, 1oz(전원 빡빡하면 외층 2oz 발주 옵션).
- 인증(액세서리/국내): 어린이제품 **공통안전기준**(공급자적합성확인 추정) + 전파 **적합등록**(WROOM 모듈인증 활용) + 동봉 어댑터 KC. EMC·발열·케이블 안전 설계 반영. **의학적 효능 표현 배제**.
- 성공 기준: **재시작 직후 네이티브 DRC = 0** (필요조건). ⚠️**DRC는 배선 무결성만 본다 — 정격·극성·전력수지·EMI는 DRC가 못 잡으므로 §1.5/A1 설계검증을 별도 통과해야 충분조건.** + 넷 무결성·회로도↔PCB 일치·부팅 스트래핑·전원폭 충족.

## 1.5 ★실패 분류 & 3대 예방원칙 (이번 재설계의 메타 원칙)
과거 회고: 실수는 두 종류였고, 둘 다 **순서/분담을 처음에 안 정해서** 늦게·반복 발견됐다.

| 클래스 | 정체 | 왜 늦게/반복 발견됐나 | 차단 |
|---|---|---|---|
| **A. 설계 결함** | 정격·극성·전력수지·EMI = **DRC가 못 잡는 영역** | "DRC 통과"를 기준으로 한 겹씩 봐서. 요구사항에서 출발해 전 도메인을 한 번에 안 봐서 | **Phase A1**(선제 일괄검증) |
| **B. 도구 장애** | EasyEDA/브릿지 beta·멀티윈도우 한계 | 브릿지/UI 역할 분담을 처음에 안 정해서 시행착오 | **§7**(역할 분담·동기화) |

### 3대 예방원칙 (전 단계 관통)
1. **요구사항 → 데이터시트 요구 → 마진 충족을, 전 도메인 한 번에.** DRC 뒤를 쫓지 말 것. → Phase A1.
2. **극성·정격은 핀이름·실측값으로. 가정 금지.** pad번호 ≠ 극성(D3 역방향 교훈), 노트텍스트 ≠ 부품데이터(R1/D3 모순). `getState_PinName`·데이터시트로 확정. → A0/A1.
3. **도구 역할 분담 + 수정 즉시 동기화.** 브릿지=읽기/이동, UI=무거운 작업. 수정 직후 회로도↔PCB↔design_flow.json 동기(드리프트 금지). → §7.

## 2. ★Phase A0 — BOM/넷리스트 SSOT 동결 (회로도 그리기 전 필수)

| # | 항목 | 모순/위험 | 확정값 (근거) |
|---|---|---|---|

| **M3** | **D2 (USBLC6-2SC6)** | USB-C가 **충전전용**(D± 없음)인데 D2는 GND만 연결된 **고아부품** | **D2 삭제** → 부품 45→44. BOM·면적·고아넷 정리 |
| M4 | U3 MP3426DL | LCSC가 문서마다 다름(C2909511 vs C162810), 핀번호 미확정 | MP3426DL QFN-14 **데이터시트로 핀번호 확정** + LCSC 실물 일치 확인 |
| M5 | 캡 전압 디레이팅 | 12.12V 레일에 10V캡 금지(과거 사고) | PVDD계 캡 **≥25V**(C96446 ✓). 전 캡 정격 ≥ 레일×1.5 재확인 |

## 2.5 ★Phase A1 — 전 도메인 설계검증 (DRC가 못 잡는 결함 A를 한 번에)
회로도 그리기 전, **모든 부품·모든 넷**을 4개 도메인에서 *요구사항→데이터시트→마진* 순으로 **1회 일괄 검증**하여 표로 남긴다. (DRC 뒤를 쫓아 한 겹씩 보지 않는다 = 원칙①)

**① 정격** (전 부품) — 실제 스트레스 vs 데이터시트 절대최대. 마진 규칙:
- 캡 전압 ≥ 레일×1.5 · 다이오드 전류·전압 ≥ 피크 · 인덕터 Isat ≥ 피크 · 저항 전력 ≥ 2× · IC 동작전압/온도 범위.
- 확정 적용: C8/C9 25V(12.12V레일✓) · C6/C7 25V✓ · D3 SS34 3A(피크3.2A✓) · L1 Isat5A(피크3.34A✓).

**② 극성** (전 극성부품 D/전해C/U) — 1번핀·A/K·+/− 를 **데이터시트 핀이름 + 실측(`getState_PinName`)** 으로 확정. **pad번호로 가정 금지**(D3 역방향 교훈). 회로도 심볼핀 ↔ 넷 ↔ PCB패드 **4중 대조**.

**③ 전력수지** (입력→출력 전 레일 정산) — USB-C 입력 한계(5V·3A=15W) ≥ 총소비. 부스트 효율·LDO 드롭·앰프 효율 반영(§3 전류표가 근거). 레일별 평균/피크 전류 합산이 한계 내인지.

**④ EMI/리턴패스** — 부스트 입력루프(VBUS-L1-SW-D3) <2mm · BOOST_SW 노드 면적 최소 · GND 평면 연속 · 디커플 캡 전원핀 근접 · 앰프 출력 루프 짧게.

**게이트**: 4개 도메인 표가 전부 마진 충족(가정 0건)일 때만 회로도(Phase B) 착수.

## 3. 전원 트레이스 폭 — 전류 요구량 계산 (IPC-2221, 외층 1oz, ΔT 10℃)
공식: A[mil²]=(I/(0.048·ΔT⁰·⁴⁴))^(1/0.725), 폭=A/1.378(1oz).

| 넷 | 전류 | IPC 최소폭 | **채택폭** | 방법 |
|---|---|---|---|---|
| **VBUS_5V** | 2.6A | ~44mil | **1.2mm(47mil) 또는 pour** | 입력 동맥. pour 권장(전류+미세핀 진입+클리어런스 동시해결) |
| **PVDD_12V** | 1.5A pk | ~21mil | **1.0mm(39mil) 또는 pour** | 앰프 공급. pour 권장 |
| **BOOST_SW** | 2A avg/4A 펄스 | ~31mil | **0.8mm(31mil)** | **짧게(<10mm)·입력루프<2mm**, EMI 핵심 |
| **AMP_OUT_A/B±** | 1.4A pk | ~19mil | **0.5mm(20mil)** | 트랜스듀서 출력 |
| **VCC_3V3** | 0.5A | ~5mil | **0.25mm(10mil)** | 여유 |
| 신호 | <0.1A | — | **0.15mm(6mil)** | 일반 |
| **GND** | — | — | **Inner1 솔리드 평면** | 트랙 금지 |

→ 채택폭은 모두 IPC 최소 이상(발열·IR 여유 포함). IR강하: VBUS 2.6A/1.2mm/20mm ≈ 21mV(무시 가능). **빡빡하면 외층 2oz 발주로 폭 절반.**

|---|---|---|---|

## 6. 실행 단계 (회로도 먼저)

### Phase B — 회로도 (ERC 클린이 게이트)
1. §2 동결 BOM/넷리스트로 `run_draw_schematic.py` 실행 → 44부품·37넷 회로도 생성.
2. **ERC 0** 확인. 검증: 핀맵 일치, 모든 디커플/풀업/EP→GND/부스트 보상망(R9/R10/R11/C21/C22) 존재, 부팅 스트래핑(EN·IO0 풀업, IO12/IO2 플로팅, IO15/IO5 내부풀업) 정상.
3. **게이트**: ERC=0 + 회로도↔SSOT 일치 확인 후에만 PCB 진행.

### Phase C — 새 PCB 보드 + Import
- 새 빈 PCB 1개 생성(과거 회로도복제 꼼수 불필요 — 처음부터 1보드=1회로도=1PCB).
- 4층 설정 → 회로도 Import(UI). **Apply Changes 클릭**(API importChanges는 true만 반환).
- 보드 외형 80×60mm, 안테나 keepout(핀 제외).

### Phase D — 설계 규칙 먼저 (배선 전)
- 넷클래스 폭(§3), 클리어런스 6mil, 홀↔동박 6.9mil, **same-net via-in-pad 허용**(EP비아).
- 도구: **Net Class Manager**(Design 메뉴). ※Design Rule 대화상자 금지(S3).

### Phase E — GND 평면
- Inner1 전면 솔리드 GND pour. Top/Bottom 로컬 채움. **GND 트랙 0**.

### Phase F — 전원-우선 배치 (★배선효율 결정)
존(좌→우 전원흐름): `USB-C·CC·D1·U2` → `U3+L1+D3+보상망(루프<2mm)` → `U4 앰프` → `J1/J2`. 상단 `U1 ESP32`(안테나 엣지) + `U5 IMU`(U1 옆, SPI 5넷 단축) + `UART_HDR`.
- **U1↔U4 인접·핀 마주봄**(I2C/I2S/PDN 6넷 최단), **U1↔U5 인접**(SPI 5넷).
- 부스트 루프 ≤2mm, BOOST_SW 최단. 디커플 캡 전원핀 <100mil(패드 0겹침).
- 미세핀(U4 0.65mm/U3 QFN/ESP castellated) **팬아웃 비아 사전계획**.
- **게이트**: 배치도 그림으로 사용자 합의 후 배선.

### Phase G — 전원-우선 배선
- **VBUS·PVDD = 구리 pour**(장애물 자동회피+전류+미세핀 진입). BOOST_SW 0.8mm 짧게. AMP_OUT 0.5mm.
- 완료 후 **전원 트레이스 LOCK**.
- pour API 주의: **priority=undefined**(숫자주면 실패), 'R' 폴리곤 좌표(위-왼쪽 기준), create가 에러던져도 생성될 수 있음(getAll 확인), 충전=**Shift+B**(UI).

### Phase H — 신호 배선
- 전원 LOCK 상태에서 신호 오토라우트(Top/Bottom/Inner2, Inner1=GND평면 제외). Top수평/Bottom수직 직교.

### Phase I — GND 비아 + 재충전
- U1(1/15/38/EP)·U4 EP·U3 EP GND비아 + 스티칭 격자(~250mil). **Inner1 활성→Shift+B 재충전**.

### Phase J — 검증 (재시작 직후 1회)
1. 네이티브 DRC=0(클리어런스·미연결·동일풋). 2. 넷 무결성(전 넷 pad≥2, 의도된 NC만). 3. 회로도↔PCB("No changes"). 4. 부팅 스트래핑. 5. **전원폭 달성 확인**. 6. EP 접지. 7. 층/외형.

### Phase K — 제작 준비
- Gerber(사용자 허락 후 출력) + BOM + CPL + DFM 체크. 인증 설계반영(§8).

## 7. EasyEDA 도구 역할 분담 & 동기화 (실패 B 예방 — 처음에 못박기)
### 역할 분담 (시행착오의 근원 = 분담 미결정)
| 작업 | 도구 | 이유 |
|---|---|---|
| 부품 이동(modify)·좌표/핀 읽기·넷 조회 | **브릿지** | 정밀·안정 |
| 배선삭제·오토라우트·동박 pour/재충전·DRC·규칙·외곽선·keepout | **UI** | 브릿지로 하면 degrade/실패/멈춤 |
| 회로도 부품삭제·와이어 | **브릿지(회로도 탭 활성시)** 또는 UI | openDocument 전환=크래시 → UI 탭클릭으로 전환 |

### ★수정 즉시 동기화 (아티팩트 드리프트 금지 — 원칙③)
- 셋 중 하나(회로도/PCB/design_flow.json)를 고치면 **즉시 나머지 동기**: 회로도 수정 → Import Changes(Apply) → PCB 반영 → design_flow.json 갱신. 미루면 "회로도만 최신·PCB는 옛날" 드리프트로 재작업.

### 기타 수칙 (degrade·바인딩 회피)
- 실행규약: 코드는 `async (eda)=>{...}` 본문, **최상위 return**이 결과(IIFE는 null).
- region/keepout **modify 실패→UI 속성패널**(숫자 X/Y/W/H 작동).
- 멀티윈도우 stale 시: `Stop-Process easyeda-pro -Force` → 재기동 → **PCB 트리 더블클릭(캔버스 렌더)** → WINID 갱신.
- 저장 직후 리로드 금지(클라우드 동기 대기). **단계마다 JSON 백업**. 2회 실패하는 방법은 즉시 우회(P1).

## 8. 인증 설계 반영 (액세서리/국내)
- **케이블**: 트랜스듀서 200cm → 영아 목졸림 위해. 길이단축/고정/strain-relief 재검토(시스템 설계).
- **발열**: U4 ~8W → EP 써멀비아 다수 + 구리 면적 + 표면온도 상한. 매트리스/피부 접촉부 고려.
- **EMC**: 부스트 입력루프<2mm, 입출력 필터, GND 평면, 동봉 어댑터 KC품. (전원-우선 레이아웃이 EMC에 유리)
- **펌웨어 안전**: 30분 자동정지·진폭상한·과변위차단 유지(PL 방어). **안전 파라미터 하드코딩/잠금 + 서명(Secure) OTA**(인증 무효화·임의펌웨어 방지).
- **마케팅**: "뇌파/숙면/치료" 등 의학적 효능 표현 배제(의료기기·표시광고 리스크).

## 9. 순서 요약 (게이트)
**A0(SSOT 동결) → A1(전 도메인 설계검증: 정격·극성·전력수지·EMI) → B(회로도·ERC0) → C(새보드+Import) → D(규칙) → E(GND평면) → F(배치·그림합의) → G(전원 pour·LOCK) → H(신호 오토라우트) → I(GND비아·재충전) → J(권위 DRC0·검증) → K(제작).**
A0/A1에서 **DRC가 못 잡는 결함(정격·극성·전력수지·EMI)까지 선제 차단**하고 F(배치)를 합의하면, 배선(G/H)은 짧고 깨끗해져 **오류가 발생하지 않는 상태로 수렴**한다.
