# 마중 배시넷 — 전원 배선 계획 (Phase C 전원-우선)
*2026-06-24, design_flow v1.8.0 기준. 각 부품 전류 → 트레이스 폭·토폴로지·층·비아·발열. IPC-2221(외층 1oz, ΔT 10℃) 기준.*

---

## 0. ★시스템 전류 천장 (가장 먼저 박을 사실)
- 입력 = **USB-C 5V / 3A = 15W** (CC 5.1k 풀다운 = 기본 3A 상한). 모든 하류 전류는 이 천장에 묶인다.
- 트랜스듀서는 **스테레오 2채널(J1=A, J2=B)**. 둘 다 풀파워(8W×2=16W)면 입력 ~24W로 **USB-C 초과** → 실사용 진동출력은 낮게(펌웨어 진폭제한) 운용. **단, 트레이스는 "입력 천장 3A"로 사이징**(소스 한계까지 안전).
- 즉 전원선은 *순간 최대치(부품 정격)* 가 아니라 *공급 가능한 최대(USB-C 3A에서 파생되는 각 구간 전류)* 로 설계.

## 1. 전류 흐름도
```
USB-C VBUS (≤3A) ─┬─[VBUS trunk]─ C5 → L1 → U3.SW → D3 → PVDD_12V (부스트)
                  └─[VBUS LDO지선]─ U2(AP2112K) → VCC_3V3 (3.3V 로직)

PVDD_12V ─ C6/C7 → U4.PVDD×4 ─ Class-D ─ AMP_OUT → 페라이트비드 → J1/J2
VCC_3V3 ─ C1(22µF) → U1(ESP32) + U5(IMU) + U4.DVDD + 풀업
GND = Inner1 솔리드 평면 (모든 리턴)
```

## 2. ★넷별 전류 → 폭 표 (핵심)
| 넷 | 구간 | 설계전류 | IPC최소폭(1oz/10℃) | **채택폭** | 방법·층 |
|---|---|---|---|---|---|
| **VBUS_5V** | USB-C → 분기노드 (트렁크) | **3.0A** | 54mil | **Top 구리 pour** (또는 ≥50mil) | 입력 동맥, 최대전류 |
| VBUS_5V | 분기 → L1/U3 (부스트 지선) | 2.4A | 44mil | pour 연속 | |
| VBUS_5V | 분기 → U2 (LDO 지선) | 0.6A | 6mil | **15mil**(0.4mm) | |
| **BOOST_SW** | L1 ↔ U3.SW(4/5/6) ↔ D3.A | 2.5A RMS / 3.3A pk(펄스) | 31mil | **0.8mm(30mil) + 최단** | ★핫루프, Top 한 층 고정 |
| **PVDD_12V** | D3.K → C6/C7 → U4.PVDD×4 | 1.5A pk (듀얼 ~2A) | 21~31mil | **Top/Bottom 구리 pour** | 앰프 공급 |
| **AMP_OUT_A±/B±** | U4.OUT → 페라이트비드 | 1.4A pk/leg | 19mil | **0.5mm(20mil)** ×4레그 | 출력 |
| SPK_A±/B± | 비드 → J1/J2 | 1.4A pk | 19mil | 0.5mm | 비드 후단 |
| **VCC_3V3** | U2.VOUT → C1 → U1/U5/DVDD | 0.6A pk | 6mil | **15mil**(0.4mm) | ESP32 벌크경로 저임피던스 |
| BOOST_VDD | U3.VDD → C21 | <50mA | — | 6~10mil(default) | 바이어스 |
| AVDD·VR_DIG·BST·COMP·FB·FSET·SS | 신호급 | <10mA | — | 6~10mil | 일반 |
| **GND** | 전 리턴 | — | — | **Inner1 솔리드 평면** | 트랙 금지 |

> 1oz가 빡빡하면 **외층 2oz 발주** → 동일 전류에 폭 절반(VBUS 3A를 ~27mil로). 10W급 전원제품엔 정당화 가능.

## 3. IR 강하 점검 (기능 보장 = 부품이 정상전압 받게)
얇으면 전압강하 → 부품 저전압 = 오동작. 채택폭에서:
- **VBUS 3A / 1.2mm pour / 20mm** ≈ R 8mΩ → 24mV 강하 (5V→4.98V). 부스트는 3.2V까지, LDO는 4.7V↑ 필요 → **여유 충분**.
- **PVDD 1.5A / 1.0mm pour / 25mm** ≈ R 10mΩ → 15mV (12.12→12.10V). 앰프 무영향.
- **AMP_OUT 1.4A / 0.5mm / 30mm** ≈ R 40mΩ → 56mV + 비드 DCR(~수십mΩ) → 8Ω 부하엔 미미(<1% 손실).
→ 채택폭 전부 IR·발열 여유 확보. **얇아서 기능 못 하는 구간 없음.**

## 4. ★임계 루프 & 배치 (EMI·동작 직결)
- **부스트 핫루프 최소화**: `C5(입력캡) → L1 → U3.SW → D3 → C6/C7(출력캡) → PGND → C5`. 이 di/dt 루프 면적을 **<2mm급**으로. C5는 U3.VIN/PGND에 밀착, C6/C7은 D3.K~U4.PVDD 사이 밀착. **BOOST_SW는 한 층(Top)에서 짧게, 비아로 층 넘기지 말 것.**
- **PVDD 디커플**: C8/C9(10µF) U4.PVDD핀 <2mm, 0.1µF급 HF캡 검토(고di/dt).
- **VCC_3V3 벌크**: C1(22µF) U1.3V3핀 근접 + C2(100nF) 더 근접 → WiFi 트랜지언트 흡수.
- **출력 EMI**: 부트스트랩캡(C12~15)은 U4쪽, 페라이트비드+캡(C24~27)은 커넥터쪽. SPK 트레이스 차동쌍 가깝게.

## 5. 4층 pour 전략
| 층 | 역할 |
|---|---|
| **Top** | 부품 + **VBUS·PVDD 구리 pour**(전류+미세핀 자동진입) + 짧은 신호 + BOOST_SW |
| **Inner1** | **GND 솔리드 평면**(전 리턴, 스티칭) |
| **Inner2** | 전원 보조 분배(PVDD/VBUS 확장) + 횡단 신호 |
| **Bottom** | 2차 신호 + 전원 병렬 + 로컬 GND 채움 |
- pour 주의(확정): `priority=undefined`, 'R' 폴리곤 좌표(위-왼쪽), 충전=Shift+B(UI).

## 6. 비아 전류용량 (층 전환 시)
0.3mm 드릴 비아 ≈ **~1A/개** 안전(보수). 고전류 넷은 병렬:
| 넷 | 전류 | 비아 수(층전환) |
|---|---|---|
| VBUS_5V | 3A | **3~4개 병렬** |
| PVDD_12V | 1.5A | **2개** |
| AMP_OUT(leg) | 1.4A | **2개** |
| BOOST_SW | — | **층전환 금지**(한 층 유지) |
| VCC_3V3 | 0.6A | 1개 |

## 7. 발열 (EP 써멀비아 = 동작·수명·안전)
| 부품 | 손실 | 처리 |
|---|---|---|
| **U4 TAS5805M** | ~2W(16W/88%) | **EP(29)→GND 써멀비아 어레이 9~16개** + Top/Bottom 구리, 표면온도 관리 |
| **U3 MP3426** | ~0.5W(스위칭) | EP→PGND 비아 4~9개 |
| **D3 SS34** | ~1.1W(2A×0.55V) | K(PVDD) 패드 구리면적↑ + 비아 |
| U2 AP2112K | ~0.5W(1.7V×0.3A) | SOT-23-5 + 구리 여유 |
→ 어린이제품 표면온도 기준상 발열집중 회피 = U4 EP 접지·방열 견고히.

## 8. 실행 순서 (전원 FIRST·LOCK)
1. 배치: §4 임계루프(부스트 핫루프, 디커플) 우선 + 전원 동맥 공간 확보.
2. **GND 평면**(Inner1) 먼저.
3. **VBUS·PVDD = 구리 pour**(Top), BOOST_SW 0.8mm 짧게(Top), AMP_OUT 0.5mm.
4. **전원 트레이스 LOCK.**
5. 비아(§6) + EP 써멀비아(§7) + 스티칭.
6. 신호 오토라우트(전원 LOCK 상태).
7. 재충전(Shift+B) → 재시작 → **권위 DRC 0.**

## 9. 한눈 요약
- **VBUS 3A(천장)·BOOST_SW 0.8mm단/PVDD pour·AMP_OUT 0.5mm·VCC 0.4mm·GND 평면.**
- 폭은 *부품 정격*이 아니라 *USB-C 3A에서 파생되는 구간 전류*로. IR·발열 전부 여유.
- 핫루프 최소 + EP 써멀비아 + 고전류 병렬비아가 "기능·EMI·발열" 3박자 핵심.
