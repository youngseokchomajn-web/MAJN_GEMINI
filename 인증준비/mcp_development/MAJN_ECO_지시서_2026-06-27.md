# 마중 PCB — 정밀 ECO 지시서 (2026-06-27)

남은 결함(E-01·E-03·E-04·E-05·E-02마무리)을 **한 번의 EasyEDA 편집 세션**으로 처리하는 좌표단위 지시서.
좌표 mil (1mm=39.37mil). 화면 Y축 반전(보드 y=0=화면 하단). 대상 = `new start`/PCB1.

## 역할 분담 (확실성 위해)
- **사람(UI)**: 부품 이동·재라우트·풋프린트 교체 — 정밀·안정.
- **Claude(브릿지)**: 각 단계 후 전수 기하검증(클리어런스·디커플링거리·SW루프·단락/개방·EP). 수정 끝나면 호출.
- **공통 규칙**: `eda_routing_rules.md` §4 — 각 부품 이동 후 "다른넷 패드 겹침 0·클리어런스 ≥6mil" 확인.

## 실행 순서 (의존성 순)
풋프린트(ECO-1) → 부품이동(ECO-2~4) → EP(ECO-5) → Claude 전수검증 → 시제품.

## ECO-1. U1 풋프린트 -32UE 교체 (E-02 마무리)
- **현재**: U1 = ESP32-WROOM-32E (C701342), PCB안테나.
- **작업**: EasyEDA에서 U1 부품을 **ESP32-WROOM-32UE-N8 (C701345)** 로 교체.
  - 패드 38핀 동일 → **기존 배선 유지**(재라우트 불필요).
  - 모듈 6.3mm 짧아짐(25.5→19.2mm) → 좌측 안테나 영역 사라짐.
- **확인**: ①u.FL 커넥터(좌측 변)와 좌측 부품(C3 827,472 / U2 994,472) **3D 클리어런스** ②바디 outline·실크 갱신 ③외장 안테나 케이블 출구 경로.
- **합격기준**: U1 38핀 넷 변화 0, u.FL 간섭 0.
- **BOM/기구**: 외장 안테나 + 피그테일 추가, **KC 인증서 호환 안테나(게인 한도)**.

## ECO-2. 디커플링 캡 → IC 전원핀 밀착 (E-05) ★PI 핵심
> 규칙: HF 디커플링 캡은 IC 전원핀 **≤2mm(≈80mil)**. 각 캡을 핀 옆 ~60mil로 이동 후 그 넷 재라우트.

| 캡 | 값 | 현재 | → 목표 전원핀 | 현재거리 | 우선 |
|---|---|---|---|---|---|
| **C21** | 1µF | (440,1874) | **U3.7 VDD** (649,1750) 옆 ~60mil | **6.19mm** | ★★★ MP3426 바이패스 |
| **C8** | 10µF | (1309,1575) | **U4.15/16 PVDD** (1741,1805) 옆 | **12.45mm** | ★★★ Class-D PVDD |
| **C11** | 100nF | (2205,512) | **U5.8 VDD** (2332,583) 옆 | 3.72mm | ★★ IMU |
| C9 | 10µF | (1299,1811) | U4.27 PVDD (1434,1805) | 3.44mm | ★ (이미 근접, 미세) |
| C1 | 22µF | (1457,276) | U1.2 (1270,354) | 5.14mm | △ 벌크라 후순위 |

- **작업**: C21·C8·C11 이동(각 핀 옆 ~60mil, 같은넷 핀쌍 사이 권장) → 해당 넷(BOOST_VDD·PVDD_12V·VCC_3V3) 짧게 재라우트.
- **합격기준**: C21→U3.7 ≤2mm, C8→U4 PVDD ≤2mm, C11→U5.8 ≤2mm. 이동 후 겹침 0.
- **주의**: TAS5805M PVDD는 1µF+10µF 권장 — C8(10µF 벌크)을 핀 옆, 가능하면 소형 0.1µF 추가 검토.

## ECO-3. 부스트 스위칭 노드 축소 (E-04) — L1 6mm 한계 내 최대
- **현재**: U3(709,1693) · L1(709,1969, 6×6mm) · D3(945,1693). SW노드 대각 8.48mm.
- **목표 배치** (클러스터 ~10mm 박스):
  - **L1을 U3 바로 위로**: L1 → ~(709,1890) (U3 상단과 ~20mil 간격, 인덕터 6mm라 이게 한계). SW핀↔L1.2 6.4→~4.7mm.
  - **D3을 U3-SW와 출력 사이로**: D3 → ~(860,1790) 근방 (anode D3.2를 U3 SW쪽, cathode를 PVDD pour쪽). SMA 크기(5×3mm) 고려해 배치.
  - 입력캡 C5(VBUS) → U3 VIN(pin3) 옆으로.
- **작업**: L1·D3(·C5) 이동 → BOOST_SW·VBUS·PVDD 재라우트 + BOOST_SW pour 재생성.
- **합격기준**: SW노드 대각 ≤6mm 목표(인덕터 한계상 안되면 최소화), SW pour 면적↓. 단락 0.

## ECO-4. R13 재배치 + 재라우트 (E-03)
- **현재**: R13(1973,859) — U1.22(1929,834)와 **13.65mil 겹침**, 우측 R6(2017,866)에 막혀 nudge 불가(기하 모순).
- **목표 빈자리**: **~(2053,989)** (가까운 패드 145mil, 충분) 또는 그 부근 위쪽 빈공간. R13을 U1·R6 사이에서 빼내 위로.
- **재라우트**: R13.1(AMP_PDN) → U1.23(1929,884), R13.2(VCC_3V3) → 인근 VCC. 둘 다 짧게.
- **합격기준**: R13 어떤 핀도 다른부품 패드와 겹침 0, U1.22 침범 해소, 클리어런스 ≥6mil.

## ECO-5. U4·U3 EP 써멀비아 GND화 (E-01) — 풋프린트 정공법
- **현재**: U4 EP 밑 비아 12개 net='' (GND평면 void로 단절), U3 EP 비아 0개. EP 조밀(피치~47mil)해 PCB에 비아 추가 불가.
- **작업(택1)**:
  - **(권장) 풋프린트 편집**: U4·U3 풋프린트의 EP 써멀비아 **net 속성을 GND로** 지정(또는 EP패드 thermal-via 옵션 활성). → re-pour시 평면 본딩.
  - (대안) EP패드 좌우 여백(x[1465,1504]·[1646,1685])은 net='' 비아와 0mil이라 추가 불가 → 풋프린트 외 방법 없음.
- **참고**: 이미 추가한 **GND 스티칭 비아 5개**(U4 옆 1452,1693 등)가 측면 GND-평면 본딩을 보강함(E-06). EP 직접본딩은 위 풋프린트 작업 필요.
- **합격기준**: re-pour 후 EP가 GND평면에 본딩(클리어런스 위반 13건 소멸), net='' 비아 0.

## ECO-6. L1 인덕터 / 펌웨어 (E-07) — PCB 아님
- 깨끗한 6×6 드롭인 없음(SRP6540=Isat6.5A·7×7·품절). **권장: 펌웨어 SPL 하드리밋(E-09)으로 피크전류를 L1 Isat 5.5A 이하로 제한 + 발열 실측.** 하드웨어로 풀려면 7×7 8A 인덕터(풋프린트 변경).

## 수정 완료 후 — Claude 전수 재검증 (2중 진실원)
1. **권위 DRC** (EasyEDA UI): Clearance/Connection/Width = 0 목표.
2. **Claude 기하 감사** (브릿지): 단락 0 · 개방 0(직접 갭분석) · 디커플링 ≤2mm · SW루프 · EP본딩 · 부품겹침 0.
3. 통과 후 **시제품 1장 발주 → BLE거리·발열·전원 벤치 실측.**

> 각 ECO 단계 끝낼 때마다 Claude에게 알리면 그 부분만 즉시 검증해 드립니다.
