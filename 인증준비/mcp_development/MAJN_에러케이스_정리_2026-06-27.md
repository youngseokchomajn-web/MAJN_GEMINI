# 마중 PCB — 에러 케이스 전수 정리 (2026-06-27)

EasyEDA 브릿지(API Gateway)로 **16개 도메인을 기하 실측 검증**. 좌표 단위 mil (1mm=39.37mil). 보드 80×60mm 4층. PCB1 / `new start` 프로젝트.
검증 방식: 트레이스·패드·비아·pour 전체 기하를 받아 Python으로 단락·개방·클리어런스·극성·전류경로·열·기구 직접 계산 (DRC 의존 안 함).

## 🔴 진짜 결함 — 확실 (high confidence)

### E-01. IC EP 써멀비아가 GND 평면과 단절 ★
- **U4(TAS5805M, 10W Class-D) EP 밑 비아 12개가 전부 net=''** → GND pour(Inner1)가 그 주위를 void 처리 → 평면과 본딩 안 됨.
- **U3(MP3426 부스트) EP 밑 비아 0개** → 써멀비아 자체 없음.
- 증거: net='' 비아 12개 좌표가 U4 EP(1575,1693) 24~85mil에 군집 / U3 EP(709,1693)·U4 EP 200mil내 GND 비아 0개 / GND평면↔net='' 비아 클리어런스 위반 13건이 void 증명.
- **영향**: 앰프 주 방열경로 손상 + EP 접지 고임피던스. 부스트 IC 방열 부재.
- **원인**: 풋프린트가 리로드마다 EP비아를 net=''로 재생성 → 이전 GND화 수정 복귀.
- **수정방향**: EP 영역에 **별도 GND 비아**(풋프린트 비종속) 추가 + re-pour, 또는 풋프린트 EP비아 넷 고정.

### E-02. 안테나가 보드 내부를 향함 → ✅ -32UE 외장안테나로 해결(2026-06-27)
- **정정된 진단(핀 매핑으로 확정)**: 안테나는 U1 **왼쪽 변(-x, 패드없는 유일변)**. 그 존(x[925,1220])에 **U2(LDO)·C4·GND평면·트레이스 35개(VBUS6/GND13/VCC12/ESP_EN4)** 가 있음. 모듈 25.5mm라 U2가 안테나 밑/근접장. (처음 "y0엣지 8트레이스"는 엉뚱한 존 오판—정정.) 원 SSOT 의도는 상단엣지 y≈47mm였으나 autoroute 재배치가 y=18mm 내부로 옮김(P-24).
- **영향**: PCB안테나가 LDO·전원부·접지 빽빽한 내부를 정면 → BLE 거리↓·KC 리스크. **구리 void만으론 해결 불가**(U2 등 실부품이 남음).
- **✅ 해결**: **U1 → ESP32-WROOM-32UE-N8(C701345, 핀투핀 호환·외장 u.FL).** PCB안테나 제거 → 키프아웃 불필요·U2간섭 해소(모듈 6.3mm 짧아짐)·외장안테나 케이스 자유공간 부착. **PCB 재라우트 불필요(패드 동일).** SSOT v1.9.1 반영.
- **발주전 잔여**: ①EasyEDA에서 U1 풋프린트를 -32UE로 교체(패드동일·바디outline/실크/**u.FL 커넥터 클리어런스** 확인) ②외장안테나+피그테일 BOM추가 ③**KC 인증서 호환 안테나(게인 한도내)** 사용 ④케이스에 안테나/케이블 배치.

### E-03. R13이 U1 22번핀 패드 침범 (배치오류) ★NEW
- 증거: U1.22(NC) @ (1929.4,834) RECT 82.7×37.4 → x[1888.05,1970.75] / R13.2(VCC_3V3) @ (1973,829.6) RECT 31.8×34 → x[1957.1,1988.9]. **x축 13.65mil·y축 31mil 겹침**.
- **영향**: R13(AMP_PDN 풀업)이 ESP32 22번핀 castellated 패드 위에 올라탐. 22번이 NC라 기능 단락은 아니나 **VCC 구리가 U1 패드로 번짐 + 솔더브릿지/안착불량** 위험. DRC 클리어런스/단락으로 플래그 가능.
- **수정방향**: R13을 U1에서 ~15mil 이상 이격.

### E-04. 부스트 스위칭 노드가 대면적 구리 pour (EMI)
- 증거: U3 SW핀(689,1750) ↔ L1.2(812,1969) 6.1–6.6mm, ↔ D3.2(858,1693) 4–5mm / BOOST_SW pour rect 250×330mil(6.4×8.4mm).
- **영향**: 고 dv/dt 대면적 구리 = EMI 방사체. KC 방사 리스크 + SW 링잉.
- **수정방향**: L1·D3을 U3에 근접 재배치해 SW 노드 면적 축소.

### E-05. 디커플링 캡이 IC 전원핀에서 멈 (PI/EMI)
- 증거: C21(MP3426 VCC=BOOST_VDD 바이패스) ↔ U3.7 **6.8mm** (권장<2mm) / U4 PVDD 최근접 캡 C8 **6.7mm** / C1·C11(VCC) 4.1–4.2mm.
- **영향**: SMPS 바이어스 바이패스 부실 → 불안정·노이즈 / Class-D PVDD 디커플링 멀어 PSRR·THD 저하.
- **수정방향**: C21을 U3.7 핀에, PVDD 캡을 U4 PVDD핀에 국소 이동.

### E-06. 전원부 GND 스티칭 희박
- 증거: GND 비아 5개가 전부 (1231,411)(1321,501)(2166,624)(2292,620)(2386,560) — U3/U4(y1693)에서 **1100mil+ 이격**. 전원부 GND는 173개 top 트레이스로 연결되나 평면 본딩점이 멀다.
- **영향**: 전원부 접지귀환 경로 길어 인덕턴스↑ → EMI/PI (특히 Class-D·부스트 스위칭 귀환).
- **수정방향**: U3/U4 GND 핀·EP 근처에 GND 스티칭 비아 추가.

### E-07. 부스트 인덕터 L1 포화전류 마진 부족
- 증거: L1 = 4.7µH ±20% **Isat 5.5A** / 부스트 피크 입력전류 ~5A(풀로드 5V→12V).
- **영향**: 풀출력시 인덕터 포화 위험 → 효율저하·발열·잡음. (README도 "8A 교체" 권고.)
- **수정방향**: Isat 8A급 인덕터로 교체.

## 🟡 조건부 / 시스템 (사실이나 의도·정량화 필요)

### E-08. 전원 pour 잠식 (전류용량)
- 증거: VBUS pour를 다른넷 트레이스 **143개**, PVDD pour를 **100개** 관통 → 유효 전원동박 단면 감소. (SSOT의 VBUS 1.2mm 폭이 광폭트레이스 아닌 pour로 구현 — 실 트레이스는 전부 10mil.)
- **불확실**: 실제 5A 용량 미달 여부는 fill 기하 없인 단정 불가. 괜찮을 수도 있음.
- **수정방향**: 핵심 전원경로(USB-C→U3, D3→U4)를 광폭 트레이스로 보강하거나 pour 넥 육안 확인.

### E-09. USB-C 전력 한계 (시스템)
- 증거: CC에 Rd 5.1k(R3/R4)만 있고 **PD 컨트롤러 없음** → 표준 USB-C 최대 3A@5V=15W. 20W RMS 오디오는 ~25W 필요.
- **영향**: 풀볼륨이 USB-C 공급한계 초과 → 브라운아웃 가능. 메모상 "펌웨어 SPL 하드리밋"으로 대응 계획 → **의도된 트레이드오프 추정**.
- **수정방향**: 펌웨어 SPL 제한 확정, 또는 PD 컨트롤러 추가(5A엔 e-marked 케이블 필요).

### E-10. 마운팅홀 0개
- 증거: H/MTG/MH designator 부품 0개.
- **불확실**: 케이스가 다른 방식(스냅·접착)으로 고정하면 의도. 유아제품이라 기구강도 확인 권장.
