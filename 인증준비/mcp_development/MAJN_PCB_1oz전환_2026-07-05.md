# MAJN PCB — 1oz 전환 + 전원 pour폭 감사 + Gerber 재출력 (2026-07-05)

대상: EasyEDA Pro `new start`/PCB1. 목적: 발주 원가 절감을 위한 외층 동박 2oz→**1oz** 전환 타당성 검증 및 필요 보강.

---

## 1. 왜 이 작업을 했나 (배경)

JLCPCB 발주 견적에서 외층 2oz가 $33.40/발주를 차지. 1oz로 내리면 절감되나, **설계가 2oz 전제로 검증**돼 있어 무조건 전환은 위험. → 전원 경로가 1oz에서 실제로 전류를 버티는지 **직접 기하 감사**.

## 2. 핵심 발견 — DRC가 못 잡는 pour 넥 (E-08류)

전 트레이스가 10mil이고 전원은 **pour(구리 채움)**로 운반됨. 그런데 **"전원 경로를 따라 pour 최소폭이 몇 mm인지"는 그동안 한 번도 수치 감사한 적 없음** (DRC는 연결·간격만 보고 전류용량은 안 봄).

pour 래스터 감사(scipy EDT + 병목폭) 결과 3개 전원 경로에 **10mil 트랙/비아 핀치**가 실재:
- **VBUS (USB→L1)**: pour가 L1까지 못 가고 마지막 구간이 10mil 트랙 1~2가닥 (12W캡 시 ~3.3A)
- **BOOST_SW 크로싱**: SW pour가 west(U3핀)/east(L1·D3) 두 조각으로 갈라져 **비아2+10mil점퍼2(내층 0.5oz 고정)**로만 연결 (12W캡 시 rms ~2.3A) — 가장 심각
- **PVDD (D3→U4 우측)**: 300mil 길이 10mil 바텀 트랙 (하프브리지 전류)

> 교훈: 2oz도 이 핀치들은 완전 커버 못 함(2oz는 외층만 두꺼워지고 내층 점퍼·비아는 그대로). "2oz+pour 전략"이 최종 라우팅에서 마지막 구간까지 구현되지 않았던 것.

## 3. 보강 — additive-only (삭제·이동·기존배선 변경 0건)

기존 DRC 0 보드를 안 흔들기 위해 **순수 추가만**. 생성 ID 전부 로그(`_fix_log.json`)로 결정적 롤백 확보.

| 수정 | 내용 | 결과 |
|---|---|---|
| **F1** | VBUS **60mil** top 트랙 (530,1962)→L1.1, C23 패드 피하는 저y 경로 (클리어런스 55mil) | ✅ DRC 0, 유지 |
| **F3** | PVDD **30mil** bottom 트랙 (U4 우측 피드) (클리어런스 26mil) | ✅ DRC 0, 유지 |
| **F2** | SW 크로싱 비아 2개(690,1795·762,1820)+30mil 바텀점퍼 | ❌ **롤백** |

**F2 실패 이유(권위 UI DRC가 정확히 적발)**: 신규 비아가 ①기존 비아와 hole-to-hole 3.1/6.1mil(규정 11.8mil 위반) ②GND평면 안티패드 0mil. SW west 패치가 U3 노출패드(GND)+VBUS트랙+C21(BOOST_VDD)로 완전히 갇혀 **규정 간격 비아를 물리적으로 못 넣음**. → F2 롤백 후 재-DRC **0 에러**.

- 과정 함정: 브릿지 `pour.modify()` 재-pour는 **신규 비아 안티패드를 안 만듦** → GND단락 위반. 자체 pour 기하 파서도 known-good 옛 비아를 오판 → **권위 UI DRC만 신뢰**(규칙 §0.3 재확인). EasyEDA 창 2개로 늘면 브릿지가 엉뚱한 창을 잡음(여분 창 닫아 복귀).

## 4. 결정 — 1oz + FW 캡 10W

F1·F3로 VBUS·PVDD는 1oz 견고. SW 크로싱만 하드웨어로 못 키움 → 원상태(비아2+10mil점퍼) 유지.
- SW 크로싱 1oz 용량: 점퍼 RMS 1.6A(=10W)에서 **승온 ~23°C**(짧은 내부 구간, 안전). 실사용 1~3W엔 2~7°C.
- 진짜 안전망은 구리가 아니라 칩(MP3426 전류제한·열차단; 10mil 1oz 용단전류 10A+). 최종 확인은 §5-2 열영상 실측.
- **1oz 성립 조건 = FW-3 캡 ≤10W** (FW 명세 반영 완료). 12W 원하면 2oz.
