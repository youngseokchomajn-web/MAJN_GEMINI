## S4 — 회로도 생성 + ERC

### S4-1. 💻 회로도 자동 생성
터미널에서:
```
cd "C:\Users\newdo\OneDrive\바탕 화면\claude code\인증준비\mcp_development"
python run_draw_schematic.py
```
이 스크립트가 에디터 안에서 자동 수행: 회로도 페이지 생성 → **40개 부품 심볼 배치** → **각 심볼 실제 핀 읽기** → 핀↔네트 매칭 → **와이어+네트라벨 그리기** → 회로도↔PCB UniqueId 연결.

✅ **출력에서 반드시 확인할 것:**
- `수집된 총 핀 개수: N개` — N이 수백 단위면 정상(부품 핀 전체).
- `디바이스 캐싱 완료/없음` — "없음"이 뜬 부품은 라이브러리 캐시 필요(아래 S4-3).
- `[WARN] 스펙↔심볼 미매칭 M건` — **여기 뜨는 핀이 핵심.** M=0이면 완벽. M>0이면 그 핀들(특히 `U3.*`, `USB_C.*`)은 심볼 핀이름이 스펙과 달라 연결 안 된 것 → S4-3.

### S4-2. ✅ MP3426·USB-C 핀 확정 (보류분 해소)
스크립트 출력의 핀 덤프(또는 WARN 목록)에서 U3(MP3426)·USB_C의 **실제 핀 이름**을 확인하세요.
- U3가 **14핀으로 잡혔는지**(2핀이면 라이브러리 캐시가 잘못된 것 → S4-3 캐시 재등록).
- U3 핀이름이 스펙(`VIN/SW/FB/EN/GND/PGND/EP`)과 다르면(예: `IN/LX/FB/EN/PGND`), `mcp_design_flow.json`의 U3 항목을 실제 이름으로 고친 뒤 S4-1 재실행.
- USB_C의 `CC1/CC2` 핀이름도 동일하게 확인·정정.

### S4-3. 🖱️ 미캐싱/2핀 부품 라이브러리 재등록 (필요 시)
WARN/실패가 난 LCSC만:
- EasyEDA에서 **Shift+F**(라이브러리 검색) → 해당 LCSC ID 검색 → 부품 더블클릭으로 캐시 등록.
- 특히 **C162810(MP3426)**: 검색 결과의 풋프린트가 **QFN-14(+EP)** 인지 확인. 2핀짜리면 다른 정상 MP3426 부품으로 교체 필요(스펙 lcsc_id 변경).
- 재등록 후 S4-1 재실행.

### S4-4. 🖱️ ERC (전기규칙검사) 실행
회로도 탭(**P1.Schematic1**)에서:
- 상단 **Design(설계) 메뉴 → Check / ERC**(버전에 따라 "Design Rule Check"/"电气规则检查").
- ✅ 결과창의 오류 **0건**까지. 흔한 항목: *Unconnected pin*(미연결 핀), *Duplicate net*(중복), *Net with single pin*(단일핀 네트).
- ⚠️ 미연결 핀이 뜨면 그 핀이 S4-1에서 매칭 안 된 핀 → 스펙 정정 후 재생성 또는 수동 배선.

### S4-5. ✅ 스팟체크 (핀맵 대조: pinmap_master.md)
회로도에서 몇 핀만 눈으로 확인:
- U4: SDA=핀10, SCL=핀11, LRCLK=핀6, SDIN=핀8, PDN=핀12, EP→GND
- U5: VDD(9)·VDDIO(5)→3V3, CS=핀12
- U3: VIN←5V, SW→인덕터, EN←ESP32 IO4

**S4 완료 기준:** ERC 0건 + 스팟체크 일치.

## S5 — PCB 반영 · 배선 · Gerber

### S5-1. 🖱️ 회로도 → PCB 동기화 (Update PCB)
회로도 탭에서:
- **Design 메뉴 → Update PCB / Convert to PCB**(회로도 변경을 PCB에 밀어넣기).
- ✅ PCB1 탭에 **변경 네트가 ratline(흰 연결선)** 으로 표시되고, **신규 부품 5개(R7/R8/C18~C20)** 가 추가됨.
- ⚠️ "이 부품을 추가/삭제/네트변경" 확인창이 뜨면 내용 검토 후 승인.

### S5-2. 🖱️ U3(MP3426) 풋프린트 교체 — 가장 까다로움
현 PCB의 U3는 **2패드 불량**입니다.
- 회로도가 올바른 MP3426를 가졌으면 S5-1 동기화 때 풋프린트가 교체될 수 있음 → PCB에서 **U3가 14패드(+EP)** 인지 확인.
- 여전히 2패드면: PCB에서 기존 U3 삭제 → 회로도의 U3와 연결된 올바른 14핀 풋프린트를 재배치(Update PCB 재실행 또는 수동 Place).

### S5-3. 🖱️ 신규/이동 부품 배치 정리
- 추가된 R7/R8/C18/C19/C20을 보드 경계(80×60mm) 안, 각 기능 근처로 이동:
  - R7/R8(I2C 풀업)·C18~C20(앰프 디커플) → **U4 근처**.
- ⚠️ 안테나 keepout(ESP32 상단)·스위칭 루프(U3-L1-D3 ≤2mm) 침범 금지.

### S5-4. 🖱️ 배선 (Route)
- 자동배선: **Route 메뉴 → Auto Router**(또는 수동 배선).
- 전원 트레이스 폭: VBUS **1.2mm**, PVDD **1.0mm**, VCC_3V3 **0.25mm**, BOOST_SW **0.8mm**.
- ✅ ratline(흰선)이 전부 실제 동박으로 바뀌면 OK.

### S5-5. 🖱️ GND 동판 (Copper Pour) + 재구축
- 4개 층(Top/Bottom/Inner1/Inner2)에 **GND pour** 생성(Place → Copper Area/Pour, net=GND).
- **Shift+B** 로 동판 재구축.

### S5-6. DRC (설계규칙검사)
- 🖱️ PCB 상단 툴바/메뉴의 **DRC** 실행, 또는 💻 `python run_full_drc.py`.
- ✅ 위반 **0건**까지(클리어런스/오버랩/미배선).

### S5-7. Gerber 재출력
- 💻 `python run_export_gerber.py` → `Gerber_Output.zip` 갱신(프로젝트 루트).
- 또는 🖱️ **File → Export → Gerber**.
- ⚠️ 기존 06-18 출력본은 폐기(구버전).

**S5 완료 기준:** DRC 0건 + Gerber 재출력 완료.

## 대안 경로 B (참고) — PCB 직접배선 한 방
회로도/ERC 없이 PCB에 바로 재구성하려면:
```
python run_mcp_design_flow.py
```
- 정정 스펙 + 견고화된 connect_net으로 **재배치+재배선+pour+Gerber+DRC**를 한 번에.
- 장점: 단순(스크립트 하나). 단점: **ERC 없음** → S7 데이터시트 대조로만 검증.
- ⚠️ 실행 시 `[WARN] connect_net 미해석 핀` 로그를 반드시 확인(특히 U3/USB_C).
- 인증 신뢰성 위해선 경로 A(스키매틱+ERC) 권장.
