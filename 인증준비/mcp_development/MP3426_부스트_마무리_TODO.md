# MP3426(U3) 부스트 마무리 TODO — 정밀 스펙

**상태:** 회로도(S4)에 U3는 배치·주요핀 결선 완료. **지원망(COMP/FSET/SS/VDD)만 남음.**
**왜 보류:** 이 값들은 전원-임계(안정성·출력전압)이고 MP3426DL 데이터시트의 파라미터가 필요한데, 외부 데이터시트 CDN이 전부 차단돼 정확값 확보 실패. **인증용 영유아 제품이라 추측값으로 "최적" 단정 안 함.**
**부하 특성(참고):** TT25-16로 10~12µm **미세진동** → 평균 전류 작음(경부하). 경부하라 보수적 보상이면 안정성 위험은 낮음(단, 제작 전 벤치 검증 필수).

## 실측 심볼 핀 (C2909511 = MP3426DL, 15핀)
| pin | 이름 | 현재 결선 |
|---|---|---|
| 3 | VIN | VBUS_5V ✅ |
| 4,5,6 | SW | BOOST_SW(→L1/D3) ✅ |
| 13 | FB | BOOST_FB(R1/R2) ✅ |
| 2 | EN | BOOST_EN(GPIO4) ✅ |
| 8,9,10 | PGND | GND ✅ |
| 11 | AGND | GND ✅(정정됨) |
| 15 | EP | GND ✅ |
| **1** | **COMP** | **미연결 → 보상망 필요** |
| **14** | **FSET** | **미연결 → 주파수 저항 필요** |
| **12** | **SS** | **미연결 → 소프트스타트(옵션)** |
| **7** | **VDD** | **미연결 → 내부LDO 바이패스 필요** |

## 데이터시트에서 확정할 값 (★ = 꼭 필요)
1. ★ **FB 기준전압(Vref)** — 현재 R1=150k/R2=16k. Vref=1.2V 가정 시 **≈12.45V**(앰프 PVDD 4.5~26.4V 내, OK). 정확히 12.0V는 R2≈16.5k. → Vref 확인 후 R2 확정.
2. ★ **FSET 저항↔주파수 공식** — L1=4.7µH 기준 목표 **~700kHz**(0.5~1MHz 권장대) 저항 산출.
3. ★ **COMP 보상망** — type-II (Rc직렬Cc + 병렬Cc2). 경부하 보수적 시작값(데이터시트 가이드로 확정): 예 **Rc 20~30k, Cc 2.2~3.3nF, Cc2 100pF**.
4. **VDD 바이패스** — 내부 LDO. 통상 **1µF/GND**(데이터시트 권장값 확인).
5. **SS 캡** — 소프트스타트 시간. 통상 **10nF/GND**(또는 내부 기본이면 생략 가능).

## 추가할 부품(스펙+캐싱 필요, 현 BOM에 없음)
| 지정 | 값 | 연결 | 비고 |
|---|---|---|---|
| C21 | 1µF 0603 | VDD(7)→GND | LCSC 캐싱 필요 |
| C22 | 2.2nF 0603 | COMP(1)→Rc | LCSC 캐싱 필요 |
| R9 | 20~30k 0603 | COMP(1)→C22 | (값 확정 후) |
| C23 | 100pF 0603 | COMP(1)→GND | (옵션 Cc2) |
| C24 | 10nF 0603 | SS(12)→GND | LCSC 캐싱 필요 |
| R10 | (FSET값) 0603 | FSET(14)→GND | 주파수 산출 후 |

> ⚠️ 새 LCSC ID는 `run_draw_schematic` 전에 EasyEDA 라이브러리에 **캐싱**돼야 배치됨(`cache_components` 또는 Shift+F 검색).

## 마무리 절차 (데이터시트 확보 후 ~10분)
1. 위 값 확정 → `mcp_design_flow.json`에 부품 6개 + 네트(BOOST_COMP, U3.VDD→C21, U3.SS→C24, U3.FSET→R10) 추가.
2. 새 부품 LCSC 캐싱.
3. `python run_draw_schematic.py` 재실행 → 회로도 갱신.
4. ERC → S5(PCB)로 진행.
5. **제작 전 벤치에서 부스트 출력전압·기동·안정성 측정** (인증 항목).
