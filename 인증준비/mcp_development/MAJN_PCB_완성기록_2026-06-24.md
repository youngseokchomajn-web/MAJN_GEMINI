# 마중 진동모듈 PCB — 완성 기록 (2026-06-24)

## 결과
- **라우팅 100% 완료** (autoroute 586트랙/61비아, 16.7초) · **DRC All(0)**
- 4층: Top(부품+전원pour+신호) / Inner1(GND 솔리드 평면) / Inner2(신호) / Bottom(신호)

## 핵심 교훈 — 배치가 배선효율의 결정 요인
- **구(舊) 배치**: U1(ESP32)·U4(앰프)가 보드 양쪽 → I2S/I2C 버스 혼잡 → **autoroute 88.37%에서 하드캡**(3회 동일).
- **신(新) 데이터플로 배치**: 좌표만 재설계(회로도/BOM 불변) → **autoroute 100%**. 배치 인접성이 결정적이었음이 정량 입증됨.

## 데이터플로 플로어플랜
- **U1(ESP32) 바로 아래 U4(앰프)** — I2S/I2C 버스 최단(수직 인접, 갭 ~6.5mm). 안테나 상단 키프아웃.
- **U4 좌측 = 부스트 클러스터**(U3+L1+D3, PVDD 우측 U4로). **부스트 좌측 = USB-C**(VBUS 좌→우).
- **U4 우측 = FB1~4 페라이트 + J1/J2 커넥터**(AMP_OUT 최단).
- **U1 옆 = U5(IMU, SPI 최단)·U2(LDO, VCC)·UART 헤더.**

## Fresh-eye 전수 점검 + 디커플링 수정 (2026-06-24 밤)
자동검사(100%·DRC0) 통과 후 **DRC가 못 잡는 전력무결성(PI) 결함**을 fresh-eye로 발견·수정:
- **발견**: 재배치(클러스터이동+de-overlap)가 디커플링을 핀에서 흩어놓음 → C2(MCU 100nF) **23mm**, C1(MCU 22µF) 23mm, C12~15(Class-D 부트스트랩) 8mm, C20(VR_DIG) 8mm.
- **위험 재보정(정직)**: "고장"이 아니라 신뢰성·EMC 마진 감소(ESP32 모듈 내부캡·부스트 메인필터 있음). KC+EMC 인증·양산 위해 수정.
- **수정(안전절차)**: BOOST_SW LOCK → 캡 7개를 IC 전원핀 옆(<3mm)으로 국소이동 → "Remove existing" 재라우트(잠금전원 유지) → EP비아 재추가 → pour 재충전.
- **결과**: C2 23→**2.0mm**, C1 23→4.2mm, C12~15 8→2.6~3.3mm, C20 8→2.7mm. **100% 라우팅·DRC0·BOOST_SW 18mil(23개 전부)·pour 전부 유지.** 국소 캡이동은 매크로 배치 불변 → 라우팅 안 깨짐을 실증.
- **잔여 경미**: 안테나 키프아웃은 WROOM 풋프린트가 자체보유 + C1/C2를 U1 위(y7)에 둬도 DRC 무위반 → 상단은 안테나 아님(좌측 추정). 발주 전 육안 1회 권장.
