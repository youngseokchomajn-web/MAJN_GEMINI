# 마중 PCB — 치명결함 수정 기록 (2026-06-25)

전수 재검증으로 확정된 결함을 EasyEDA 브릿지로 수정. **모든 수정은 기하/연결성 실측으로 검증.**
(EasyEDA cloud PCB1에 저장됨. 공식 DRC 재실행은 bridge `check()` 500 + UI IME 차단으로 미실시 → 기하검증으로 대체.)

## 근본 원인
**R12(ADR 풀업 4.7k)가 회전 편집 중 두 핀이 swap돼**, VCC라인은 AMP_ADR핀에·AMP_ADR스텁은 VCC핀에 가 있었음. 양쪽 다 미연결.

## 수정 (5건)
| # | 결함 | 수정 | 검증 |
|---|---|---|---|
| 1·2 | R12 양핀 미배선 (AMP_ADR·VCC 단선) | **R12 두 패드 넷 swap** (pad1@1505→VCC, pad2@1565→AMP_ADR). 대칭저항이라 전기적 동일. 기존 배선이 올바른 핀에 정합 | U4.3↔R12.2(AMP_ADR), R12.1↔VCC 모두 touch OK. ADR 풀업 완성(0x2C) |
| 5 | EP 모서리비아 ↔ AMP_OUT_A- 5mil 겹침(GND-출력 단락) | **모서리 비아(1646,1740) 삭제** | AMP_OUT 최소간격 8.09mil (>6mil) |
| - | EP 써멀비아 12→11개 net='' (DRC 노이즈·접지미검증) | **11개 모두 GND 할당**(via.modify, 영속확인) | net='' 0개, GND비아 16개. clearance 노이즈 ~42건 정리 |
| - | PVDD 트레이스 ↔ EP GND비아 3개 1.5mil(근접단락) | **PVDD 트레이스(1444,1757)-(1680,1757) 우회**(중간 y1768 dip), EP비아 11개 보존 | 다른넷 근접 위반 **0건**, PVDD 연결유지 |

## 수정 후 상태 (기하검증)
- ✅ 다른넷 clearance 위반 0 / net='' 비아 0
- ✅ AMP_ADR·VCC 연결, AMP_OUT 단락 제거
- ✅ 제조성(폭10mil·드릴12mil·환형4mil) 유지

## 잔여 (경미/후속)
1. **GND 고립 섬 2개** (원 DRC) — 경미, 평면 미도달 소동박. DRC 재실행으로 재확인 필요.
2. **R12 핀라벨**: PCB pad1=VCC/pad2=AMP_ADR ↔ 회로도 pad1=AMP_ADR/pad2=VCC. **대칭저항이라 전기적 무관**이나, EasyEDA 넷리스트 검사가 핀번호로 비교하면 표시 가능 → 회로도 재생성으로 정합 가능(선택).
3. **공식 EasyEDA DRC 재실행** 권장 (bridge 500/IME로 이번엔 기하검증 대체).

## 도구 교훈
- `pcb_PrimitiveComponent.setState_Rotation/Designator/UniqueId` = **비영속**(transient, 저장해도 복귀). 컴포넌트 회전은 bridge로 불가.
- `pcb_PrimitivePad.modify({net})`·`pcb_PrimitiveVia.modify({net})`·`.delete()`·`pcb_PrimitiveLine.create/delete` = **영속**. → 넷 swap·비아 삭제·트레이스 우회는 신뢰가능.
- `pcb_Drc.check()` 무거운 호출 = HTTP 500.
