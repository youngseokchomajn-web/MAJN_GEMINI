## 1. 프로젝트 / 목표
- **제품:** 영유아용 "마중 스마트 배시넷"(스마트 요람). 실제 양산·**KC 인증 준비** 중 → **안전 직결, 값은 추정 금지·데이터시트로 확정**.
- **설계 의도:** 30~65Hz 폐루프 진동 구동, **5V→12V 부스트(MP3426)**, TAS5805M 앰프(85dB 제한), LSM6DSOX IMU 피드백, ESP32 제어, 안전 차단.
- **GitHub:** https://github.com/youngseokchomajn-web/MAJN_GEMINI

## 2. 무엇이 문제였나 (진단 결과)
실측 Gerber 넷리스트(`FlyingProbeTesting.json`)를 데이터시트와 1:1 대조 → **현 설계는 제작·동작 불가**였음. 근본원인 2개:
1. **스펙 핀번호 오류** — `mcp_design_flow.json`이 U4(TAS5805M)·U5(LSM6DSOX)의 I2C/I2S/CS/전원을 틀린 핀에 배정. U3(MP3426)는 **2핀**으로 캐싱됨.
2. **툴 결함** — `connect_net()`이 ESP32 핀 이름 못 찾으면 `pads[0]`로 조용히 오배정→증발. ESP32 39핀 중 6핀만 실제 연결됨.

## 3. 설정된 규칙 (반드시 지킬 것)
- ⛔ **main으로 머지 금지.** 작업은 브랜치에서만.
- 🧩 **단계별 진행 + 각 단계 끝나면 중지**하고 사용자 확인 받기.
- 📐 전원/보상 값은 **데이터시트 확정값**만 사용(추정 금지).
- ✅ 접근법: **스키매틱 우선 + ERC**(동박 직접배선 패치 아님 — ERC 안전망 위해).

## 5. MP3426(U3) 부스트 — 데이터시트 확정값 (핵심 산출물)
출처: MP3426 데이터시트 Rev.1.11(MPS 공식). 5V→12V, COUT≥22µF 기준.
| 핀 | 부품 | 값 | LCSC | 근거 |
|---|---|---|---|---|
| FB(13) | R1/R2 | 150k/16k → **12.71V** | (기존) | Vref=**1.225V** |
| FSET(14) | R9 | **82k → ~556kHz** | C325632 | EC 84.5k=540kHz |
| COMP(1) | R10+C22 | **24.9k + 4.7nF 직렬→AGND** | C48391802 / C596328 | Table2(25k/4.9nF) |
| VDD(7) | C21 | **1µF→GND** | C106858 | 내부 LDO 바이패스 |
| EN(2) | R11 | **100k 풀다운** | C2073721 | EN 플로팅 금지·부팅시 boost OFF |
| SS(12) | — | **NC** | — | 데이터시트 기본 |
- 추가넷: `BOOST_VDD/BOOST_FSET/BOOST_COMP/COMP_RC`, GND에 R9.2·C21.2·C22.2·R11.2.
- 옵션(현 값도 동작): R2 16k→16.9k(정확히 12.10V), 인덕터 L1 4.7µH→6.8µH(데이터시트 정합).

## 7. 툴 환경 (라이브 작업 전 필수)
- EasyEDA Pro 자동화 = **브릿지 서버(Node, localhost:49620)** + **run-api-gateway 플러그인(WebSocket)**.
- 점검: `curl http://localhost:49620/health` → `edaConnected:true` 확인.
- 죽었으면: `node scripts/bridge-server.mjs`(백그라운드) 후, EasyEDA에서 API Gateway 플러그인 → Reconnect(컴퓨터 제어로 클릭).
- 데이터시트 PDF가 WebFetch/curl로 막히면 **Chrome MCP로 PDF 열고 pdf.js 추출**(검증된 우회법).

## 8. 다음에 할 일 (재개 지점)
1. **(선택) ERC** — EasyEDA `Design → ERC`. 예상 NC 경고(정상): U3.SS, U4.SDOUT(9), U5 예약핀(2/3/10/11), USB D±/SBU/쉴드.
2. **S5 PCB** — 회로도→PCB 동기화 → **2패드 U3가 14핀 풋프린트로 교체됐는지 확인(중대)** → 배선 → 4층 GND pour → DRC → Gerber 재출력.
3. **S7 재검증** — 재출력 `FlyingProbeTesting.json` ↔ `pinmap_master.md` 자동대조 PASS, 인증 체크리스트 0건.
4. **제작 전 벤치:** 부스트 출력전압·기동·load step 안정성 측정(R_COMP 점진 상향으로 오버슈트 최소화).
