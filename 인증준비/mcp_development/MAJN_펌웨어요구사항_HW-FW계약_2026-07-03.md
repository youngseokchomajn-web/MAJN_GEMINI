## §2. 펌웨어 필수 요구사항

### FW-1. 부팅/전원 시퀀스 (TAS5805M TI 권장 순서 보장)
하드웨어상 부팅 직후 "PDN=H·PVDD=0" 창이 존재(R13 풀업 + 부스트 기본OFF). 손상은 없으나(내부 UVLO) 초기화 품질을 위해:
```
1. 부팅 즉시:      GPIO15 = LOW   (PDN 잡기 — 최우선, GPIO 초기화 첫 줄)
2. 준비 완료 후:   GPIO4  = HIGH  (부스트 ON)
3. PVDD 안정 대기: ≥10 ms (부스트 SS 포함)
4. PDN 해제:      GPIO15 = HIGH
5. ≥5 ms 후:      I2C(0x2C) 초기화 시퀀스 진입
종료/에러 시 역순: 볼륨 램프다운 → PDN LOW → BOOST_EN LOW
```

### FW-2. TAS5805M 초기화 (EMC 통과 조건)
- **Fsw = 384 kHz** + **확산 스펙트럼(spread spectrum) ON** + **BD 변조** — TI 공식: PVDD<14V(우리 12.17V)에서 페라이트 출력필터로 EMI 마진 확보되는 설정. 하드웨어가 필터리스(FB1~4+2.2nF)이므로 **이 설정 없이는 KC 방사 시험 위험**.
- 채널 간 180° 위상 시프트 옵션 활성 권장.

### FW-3. 출력 전력 상한 (하드코딩 캡)
- **총 출력 ≤ 10 W (양 채널 합)** 를 디지털 게인/볼륨 상한으로 강제. (★2026-07-05 1oz 발주 확정으로 12W→10W 하향)
- 근거(하드웨어 한계):
  - L1 SWPA6045S4R7MT: Isat 5.5A — 12W 시 피크 ~4.0A(마진 27%), 20W 시 ~5.0A(마진 10%) ❌
  - L1 Irms 3.3A(40°C승온) — 20W 시 입력평균 4.4A로 초과 ❌ / 10W 시 ~2.3A ✅
  - 출력 트레이스 10mil(1oz ≈0.9A@10°C) — 12W 시 채널 0.87A ✅
  - **★1oz 전용 제약 — BOOST_SW 크로싱**: 원설계 pour폭 감사 결과 SW 노드 west↔east 연결이 비아2+10mil점퍼2(내층 0.5oz)로만 이뤄짐. 이 크로싱이 1oz에서 ~1.6A(=10W 시 점퍼 RMS)에서 승온 ~23°C로 안전. 12W(2.3A)면 ~32°C로 마진 축소 → **1oz에서는 10W 캡이 근거상 필수.** (2oz 발주 시엔 12W 가능.) F2(크로싱 비아 추가) 시도는 congested 영역이라 DRC hole-to-hole+GND안티패드 위반으로 롤백 — [MAJN_PCB_1oz전환_2026-07-05.md](MAJN_PCB_1oz전환_2026-07-05.md) 참조.
- 실사용(미세진동)은 1~3W라 체감 영향 없음. 상한은 버그/오설정 방어선.

### FW-4. 온도 감시 (매트리스 밑 안전)
- TAS5805M 폴트/OTW 레지스터를 **주기 폴링(≤5 s)** — OTW/폴트 시 단계 감쇠→차단.
- 장시간 연속 구동 시나리오에 **출력 시간가중 상한**(예: 고출력 지속 n분 후 자동 레벨 다운) 권장.
- 최종 판정은 시제품 열영상 실측(§5-2) — 실측 결과에 따라 FW-3 상한 하향 조정 가능.

### FW-5. 페일세이프
- ESP32 워치독 활성 — 행 시 리부트하면 GPIO 기본상태(BOOST_EN↓=12V 차단)로 자동 안전.
- I2C 통신 실패(앰프 무응답) 시: PDN LOW + BOOST_EN LOW 후 재시도.
- BLE 명령 없이도 로컬 안전규칙(FW-3/4)은 항상 우선.

## §3. 하드웨어가 이미 보장하는 것 (펌웨어가 기대해도 되는 것)
