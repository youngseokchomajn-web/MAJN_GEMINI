# 마중 배시넷 — Phase A0/A1 부품 검증 리포트
*2026-06-24. 회로도 그리기 전 BOM 전수검증. 출처: LCSC 제품페이지 실조회(26개 고유 LCSC ID) + 데이터시트.*

## 결론
- **LCSC ID 전수 일치**: design_flow.json v1.3.0의 26개 고유 부품번호가 **전부 명칭과 일치**. 과거 "lcsc_id가 엉뚱한 저항을 가리킴" 버그는 **없음**.
- **정격(A1①) 결함 2건 발견** (DRC로는 안 잡히는 영역):
  - **★결함1 (중대)**: U2 LDO = **300mA** < ESP32-WROOM WiFi 피크 **~500mA** → 브라운아웃/리셋 위험.
  - **결함2 (경계)**: C3(LDO 입력, 5V 레일) = 10µF **10V** → TVS 클램프 9.2V 대비 여유 0.8V.
- **극성(A1②)**: D3 정류 방향 = design_flow 넷 기준 정상(양극→SW, 음극→PVDD). D1 TVS pad1=음극은 심볼 단계 확인 필요.
- **미확정 1건**: L1(C78804) Isat — LCSC 페이지 404, 캐시값 5~5.5A(피크~3.3A 충분)이나 데이터시트 최종확인 권장.

## 1. 정격(A1①) 결함 상세

### ★결함1 — U2 LDO 전류 정격 미달 (중대, A급/전력수지)
- **U2 = SGM2036-3.3 (C81114)**: 확인된 정격 = **최대 출력 300mA**.
- **부하**: VCC_3V3 레일 = ESP32-WROOM-32E + IMU + TAS5805M DVDD + 풀업. 지배부하=ESP32.
- **ESP32-WROOM WiFi 송신 피크 ~500mA**(Espressif 권장: 3.3V 공급 ≥500mA). OTA/WiFi 시 **300mA 한계 초과 → 전압강하·리셋·재부팅**.
- **수정안**: U2를 **≥500mA(권장 600mA) LDO**로 교체. 예: **AP2112K-3.3**(600mA, SOT-23-5, C51118) 등 + 3.3V 벌크캡 ≥10µF 유지(피크는 ms 단위라 평균 발열 0.14W로 무리없음, 피크 0.85W는 열시정수상 허용).
- **영향**: 회로도 U2 부품·풋프린트 변경 → **A0에서 design_flow.json 수정 후 회로도**.

### 결함2 — C3 캡 전압정격 경계 (A급/디레이팅)
- **C3 = 10µF 10V (C19702)**, VBUS_5V(5V) 레일의 LDO 입력캡.
- 1.5× 규칙(5×1.5=7.5V)은 통과하나, **D1 TVS 클램프 9.2V** 서지 시 여유 0.8V + 10V X5R의 DC바이어스 손실.
- **수정안**: C3(및 5V 레일의 10µF)을 **16V 또는 25V**로. (C1/C4는 3.3V라 10V로 충분.)
- 비교: C5(부스트 입력 4.7µF)=C19666 **16V** ✓ 양호.

## 4. 극성(A1②) — 심볼 단계 확인 항목
- **D3**: design_flow 넷 = D3.1(음극)→PVDD_12V, D3.2(양극)→BOOST_SW = **부스트 정류 정상** ✓ (과거 역방향 수정 반영됨).
- **D1**: TVS pad1=음극→VBUS, pad2=양극→GND. **심볼 pad1=음극 확인 필요**.
- **U3/U4/U5 EP**: EP→GND 확인(U4 EP는 과거 12V 오접 이력 → 반드시 GND).
- ⚠️ LCSC-ID는 검증됐으나 **심볼 핀번호↔넷 매핑(D3 역방향 부류 버그)은 라이브 EasyEDA 심볼 덤프(브릿지)로 별도 확인** 필요 = 다음 검증 레이어.

- AP2112K 핀아웃 = Diodes 데이터시트 직접확인(SOT-23-5: 1VIN/2GND/3EN/4NC/5VOUT). JSON 정합성·핀매핑 검증 통과.

### ★재검토에서 추가 발견 (미반영 — 다음 라운드)
1. **AMP_OUT EMI 필터 누락 (중요, EMC)**: TAS5805M는 filterless → TI 권고 "PVDD≤14V는 **페라이트비드**(100Ω@100MHz, 4A, 0806)" 또는 **LC필터(4.7µH+0.68µF)**. 현재 출력 4선에 **아무것도 없음** + **2m 케이블** → KC EMC 위험. **출력에 페라이트비드 4개(+캡) 또는 LC 추가 필요** = 넷 토폴로지 변경(부품 추가).
2. **MP3426 핀번호 미확정 (위험)**: 데이터시트 웹조회 실패(MPS 리다이렉트). design_flow의 U3 핀배정(COMP1/EN2/VIN3/SW4-6/VDD7/GND8-11/FB13/FSET14/EP15)은 **미검증** → D3 역방향 부류 잠재결함. **라이브 EasyEDA 심볼 덤프(브릿지) 또는 데이터시트로 확정** = A1 완료 게이트.
3. **C19 AVDD 디커플 100nF**: TAS5805M AVDD(내부LDO)는 통상 1µF 권장 → 값 확인.
4. **L1 Isat**: C78804 LCSC 404 → 데이터시트로 Isat 최종확인(피크~3.3A 대비).
