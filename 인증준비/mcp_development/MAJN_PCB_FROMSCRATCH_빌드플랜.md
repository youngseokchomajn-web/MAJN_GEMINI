# 마중 배시넷 PCB — 처음부터 새로 빌드 (배선 효율 최우선 플랜)
*2026-06-22. 컨텍스트·오류이력은 [MAJN_PCB_종합정리_재생성계획.md] 참조. 본 문서는 "처음부터 새 PCB" 실행 플랜.*

## 0. 설계 철학 — "배선은 배치에서 결정된다"
이전 실패(미배선 10개, 클리어런스 폭발, 두더지잡기)의 3대 근원과 본 플랜의 대응:
| 근원 | 결과 | 본 플랜의 차단 |
|---|---|---|
| U1(ESP32)↔U4(앰프) 대각선 원거리 | I2C·I2S 6넷 횡단 혼잡 → 미배선 | **Phase3: 인접 배치** |
| GND 평면 있는데 GND 트랙 168개 난립 | Top 포화 → Track-Via 클리어런스 | **Phase2: GND 평면 일원화(트랙 금지)** |
| 규칙 없이 배선 후 전원폭 확대 | 클리어런스 폭발 | **Phase1: 규칙 먼저 + Phase4: 전원 우선·정폭 배선** |

→ **솔리드 GND 평면 + 결합 부품 인접 + 전원 우선 정폭** 이면 배선이 자연히 깔끔해지고 50개 오류가 *생기지 않음*.

---

## 1. 레이어 스택 (4층 — 배선 친화)
| 층 | 역할 | 배선 효율 기여 |
|---|---|---|
| **L1 Top** | 부품 + 수평 신호 + 전원 | 부품핀 직결, 짧은 신호 |
| **L15 Inner1** | **솔리드 GND 평면** | 모든 신호의 깨끗한 리턴 → Top/Bottom 자유 배선 |
| **L16 Inner2** | 전원 분배(12V/5V) + 수직 신호 + 혼잡 우회 | 횡단 신호/전원 전용 |
| **L2 Bottom** | 신호 + 전원 + 로컬 GND 채움 | 2차 배선면 |
- 동박 1oz (배치 빡빡하면 2oz로 전원폭 절감 가능 — 발주 옵션).
- 권장: Top=수평 위주, Bottom=수직 위주(혼잡구간 직교 배선으로 충돌↓).

## Phase 0. 새 빈 PCB 생성
1. 프로젝트에 **새 PCB 문서 생성**(빈 보드).
2. **회로도(Schematic1) → Import Changes/Convert** → 45부품 + 38넷 래트선 import (배선 0, 깨끗한 출발).
3. 보드 외형 **80×60mm**(직사각), 원점 설정.
4. ESP32 안테나 **keepout 영역** 지정(엣지, 동박/부품 금지).
*도구: UI로 생성/Import(브릿지 X). 정정 넷리스트가 자동 반영됨.*

## Phase 1. 설계 규칙 먼저 (배선 전 필수 — 사후수정 방지)
1. **넷클래스 폭**: VBUS_5V 1.2mm · PVDD_12V 1.0mm · BOOST_SW 0.8mm · AMP_OUT_A±/B± 0.5mm · VCC_3V3 0.25mm · 신호 0.25mm(10mil) · GND=평면.
2. **클리어런스** 6mil, **홀↔동박** 6.9mil, **pour 클리어런스 6mil**(규칙 일치 — Copper Region 오류 차단).
3. **같은-넷 via-in-pad 허용**(U4/U3 EP 열비아용).
4. 비아: 신호 hole12/dia24, 전원은 레이어변경 시 다수 병렬.
*도구: UI Design>Net Class Manager + PCB Design Rule.*

## Phase 2. GND 평면화
1. **Inner1(L15) 전면 GND 평면**(솔리드).
2. Top/Bottom 로컬 GND 채움(신호 사이 빈 곳).
3. **스티칭 비아 격자 ~250mil** + 모든 IC GND/EP핀 옆 비아로 평면 직결.
4. **GND 시그널 트랙 사용 금지**(평면이 담당).

## Phase 3. 배치 — ★배선 효율의 핵심★
### 존(zone) 배치 (전원 흐름 선형: USB-C→변환→앰프→출력)
```
[좌엣지] USB-C · R3/R4(CC,홀이격) · D1(TVS) · C3 · U2(LDO)
[중앙]   U3 부스트 + L1 + D3 + 입출력캡 + R1/R2/R9/R10/C21/C22  ← 루프 최소·SW 최단
[하단엣지] U1 ESP32 (안테나=엣지+keepout, 핀 안쪽 향함)
[하단좌] U5 IMU (U1 옆 — SPI 5넷 단축)
[중우]   U4 앰프 (U1 위/옆 — I2C·I2S 6넷 단축, 12V는 좌측 부스트에서)
[우엣지] J1/J2 (액추에이터/스피커, U4 옆)
[상엣지] UART_HDR (U1 근처)
```
### 인접 규칙 (래트선 최단화 = 배선 쉬움)
- **U1↔U4 인접·핀 마주봄** (AMP_I2C_SDA/SCL, I2S_LRCLK/BCLK/DIN, AMP_PDN 6넷). ← 최대 효과
- **U1↔U5 인접** (SPI_MOSI/MISO/SCLK/CS, SENSOR_INT1 5넷).
- **부스트 루프**(U3-L1-D3-입출력캡) ≤2mm, BOOST_SW 노드 최단(EMI).
- **FB 분압(R1/R2)=U3 FB핀 근처, COMP(R10/C22)=COMP핀 근처, FSET(R9)=FSET핀 근처**.
- **디커플 캡 = 각 IC 전원핀 <100mil** (단 패드 0mil 겹침 금지 → 쇼트 방지).
- **R3/R4(CC저항) = USB-C CC핀 근처 + 장착홀 코트야드 이격**(충돌 방지).
### 팬아웃/이스케이프 사전계획 (미세핀)
- **U4 HTSSOP 0.65mm**: 각 신호핀에서 **수직 이스케이프 스텁 → 비아 → Inner2**. 인접핀 간 1트랙+6mil 확보.
- **U3 QFN, ESP32 castellated**: 동일 팬아웃 비아 전략.

## Phase 4. 배선 — 전원 우선 (정폭, 사후확대 금지)
1. **전원 동맥 먼저**(Phase1 폭으로 처음부터):
   - VBUS_5V(USB-C→U2,U3) 1.2mm → BOOST_SW(U3-L1-D3) 0.8mm·최단 → PVDD_12V(U3→U4) 1.0mm → AMP_OUT(U4→J1/J2) 0.5mm.
   - 전원은 Top/Bottom 굵게 + 필요시 Inner2 경유. **공간을 먼저 차지**.
2. **핵심 신호**(배치로 이미 짧음): I2C·I2S(U1↔U4), SPI(U1↔U5) → Top 직결 or Inner2.
3. **나머지 신호**: Inner2/Bottom. 혼잡구간은 Top수평/Bottom수직 직교.
4. **부스트 FB/COMP/FSET** 짧게(노이즈 민감).
5. 방식: UI 오토라우터(넷클래스 폭 자동적용)로 1차 → 수동 정리. **사후 폭 확대 금지**.

## Phase 5. 동박 마감 + 검증 + 출력
1. 전 층 GND 채움 재생성(**UI Shift+B**, 브릿지 rpcCall 금지).
2. **UI DRC로 0 확인**(브릿지 단독 신뢰 금지): 클리어런스·미연결·같은풋 모두 0.
3. 넷리스트=회로도 재대조, **전원폭 적용·EP 접지** 확인.
4. 저장 → **클라우드 동기 완료 대기** → **Gerber 재출력**(기존 zip 폐기).

## 6. 실행/도구 수칙 (degrade·바인딩 문제 회피)
- **브릿지**: 부품이동(modify)·좌표읽기 전용 (배치는 브릿지가 정밀·안정).
- **무거운 작업(배선삭제·오토라우트·동박재생성·DRC)은 UI로** (브릿지 동박재생성이 degrade 방아쇠).
- windowId 고정, 끊기면 `location.reload`로 에디터 폴백 후 재바인딩.
- 저장 직후 리로드 금지(동기 대기). 단계마다 JSON 백업.
- 각 Phase 끝에 사용자 확인(특히 Phase3 배치는 그림으로 합의 후 진행).

---

## 실행 순서 요약
**Phase0(새보드+Import) → Phase1(규칙) → Phase2(GND평면) → Phase3(배치, 그림합의) → Phase4(전원우선 배선) → Phase5(동박·UI DRC 0·Gerber).**
배치(Phase3)가 통과되면 배선(Phase4)은 이미 짧고 깨끗해져, 50개 오류가 *발생하지 않는* 상태로 수렴.
