# MAJN EMC 설계검토·계측장비·시험 전략 — 2026-10-06

현재 결론: 계측장비를 먼저 구매하지 않는다. 현재 보유한 멀티미터로 기본 브링업을 진행하고, 회로도/PCB/BOM 자체의 EMC 설계검토를 먼저 수행한 뒤 EMC Pre-test로 확인한다.

## 장비
- 멀티미터: 현재 사용
- 오실로스코프: 지금은 필수 아님. 실제 switching/ripple/ringing 원인이 확인될 때 구매·대여
- EMI near-field probe: 필요성이 확인될 때 구매·대여
- Spectrum analyzer: 현재 구매하지 않음
- Current probe: 현재 구매하지 않음
- LISN: 시험기관에서 측정
- GTEM/TEM cell: 구매하지 않음

## 설계 사전검토 우선순위
1. MP3426 Boost switching loop / high-current loop / GND return
2. TAS5805M Class-D / BTL output / decoupling / return path
3. BTL 출력에서 약 2 m actuator cable로 이어지는 경로
4. 4개 actuator 최대 동시 구동
5. Boost + AMP + BLE 동시 동작
6. USB-C 전원 경로
7. ESP32-WROOM-32E RF/3.3 V 영역과 noisy power 영역의 coupling
8. GND plane, connector, ferrite/EMI filter 위치

## 시뮬레이션으로 가능한 것
- 전류 loop 및 return path 분석
- decoupling 구조 검토
- Boost ripple 및 switching harmonic 검토
- filter/ferrite 역할 검토
- PCB noisy zone 분석
- cable/common-mode coupling 위험 분석
- 필요 시 SPICE 계열 회로/필터 검토

시뮬레이션만으로 실제 RE/CE 수치나 KC EMC 합격을 확정하지 않는다. 실제 PCB, cable, enclosure, 부하 및 조립상태가 반영된 Pre-test가 필요하다.

## EMC worst-case
- Boost ON
- TAS5805M 구동
- 최대 진동 출력
- BLE ON
- 4개 actuator 동시 구동
- 약 2 m actuator cable
- 실제 USB-C 외부전원
- 최종 PCB/케이스/배선

## 시험기관 전략
단순 측정만 하는 곳보다 EMC Pre-test → RE/CE 문제 대역 분석 → 원인 분석 → PCB/전원/필터/케이블 대책 → 수정 → 재시험 → 정식 적합성평가까지 연결 가능한 곳을 우선한다.

## 인증 흐름
멀티미터 브링업 → 회로도/PCB/BOM EMC 검토 → 필요 설계수정 → 시제품 → EMC Pre-test → Fail이면 원인분석/수정/재시험 → HW/FW freeze → 전파 적합성평가 및 필요한 EMC/KC 안전시험

## 인증 현재 상태
- BLE 전파 적합성평가: 필수 확인 대상
- EMC: 필수 준비
- 전기용품 KC: 품목분류 및 적용기준 확인 필요
- 내부 배터리: 없음
- 외부 AC adapter: 동봉/판매 시 별도 확인
- 영유아 안전 근거: 진동/소음/온도/고장정지/30분 자동정지/하드웨어 비상정지 등 별도 확보

## 지원사업
사업자등록이나 인증비 지출을 지원사업 때문에 먼저 서두르지 않는다. 모두의창업 사업화자금의 PCB/시제품/EMC/전파/KC/시험기관 기술컨설팅 집행 가능 여부를 먼저 확인한다. EMTI/RAPA 기술지원은 정식 적합성평가를 대체하지 않는다.

## 현재 미확정
- 최종 KC 품목분류
- KC 60335-1 적용 여부
- 정확한 전파 적합성평가 범위
- 정확한 EMC 시험항목
- 모두의창업 사업비 집행 가능 범위
- 예비창업자 EMTI 지원 가능 여부
- 특정 시험기관의 Fail 후 설계수정 지원 범위

## 최종 의사결정
지금은 장비 구매보다 설계 검토가 우선이다. 실제 시험에서 문제가 확인됐을 때 필요한 계측장비만 구매·대여한다.
