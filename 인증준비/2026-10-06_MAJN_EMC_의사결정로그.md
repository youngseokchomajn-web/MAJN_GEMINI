## 실패/보류 판단 로그

### 보류: 정확한 BOOST 새 좌표
L1/D3의 BOM/netlist 정의가 해결되지 않아 새 좌표는 아직 확정하지 않는다.

### 보류: EMC 인증 합격 여부
현재 분석은 설계 위험도 평가다. 공식 시험 결과가 없으므로 합격/불합격을 선언하지 않는다.

### 보류: 오실로스코프 필요 여부
현재는 선구매하지 않는다. 실제 ringing/ripple/switching issue가 확인될 경우 재평가한다.

### 보류: Spectrum Analyzer 필요 여부
현재는 선구매하지 않는다. Pre-test 결과를 보고 필요성을 판단한다.

## DEC-017 — L1/D3 mismatch 원인 1차 판정 업데이트

- SSOT: `인증준비/mcp_development/mcp_design_flow.json`
- SSOT version: `1.9.2`
- L1: `Boost Inductor 4.7uH`, LCSC `C78804`, package `SMD-5.0x5.0`
- D3: `Boost Schottky Diode 3A SS34`, LCSC `C8678`, package `SMA-DO-214AC`
- SSOT net:
  - L1 pin 1 = VBUS_5V
  - L1 pin 2 = BOOST_SW
  - D3 pin 1 = PVDD_12V
  - D3 pin 2 = BOOST_SW

### 판정

기존 `pcb_netlist_final.json`의 L1/D3 표기와 SSOT가 서로 다르다.

따라서 현재 단계에서는 **L1/D3의 실제 설계 부품을 다시 선정하는 것이 아니라, SSOT를 기준으로 schematic → PCB → BOM → PnP → netlist/제조 export의 정합성을 맞추는 작업**으로 정의한다.

### 상태

**P0 — 제작 전 필수 정합성 확인**

새 L1/D3 좌표를 임의로 확정하지 않는다. EasyEDA Pro의 실제 PCB master에서 현재 footprint와 부품 매핑을 확인한 뒤, SSOT와 일치시키고 재-export/재검증한다.

### 다음 행동

1. EasyEDA Pro `new start / Board1 / PCB1`에서 L1/D3 footprint와 properties 확인
2. L1 = C78804 / 4.7uH / SMD-5.0x5.0 확인
3. D3 = C8678 / SS34 / SMA-DO-214AC 확인
4. PCB → BOM/PnP/netlist export 재생성
5. SSOT와 다시 대조
6. 정합성 확보 후 MP3426 U3-L1-D3 placement/BOOST_SW loop 수정안 확정

> DEC-012/DEC-013의 취지는 유지하되, 문제를 '부품 자체 선정 오류'가 아니라 **산출물 간 데이터 정합성 문제**로 구체화한다.
