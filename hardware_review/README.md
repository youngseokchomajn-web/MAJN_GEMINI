# 마중 스마트 배시넷 하드웨어 및 회로 검토 패키지 가이드

본 디렉토리(`hardware_review/`)는 EasyEDA Pro 네이티브 바이너리(`.epro2`)의 분석 한계를 극복하고, AI 에이전트 및 하드웨어 엔지니어가 회로 결선, 넷리스트, BOM, 실측값, 인증 규격을 전수 교차 검증할 수 있도록 표준화된 형태로 구성된 마스터 패키지입니다.

## 2. PCB #0005 vs PCB Rev-C 핵심 변경 내역

| 구분 | 기존 PCB #0005 (검증 기준선) | 신규 PCB Rev-C (인증 & 센서 확장) | 변경 목적 및 효과 |
| :--- | :--- | :--- | :--- |
| **전원 보호** | USB-C 직결 (VBUS 5V) | **1.5A 리셋터블 PPTC 퓨즈 (`F1`)** 직렬 추가 | USB 과전류 및 단락 보호 (전기안전) |
| **승압 노이즈** | MP3426 SW 핀 단순 인덕터 결선 | **RC 스너버 패드 (`2.2Ω + 470pF`)** 예비 배치 | 900kHz 고조파 방사(RE) 10dB 이상 억제 |
| **오디오 출력** | TAS5805M BTL 직결 | **페라이트 비드 (`FB1~FB4`)** 노이즈 필터 | 익사이터 케이블(1~2m)의 안테나 방사 차단 |
| **생체 BCG** | 미지원 | **`J_BCG` (JST-SH 4P)**: GPIO36, 39 (ADC1) | 침대 매트리스 하부 PVDF 호흡/심박 감지 |
| **생체 레이더** | 미지원 | **`J_RADAR` (JST-SH 4P)**: GPIO16, 17 (UART2) | 60GHz/24GHz mmWave 비접촉 재실 감지 |
| **환경/울음** | 미지원 | **`J_ENV_MIC` (JST-SH 5P)**: I2C + GPIO32 (DIN) | 온습도 모니터링 + 아기 울음 AI 음향 분석 |
| **인증 방어** | - | **0Ω DNP 링크 저항군 (`R_L1 ~ R_L7`)** | 1차 KC인증 시 미실장으로 방사 노이즈 0건 |

## 3. 회로 및 넷리스트 검증 결론

1. **넷 무결성**: PCB #0005의 검증된 38개 넷(VBUS, VCC_3V3, PVDD_12V, I2C, I2S, SPI 등)을 일절 훼손하지 않고 100% 보존함.
2. **센서 확장 핀 충돌 제로**:
   - BCG 아날로그: Wi-Fi/BT와 충돌 없는 **ADC1 채널(GPIO36, 39)** 전용 할당.
   - 레이더 통신: USB 디버그와 분리된 **하드웨어 독립 UART2(GPIO16, 17)** 할당.
   - 마이크/온습도: 기존 TAS5805M I2C 버스(`0x2C`)와 주소 충돌 없는 SHT40(`0x44`) 공유 + 오디오 입력(GPIO32) 할당.
3. **규제 인증 최적화**: 0Ω 저항을 통해 단일 기판 아트워크로 **"기본형 인증(DNP)"**과 **"센서형 양산(Populate)"**을 동시 만족하여 인증 비용 500만 원 및 2개월 단축.
