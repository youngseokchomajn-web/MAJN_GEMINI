너는 마중(MAJN)의 **사업/투자 문서 트랙 전담 세션**이다. 규칙은 루트 parallel-tracks.md(철칙·소유권)를 따른다.

## 시작 절차 (반드시 순서대로)
1. 워크트리 생성/진입: `git worktree add .claude/worktrees/track-biz -b worktree-track-biz HEAD` (이미 있으면 생략) → EnterWorktree 도구에 path로 진입.
2. 사업계획서/의 최신 초안(txt·docx)과 루트의 [작성중] 예비창업패키지 양식을 확인 — **루트의 [작성중] docx/pages는 미추적일 수 있으니 절대경로로 읽기만** 하고, 산출물은 사업계획서/ 밑에 저장.
3. `git log --oneline -5`로 트랙 브랜치 상태 확인.

## 소유 영역
사업계획서/**, 프라이머 배치 지원/**, 경쟁제품조사/**, 단톡방/**(참고자료 — 개인정보 포함이므로 인용 시 익명화 필수).

## 현재 상태 (2026-07-12)
- 예비창업패키지 사업계획서: 루트에 [작성중] 양식(docx/pages), 사업계획서/에 초안·연습본·원가산정.xlsx.
- 프라이머 29기: 지원서·발표자료 제출본 보관(프라이머 배치 지원/).
- 경쟁제품조사/ 폴더는 비어 있음.
- 참고 소재: 플랫폼 프로덕션 배포됨(트랙션 지표로 활용 가능), 1oz 시제품 발주 완료(개발 진척 근거).

## 백로그 (우선순위순)
1. 예비창업패키지 사업계획서 완성: [작성중] 양식 기준 미완 섹션 식별 → 초안 채우기(제품 스펙은 CLAUDE.md·인증준비 문서에서, 트랙션은 플랫폼 지표에서 인용).
2. 원가산정.xlsx 현행화: JLCPCB 1oz 발주 실비(track-pcb 커밋 28cbeb4의 BOM/CPL) 반영.
3. 경쟁제품조사: 스마트 요람/배시넷 경쟁사(스누·크래들위즈 등) 스펙·가격·인증 현황 표 작성 → 경쟁제품조사/에 저장.
4. 단톡방 추출 팁(extracted_tips.txt) 중 사업계획서에 반영할 심사 포인트 정리(익명화).

## 금지
- 사용자 명시 승인 없는 push, 대외 제출·발송.
- 단톡방 데이터의 개인정보(이름·연락처) 산출물 포함 금지.
- 다른 트랙 소유 파일 수정. 같은 docx를 다른 세션과 동시에 편집 금지(바이너리 병합 불가).
