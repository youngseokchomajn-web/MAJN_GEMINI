# 📏 [마중 누쿠 패드] 프로토타입 실측 프로토콜 (Field Measurement Protocol v1.2)

> v1.2 (2026-08-04): v3.1 총높이 20mm(캐비티 12) 반영 — G1 ≤2.3mm, 구동 시작점 2.0N, G7(바터밍) 신설.
> v1.1 (2026-08-04): 보고서 v3 최종 확정 반영 — 코어 **450×250** 좌표계로 전면 갱신.

**목적**: CAE v3.1 시뮬레이션(코어 450×250×20mm / 4mm 자작합판 박스 + EVA 폼 보더, 2.0N 등가 → 상판 11.2μm)이 보증하지 못하는 3가지 — ①리브 보강 효과 ②매트리스 결합 전달률 ③실사용 안전(열·내구) — 를 실물 측정으로 판정하고, 앰프 구동 레벨(캘리브레이션 시작점 1.8N 등가)을 확정한다.

> 원칙: 시뮬 수치는 출발점이지 합격 근거가 아니다. **모든 합격/불합격 판정은 본 프로토콜의 실측값으로만 내린다.**

---

## 1. 시료 & 조건 매트릭스

| 축 | 조건 | 비고 |
|---|---|---|
| **프로토 시료** | A: 리브 없음(기준 설계) / B: 장변 리브 1~2개 | B 리브는 익사이터 4점 회피 배치, 동일 자작합판 4mm. 450 스팬은 휨 1.9mm 예측이라 리브 이득이 작을 수 있음 — A/B 차이가 미미하면 A 채택 |
| **매트리스** | M1: 조리원 표준 배시넷 매트리스 / M2: 가정용(두껍고 무른 것) | 전달률 범위의 양 끝 확보 |
| **하중 더미** | 0kg(무부하) / 3.5kg(신생아) / 15kg(24개월) | 쌀·물주머니 등 분포 하중, 중앙 배치 |
| **구동 파형** | SVS 5-Tone 임상 파형(기본) + 40Hz 순수 사인(교차검증용) | ESP32 펌웨어 실기 출력 |

전 조합 측정이 부담이면 최소 세트: **A/B × M1 × {0, 15kg}** (8케이스).

## 2. 장비

| 장비 | 용도 | 비고 |
|---|---|---|
| LSM6DSOX (보유 IMU) + ESP32 로거 | 가속도 실측(주 계측기) | ODR ≥833Hz, ±2g 레인지. 신호 ~0.07g로 노이즈플로어 대비 충분 |
| 스마트폰 진동측정 앱 | 교차검증(보조) | 절대값 신뢰 말고 상대비교용 |
| 비접촉 온도계/열화상 | 익사이터 직상 표면온도 | 30분 연속 구동 후 |
| 버니어캘리퍼스 + 직선자(450mm 이상) | 정적 휨 측정 | 상판 중앙 처짐 |
| 주방저울/체중계 | 더미 하중 검증 | — |

**센서 부착**: 3M VHB 또는 왁스로 강결합(테이프 느슨하면 고주파 감쇠). 케이블은 테이프로 고정해 케이블 공진 배제.

## 3. 측정 포인트 맵 (정규좌표, 코어 450×250 기준)

```
P1 중앙 (0.50, 0.50) = (225, 125)mm   ← 아기 등 위치, 합격판정 기준점
P2 익사이터 직상 (0.25, 0.25) = (112.5, 62.5)mm
P3 익사이터 사이 (0.50, 0.25) = (225, 62.5)mm
P4 모서리 근방 (0.10, 0.10) = (45, 25)mm   ← 최소 진폭 확인용
P5 매트리스 상면 중앙 (P1 수직 위)           ← ★전달률 측정의 핵심
P6 폼 보더 위 매트리스 상면 (코어 밖 1개소)  ← 코어 밖 전달 감쇠 확인(기록용)
```

각 포인트 30초 이상 기록, 3회 반복, 중앙값 채택.

## 4. 절차

### 4-1. 정적 강성 (시뮬 대조)
1. 패드를 평평한 바닥에 놓고 무부하 상판 높이 기준선 기록.
2. 15kg 더미 중앙 배치 → 5분 후 중앙 처짐 측정.
3. **판정**: A시료 ≤2.3mm(시뮬 예측 1.73mm의 +35% 허용). B시료는 A 대비 개선율 기록.
4. **G7 바터밍 확인**: 15kg 더미를 각 익사이터 직상(P2 등 4개소)으로 옮겨가며 가진 → 접촉음·진폭 급락 없어야 함(캐비티 12mm 설계 검증).

### 4-2. 패드 단독 SVS (시뮬 캘리브레이션 검증)
1. 매트리스 없이, 무부하, 볼륨을 시뮬 2.0N 등가 설정으로 구동.
2. P1~P4 가속도 기록 → 변위 환산(§6).
3. **판정**: P1에서 10.0~12.5μm. 벗어나면 볼륨을 조정해 인-밴드 진입 볼륨을 기록 — 이 값이 시뮬 대비 실물 보정계수가 된다.

### 4-3. 매트리스 전달률 (★핵심 게이트)
1. 매트리스 얹고 P5(매트리스 상면) + P1(패드 상판) 동시 또는 교대 측정.
2. 전달률 T = P5진폭 / P1진폭 산출 (M1, M2 각각, 0kg·15kg 각각).
3. 볼륨을 조정해 **P5에서 10.0~12.5μm** 진입 볼륨 탐색.
4. **판정**: 최대 볼륨(FW -0.6dB 캡, 채널당 2.0W)의 80% 이내에서 P5 인-밴드 달성 가능해야 합격. 불가 시 플랜B(익사이터 6개/3채널) 검토 트리거.

### 4-4. 열 안전 (IEC 60335-1)
1. 합격 볼륨의 120%로 30분 연속 구동(매트리스 덮은 상태 = 최악 방열 조건).
2. 익사이터 직상 상판 표면온도 측정.
3. **판정**: ≤48.0°C (여유 목표 ≤43°C). 초과 시 FW 캡 하향 또는 방열 설계 변경.

### 4-5. 리브 A/B 비교 종합
A/B 동일 조건 측정 후: 정적 휨 개선율, P1~P3 진폭 균일도(최대/최소 비), 인-밴드 볼륨 차이를 표로 정리 → **리브 채택 여부 결정**.

## 6. 데이터 처리 — 가속도→변위 환산

정상상태 사인 진동에서 변위 피크 $x = a / (2\pi f)^2$.

**40Hz 조견표** (피크 기준):

| 가속도 피크 | 변위 피크 |
|---|---|
| 0.064 g | 10.0 μm (밴드 하한) |
| 0.072 g | 11.2 μm (타겟) |
| 0.081 g | 12.5 μm (밴드 상한) |

- IMU 출력이 RMS면 피크 = RMS × √2 (사인 가정).
- SVS 5-Tone 파형은 성분별 주파수가 다르므로, 정밀 판정은 40Hz 순수 사인으로 하고 5-Tone은 상대 레벨 확인용으로 사용.
- 기록 양식: `시료(A/B) / 매트리스(–/M1/M2) / 하중(kg) / 포인트 / 볼륨(%) / a_peak(g) / x(μm) / 온도(°C) / 비고`, CSV 권장.

## 7. 결과 반영처

- 인-밴드 볼륨·전달률 T → **펌웨어 기본 볼륨 & FW 캡 확정**
- 리브 A/B 결론 → **재단 도면 확정** (리브 포함 여부)
- 시뮬 대비 보정계수 → `run_ai_optimizer.py` AMP_CAL 재캘리브레이션
- G3 불합격 시 → 플랜B: 익사이터 6개/3채널 재설계 검토
