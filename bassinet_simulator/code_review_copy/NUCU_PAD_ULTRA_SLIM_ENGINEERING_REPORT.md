# 📑 [마중 스마트 배시넷] 24개월(두돌) 초슬림 누쿠 패드(Nucu Pad) 구조 & 진동 파이프라인 검토 보고서

본 보고서는 **신생아부터 24개월(두돌, 15kg 아기 하중)**까지 사용할 수 있는 초슬림 누쿠 패드(Nucu Pad) 스타일 하우징 설계의 **검토 배경, 3D/물리 검토 내용, 2.5D 이방성 Mindlin 솔버 검토 방법, 및 최종 CNC 레이저 절단 주문 사양**을 총망라한 기술 문서입니다.

## 📌 1. 검토 배경 & 설계 요구조건 (Background & Requirements)

1. **사용 기간 및 하중**: 신생아($3.5\,\text{kg}$)부터 **두돌 24개월($15.0\,\text{kg}$ 탑승 하중)**까지 휨 변형이나 파괴 없이 안전하게 지지.
2. **초슬림 모듈화 (Externalized Electronics)**: 패드 내부에는 **TEAX14C02-8 초슬림 익사이터 4개(높이 $10.0\,\text{mm}$)만 매립**하고, ESP32 컨트롤러 PCB, 배터리, 파워 회로는 케이블로 외부 컨트롤 박스에 독립 분리.
3. **최소 높이 극대화 (Ultra-Slim Profile)**: 상판 4mm + 내부 익사이터 10mm + 하판 4mm = **총 두께 $18.0\,\text{mm}$** 초슬림 상자 하우징 구동.
4. **SVS 임상 가진 변폭 달성**: 40Hz 5-Tone 임상 파형 구동 시 영유아 수면 동기화 **$10.0 \sim 12.5\,\mu\text{m}$ 피크 미세진동 진폭** 달성.

## 🧮 3. 검토 방법 & 사용 솔버 (Methodology & Physics Solver)

### ① 2.5D 직교이방성 Mindlin 판 휨 솔버 (`c3d10_solver.js`)
자작합판의 나뭇결 방향($E_x = 9.15\,\text{GPa}$)과 수직 방향($E_y = 4.20\,\text{GPa}$) 휨 강성 텐서 $D_{ortho}$를 산출하여 마이크로 미세진동 진폭을 수치 해석했습니다.

$$D_{ortho} = \sqrt{D_x \cdot D_y} = \sqrt{\frac{E_x \cdot t^3}{12(1-\nu_{xy}\nu_{yx})} \cdot \frac{E_y \cdot t^3}{12(1-\nu_{xy}\nu_{yx})}}$$

### ② 3D 슬림 박스 쉘 결합 강성 보정계수 ($K_{box}$)
상판/하판 및 4면 측판이 꽉 물려있는 슬림 박스 구조($H = 18\,\text{mm}$)의 입체 강성 증대 효과를 계수화 적용했습니다.

$$K_{box} = 1.0 + 5.5 \times \left(\frac{H_{box}}{45.0}\right) \approx 3.20\text{x stiffness boost}$$

> **v2 교정 노트**: 구 720×390×45mm 하우징의 실험계수 $K_{box}=6.5$는 위 일반화식의 $H=45$ 특수해다. 웹 솔버(`fem_engine.js`)가 18mm 초슬림 전환 후에도 6.5 고정값을 사용해 강성을 약 2배 과대평가하고 있었으며, v2에서 높이 의존식으로 교정했다(높이 슬라이더 변경 시 `solve()`에서 자동 재산출).

### ③ ESP32 SVS 5-Tone 임상 가진 수식 연동
ESP32 펌웨어 실기기 $4\,\text{kHz}$ DAC 출력 수식을 시뮬레이터에 이식하여 실효 피크 포락선 진폭($w_{peak}$)을 동기화했습니다.

$$\text{SVS}(t) = \frac{1.0\sin(2\pi \cdot 30t) + 0.35\sin(2\pi \cdot 14.2t + 0.5) + 0.25\sin(2\pi \cdot 22.7t + 1.2) + 0.40\sin(2\pi \cdot 7.4t + 2.8) + 0.20\sin(2\pi \cdot 33.1t + 4.1)}{2.20}$$

## ⚖️ 6. 16mm vs 18mm 총두께 확정 비교 (2026-08-04, 18mm 최종 확정)

구 패드 물리설계(2026-07-22)의 **총두께 16mm 균일** 안과 본 보고서의 **18mm** 안이 충돌하여, v2 교정 모델로 정면 비교를 수행했다. 전제: TEAX14C02-8 실측고 $9.85\,\text{mm}$ → 내부 유효고 10mm 확보 조건에서 **16mm 안은 상하판 3mm 스킨이 강제**된다(4mm 스킨이면 내부 8mm뿐이라 매립 불가).

| 항목 (600×340 · 15kg) | **★A: 18mm / 4mm 스킨 (확정)** | B: 16mm / 3mm 스킨 | C: 16.5mm / 3mm 스킨 |
|---|---|---|---|
| 내부 유효고 | 10.0mm ✓ | 10.0mm ✓ | 10.5mm ✓ |
| $K_{box}$ (높이 의존) | **3.20** | 2.96 | 3.02 |
| 15kg 정적 휨 | **`4.4 mm`** | `11.3 mm` (2.6배 꿀렁임) | `11.1 mm` |
| Von Mises 응력 / 안전율 | **3.85 MPa / `SF 12.5x`** | 7.41 MPa / SF 6.5x | 7.26 MPa / SF 6.6x |
| 임상 밴드(10~12.5μm) 구동력 | **1.65~2.06 N (타겟 1.85N)** | 0.64~0.80 N | 0.66~0.82 N |
| 패드 총 무게 | 1,328 g | **1,024 g** | 1,026 g |

**확정 근거 (18mm / 4mm 스킨 채택)**:
1. **정적 휨 2.6배 차이** — 16mm 안의 11.3mm 꺼짐은 아기 위치별 꿀렁임 체감 + 상판 안쪽 VHB 부착 익사이터의 반복 휨 변형 → 접착 내구 열화.
2. **안전율 마진** — SF 6.5도 기준(>5.0)은 통과하나 정적·건조 조건 수치. 진동 피로·습기(합판 강도 저하)·국부 충격(무릎 찍기) 고려 시 12.5배 마진이 실사용 안전.
3. **16mm의 이득은 2mm 슬림·300g 경량뿐** — 매트리스 하부 매립 특성상 체감 무의미.

> 유의: 구동력 밴드 폭은 두 안 모두 ±11%로 앰프 볼륨 캘리브레이션 정밀도 요구 동일. 16mm의 낮은 절대 구동력(0.72N)은 전력상 유리해 보이나 "판이 얇아 쉽게 흔들린다"는 동전의 뒷면으로, 1번 문제와 같은 뿌리다.
