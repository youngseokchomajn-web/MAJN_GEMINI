# EasyEDA Pro 자동 설계 파이프라인 개발 규칙 (Workspace Rules)

이 프로젝트(`majn/인증준비/mcp_development`)에서 EasyEDA Pro와 파이썬 자동 설계 파이프라인을 이어서 개발하거나 개선할 때, 모든 AI 에이전트가 엄격하게 준수해야 할 개발 지침 및 행동 규칙입니다.

## 0. 답변 전 필수 점검 메모리 체크리스트 (답변 및 사고 전 무조건 복기)
모든 답변 및 계획 수립 전, 아래 6대 하드웨어/작업 환경 팩트를 반드시 먼저 훑고 사고를 전개하십시오:
1. **[물리 버튼 전무]**: PCB #0005번 시제품 보드에는 BOOT, EN 버튼이 일체 없습니다. 버튼 누름 가이드 금지!
2. **[시리얼 플래시 불가]**: CP2102 헤더는 TX, RX, GND만 연결되어 있어 DTR/RTS 리셋이 불가합니다. 유선(esptool) 다운로드는 불가능하며, 오직 무선 OTA(BLE OTA 또는 Wi-Fi HTTP /update)만 유효합니다.
3. **[경로 절대성]**: 사용자 터미널은 홈 디렉토리(`~`) 등 어디서든 열려 있을 수 있습니다. 상대 경로(`인증준비/...`) 절대 사용 금지, 반드시 절대 경로(`/Users/youngseok/Desktop/majn/...` 또는 `/tmp/...`)만 제시/실행하십시오.
4. **[네트워크 존중]**: 맥북 Wi-Fi(`en1`)를 사전 동의 없이 임의 변경하여 인터넷을 끊지 마십시오.
5. **[사실 기반 판단]**: 사용자가 보고한 내용만 있는 그대로 수용하고, 화면/상태를 임의로 왜곡·추측·환각하지 마십시오.
6. **[목공 케이스 최신본(4.5T)]**: 마중 배시넷 목공 케이스(해광레이저 가공)의 최신 기준 사양은 4.0T가 아니라 **4.5T 자작합판(외경 450×250×22.5mm, R20 코너, 캐비티 13.5mm, haptic 각인 반영)**입니다.

## 1. EasyEDA 에디터 및 브릿지 서버 제어 규칙
* **연동 구조 인지**: EasyEDA Pro 에디터(플러그인 `run-api-gateway` 장착)와 로컬 파이썬 클라이언트는 Node.js Bridge Server(포트 `49620`)를 통해 통신합니다.
* **서버 상태 검증**: EasyEDA API를 호출하기 전에 반드시 `http://localhost:49620/health`를 체크하여 브릿지 서버와 에디터 연결이 활성화되어 있는지 선제 확인해야 합니다.
* **JS 코드 실행**: 에디터 조작은 `easyeda_mcp_client.py`의 `execute_js()`를 통해 에디터 내부 JS 엔진으로 코드를 송신하여 수행합니다.

## 2. 설계 및 부품 배치 규칙
* **LCSC 라이브러리 캐시 갱신**: `place_component` API를 실행해 부품 배치 시 에러가 발생하는 경우, EasyEDA Pro 에디터 상에서 해당 LCSC ID 부품을 직접 검색(`Shift+F`)하여 에디터 로컬 캐시를 활성화하도록 사용자에게 명확히 안내해야 합니다.
* **동박(Copper Pour) 재구축 지침**: 배선 완료 또는 구조 변경 후 동박이 채워지지 않았거나 불완전해 보이는 현상이 있다면, 반드시 에디터 창에서 **`Shift + B`** 단축키를 눌러 동박을 강제 재구축(Rebuild)하도록 가이드하십시오.
* **저장 단축키 안내**: 에디터 API를 통한 자동 저장은 비정상 동작이 빈번하므로, 주요 변경 작업 완료 후 사용자에게 **`Cmd + S` / `Ctrl + S`**로 저장할 것을 상시 안내하십시오.

## 3. 검증(DRC) 및 내보내기 규칙
* **자가 검증 파이프라인**: 설계 변경이 발생하면 항상 `run_full_drc.py`를 실행하여 핀/트랙 클리어런스, 트랙 교차(Crossings), 그리고 에디터 내장 DRC 연동 결과를 확인하십시오.
* **거버 파일 출력**: 최종 PCB 사양이 완벽히 검증되면 `run_export_gerber.py` 스크립트를 구동하여 `Gerber_Output.zip` 파일을 루트 폴더에 정상 생성해 제공해야 합니다.

## 4. 펌웨어 배포 및 OTA 전자동 실행 규칙 (절대 준수)
* **보드 하드웨어 제약 인지 (물리 버튼 없음)**:
  - 현재 시제품(PCB #0005) 보드에는 **물리 버튼(BOOT, EN)이 일체 존재하지 않습니다.**
  - CP2102 헤더는 TX, RX, GND만 결선되어 있어 **DTR/RTS 자동 부트로더 리셋 회로가 없습니다.**
  - 따라서 유선 시리얼(esptool) 업로드는 하드웨어적으로 불가능하며, **오직 무선 OTA(BLE OTA 또는 Wi-Fi HTTP /update)로만 플래시가 가능**합니다.
  - 사용자에게 "버튼을 누르라"거나 "시리얼 포트로 다운로드하라"는 가이드를 절대 하지 마십시오.
* **명령어 및 파일 경로 절대 경로 원칙**:
  - 사용자 터미널은 홈 폴더(`~`) 등 어디서든 열려 있을 수 있습니다.
  - 명령어를 제시하거나 실행할 때는 **절대로 프로젝트 상대 경로(`인증준비/...`)를 쓰지 말고, 반드시 절대 경로(`/Users/youngseok/Desktop/majn/...`)를 사용**하십시오.
* **사용자 수동 조작 요청 금지 & 와이파이 임의 탈취 금지**:
  - 사용자의 맥북 Wi-Fi를 임의로 끊거나 무단 변경하지 마십시오.
  - 사용자의 실제 보고 내용을 왜곡하거나 임의로 단정(예: 폰 화면에 떴다는 등)하지 마십시오.
  - 펌웨어 배포 시 사용자가 최소한의 액션(허용 1회)만 취하면 에이전트가 백그라운드에서 전자동으로 처리하십시오.
