# 마중(Majn) MicroTac Stimulation Module: 안전인증 로드맵

> **작성일**: 2026-05-11 (v2 — 제품 범위 수정 반영)
> **제품 정의**: 기존 산후조리원 배시넷에 C-클램프로 **부착**하는 독립형 진동 모듈
> **제품이 아닌 것**: 배시넷 자체 (침대 본체를 제조하지 않음)

---

## 🔑 핵심 결론

마중 MicroTac 모듈은 **배시넷이 아닌 '전자 진동 장치'**입니다.
따라서 유아용 침대(부속서 14) 관련 구조 시험(끼임, 추락, 경사각 등)은 **전부 해당 없음**.

**필수 인증은 2건**, 추가 확인 1건입니다.

| # | 인증 | 필요 여부 | 근거 |
|---|------|-----------|------|
| ① | **KC 안전확인 (전기용품)** | ✅ 필수 | VCA 모터 + 외부 전원 사용 전자기기 |
| ② | **전자파 적합등록 (EMC)** | ✅ 필수 | ESP32 Wi-Fi/BLE 무선 통신 내장 |
| ③ | **어린이제품 안전확인** | ❓ 확인 필요 | 영유아 근접 사용 기기 → 시험기관 유권해석 필요 |
| ④ | KC 안전확인 (유아용 침대) | ❌ 해당 없음 | 배시넷을 제조하지 않음 |
| ⑤ | ASTM F2194 (미국 배시넷) | ❌ 해당 없음 | 배시넷이 아님 |
| ⑥ | FDA De Novo | ❌ 현 단계 불필요 | 국내 B2B 우선 |

## 📌 인증별 상세 가이드

### ① KC 안전확인 — 전기용품 (전동 진동 장치) ✅ 필수

**법적 근거**: 「전기용품 및 생활용품 안전관리법」

**제품 분류**: 전동 마사지기 또는 전동 진동기 유사 품목

**핵심 시험 항목**:
| 시험 분류 | 세부 항목 | 마중 MicroTac 대응 |
|-----------|-----------|---------------------|
| 감전 보호 | 절연 저항, 내전압 | DC 전원(어댑터) 사용, 접촉전압 ≤24V 설계 |
| 과열 방지 | 모터/앰프 온도 상승 | Wondom JAB3 방열 설계, 과열 시 자동 차단 |
| 기계적 안전 | C-클램프 체결 강도, 낙하 | 클램프 잠금 메커니즘 + 안전 와이어 |
| 비정상 동작 | 단락/과부하 보호 | ESP32 Watchdog + 퓨즈 |
| 배터리 | (배터리 사용 시) UN38.3 | 외부 어댑터 사용 시 해당 없음 |

**예상 비용**: 150~300만원
**예상 기간**: 3~6주

---

### ② 전자파 적합등록 (EMC) ✅ 필수

**법적 근거**: 「전파법」 제58조의2

**적용 이유**: ESP32 모듈의 Wi-Fi(2.4GHz) + BLE(2.4GHz) 송수신 기능

**핵심 시험 항목**:
| 시험 분류 | 세부 항목 |
|-----------|-----------|
| EMI (방출) | 전도 방출, 복사 방출 (다른 기기 방해 여부) |
| EMS (내성) | 정전기(ESD), 서지, 전도 내성 (외부 간섭 내성) |
| RF (무선) | Wi-Fi/BLE 출력, 대역폭, 스퓨리어스 |

> **💡 비용 절감 팁**: ESP32-WROOM-32E 등 FCC/CE **사전인증 모듈**을 사용하면, 모듈 자체의 RF 시험을 생략하고 완제품 EMI/EMS 시험만 진행하여 비용과 기간을 대폭 줄일 수 있습니다.

**예상 비용**: 100~200만원
**예상 기간**: 2~4주

---

### ③ 어린이제품 안전확인 ❓ 유권해석 필요

**쟁점**: 마중 MicroTac은 배시넷이 아니지만, **영유아가 누워 있는 침대에 직접 부착하여 진동을 전달하는 기기**입니다.

| 해석 A (해당 없음) | 해석 B (해당) |
|---------------------|----------------|
| 모듈은 영아가 직접 접촉하지 않음 (매트리스 아래) | 영유아 용도 전자기기 → 어린이제품 적용 가능 |
| 배시넷 프레임 외부에 클램프 체결 | 유해물질(납, 프탈레이트) 시험 필요 가능 |

**→ 시험기관(KTR)에 사전 상담 시 반드시 물어볼 질문:**
> "기존 유아용 침대의 프레임 외부에 C-클램프로 부착하는 전동 진동 모듈인데, 어린이제품 안전 특별법상 안전확인 대상에 해당하나요?"

## 🛡️ 제품 특성상 추가로 준비할 안전 요소

배시넷 인증은 불필요하지만, **B2B 고객(산후조리원)의 신뢰 확보**와 **제조물 책임(PL)법 대응**을 위해 자발적으로 준비해야 할 항목들:

### 기계적 안전 (C-클램프 체결)
| 위험 시나리오 | 대응 설계 |
|--------------|-----------|
| 클램프 풀림 → 모듈 낙하 | 이중 잠금(래치 + 안전 와이어/스트랩) |
| 과도한 진동 → 배시넷 이동 | ADXL355 이상 진동 감지 → 자동 정지 |
| 영아 접촉 | 모듈은 매트리스 하단/프레임 외부 → 물리적 접촉 불가 설계 |

### 소음 안전 (AAP 기준)
| 항목 | 기준 | 마중 설계 목표 |
|------|------|---------------|
| 구동 시 소음 | AAP 권고 ≤50dBA | 설계도 기재: <50dB ✅ |
| 측정 위치 | 영아 귀 위치 (30cm) | 시제품 완성 후 자체 계측 |

### 진동 안전 (자체 계측 보고서)
| 항목 | 내용 |
|------|------|
| 최대 변위 | 20μm 이하 (설계도 기재) |
| 과진동 차단 | ADXL355 폐루프 → 임계치 초과 시 즉시 정지 |
| 근거 논문 | Smith et al. 2015 (Pediatrics) — 미숙아 RCT 부작용 없음 |

## 📦 체크리스트 (수정)

### 🔴 설계 단계 (지금)
- [ ] C-클램프 이중 잠금 메커니즘 설계 (래치 + 안전 와이어)
- [ ] 전원부: DC 어댑터 사용, 접촉 가능 전압 ≤24V
- [ ] ESP32 모듈: FCC/CE 사전인증 모듈(ESP32-WROOM-32E) 채택
- [ ] ADXL355 과진동 차단 임계치 설정 (변위 >20μm → 즉시 정지)
- [ ] 외장 케이스: 방열 + 방수(IPX1 이상) 고려

### 🟡 시제품 완성 시
- [ ] 자체 소음 계측 (영아 귀 위치 30cm 기준, 50dBA 이하 확인)
- [ ] 자체 진동 변위 계측 보고서 작성 (ADXL355 로그 데이터 활용)
- [ ] BOM(부품 목록) + 회로도 + 조립도 정리
- [ ] 사용 설명서 초안 (한글 경고문 포함)
- [ ] 시제품 3~5대 확보 (시험기관 제출용)

### 🟢 시험 의뢰 전
- [ ] KTR 사전 상담: "배시넷 부착형 전동 진동 모듈" 인증 범위 확인
- [ ] 통합 견적 수령 (전기용품 + EMC)
