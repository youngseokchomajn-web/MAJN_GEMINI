### 조사 항목

| 항목 | 근거 방향 | 우선순위 |
|------|-----------|----------|
| 국내 간호인력 부족 심화 추이 | 구인난 정량화 | 🔴 |
| AI 엣지 디바이스 비용 하락 | 기술 성숙 타이밍 | 🟡 |
| 글로벌 스마트 베시넷 시장 성장 | 수요 검증 | 🟡 |
| 경쟁사 전원 한국 미진출 | 공백 시장 근거 | 🔴 |
| 저출생 대응 정책 → 산후조리 지원 확대 | 정책 우호성 | 🟡 |

### 실제 조사 방법

**① 간호인력 부족 데이터**
- 보건복지부 보건의료인력 실태조사 (최신)
- KOSIS: "간호조무사 취업률", "산후조리원 인력 부족" 검색
- 워크넷 산후조리원 야간 채용 공고 수 연도별 추이 확인

**② 정부 정책 우호성**
- 검색: "저출생 대응 산후조리 지원 2025 2026"
- 저출산고령사회위원회 (https://www.betterfuture.go.kr) 정책 자료

**③ Why Now 논리 완성 (자체)**
```
기술 준비됨 (AI 엣지 + VCA 저비용화)
    +
인력 위기 심화 (구인난 정량 데이터)
    +
공백 시장 (글로벌 경쟁사 전무)
    +
정책 우호 (정부 산모 지원 확대)
= 지금 진입해야 하는 이유
```

**Output**: Why Now 슬라이드 1장 (불릿 4개 + 수치 근거)

**① 보건복지부 산후조리원 실태조사**
- URL: https://www.mohw.go.kr → 정보 → 통계 → "산후조리원 실태조사"
- 대안: https://www.index.go.kr → "산후조리원" 검색

**③ TAM / SAM / SOM 계산식**
```
TAM: 국내 연간 출생아 수 × 산후조리원 이용률
SAM: 국내 산후조리원 총 객실 수 × 마중 월 단가 × 12
SOM(1년차): 수도권 중대형(30실↑) × 평균 객실 수 × 월 단가 × 12
```

## 3. 고객 문제 정량화 (Pain Point)

> ⚠️ **이 섹션이 전체 사업성 근거의 핵심. 1차 자료 없으면 설득력 없음**

### 조사 항목

| 항목 | 자료 유형 | 우선순위 |
|------|-----------|----------|
| 야간 법정 인력 기준 vs 실제 운영 인력 | 2차+1차 | 🔴 |
| 산후조리원 운영원가 중 인건비 비중 | 2차+1차 | 🔴 |
| 야간 간호인력 이직률 / 구인난 수준 | 2차 | 🟡 |
| 신생아 야간 울음 빈도 / 간호사 대응 횟수 | 1차 (인터뷰) | 🔴 |
| 보호자 불만 VOC 중 수면 관련 비중 | 2차 (리뷰) | 🟡 |
| 수면 불량 신생아 비율 | 2차 (문헌) | 🟢 |

### 실제 조사 방법

**① 법정 인력 기준**
- URL: https://www.law.go.kr → "모자보건법 시행규칙" → 별표
- 추출: 야간 최소 인력 기준 (객실 수 대비)

**② 구인난 정량화**
- 워크넷 (https://www.work.go.kr): "산후조리원 간호" 공고 수 조회
- 사람인 / 잡코리아: "산후조리원 야간" 공고 수 및 평균 채용 소요 기간
- 대한간호조무사협회 통계 자료 확인

**③ 현장 인터뷰 — 목표 5곳 이상 (서울 3 + 지방 2)**

*접근 방법:*
- 네이버 지도 "산후조리원" 검색 → 전화 직접 문의
- 한국산후조리협회 회원사 소개 요청

*인터뷰 가이드 (30분)*
```
[오프닝 — 5분]
- 시설 규모 (객실 수, 야간 신생아실 구조)
- 야간 근무 인력 편성 현황

[Pain 확인 — 15분]
Q1. 야간에 신생아 울음으로 대응하는 빈도가 어느 정도인가요?
    (시간당 몇 회, 한 명이 몇 명 담당)
Q2. 야간 인력 한 명이 담당하기 어려운 상황이 생기나요?
    어떤 경우에 문제가 생기나요?
Q3. 야간 인력 채용에 어려움이 있나요?
    (공고 후 평균 채용 기간, 이직률)
Q4. 인건비가 전체 운영비에서 차지하는 비중이 어느 정도인가요?
Q5. 보호자 불만 중 신생아 수면/야간 대응 관련 내용이 있나요?

[니즈 확인 — 8분]
Q6. 신생아 수면을 보조하는 기기(SNOO 등)를 들어보셨나요?
Q7. 도입 의향이 있다면 어떤 조건이 필요한가요?
    (가격, 안전 인증, A/S, 설치 방식)
Q8. 의사결정을 누가 하시나요? (원장 직접 / 이사회 / 기타)

[클로징 — 2분]
Q9. 4~8주 무상 파일럿 테스트에 관심이 있으신가요?
```

**④ VOC 분석**
- 네이버 지도 / 카카오맵 산후조리원 리뷰 100개 이상 수집
- 키워드: "밤", "울음", "잠", "수면", "간호사", "불편"
- 수면 관련 불만 비중 집계

**Output**: Pain Point 요약 1페이지 (정량 수치 3개 + 인터뷰 인사이트 3개)

- 부품별 단가 × 수량 집계
  - Wondom JAB3, ESP32, ADXL355, 스피커, 인클로저, PCB 등
- 양산 시 원가 절감 시나리오: 100대 / 500대 / 1,000대

**② 판가 설정 근거**
- 상한선: SNOO $1,695 월 렌탈 역산 (~$50~70/월)
- 하한선: 인터뷰에서 확인한 도입 가능 가격대
- 목표: 산후조리원이 **4~6개월 내 ROI 달성** 가능한 가격

**③ 산후조리원 ROI 모델**
```
[입력값 — 인터뷰로 수집]
- 야간 추가 인력 절약 시간: X시간/일
- 야간 간호조무사 시급: Y원
- 월 가동 일수: 30일

[계산]
월 절감액 = X × Y × 30
ROI 회수 기간 = 초기 설치비 ÷ 월 순절감액
도입 타당: 월 렌탈료 < 월 절감액
```

**④ 3년 매출 시나리오**

| 구분 | 보수 | 중립 | 낙관 |
|------|------|------|------|
| 1년차 도입 시설 | 5 | 15 | 30 |
| 2년차 도입 시설 | 15 | 50 | 120 |
| 3년차 도입 시설 | 40 | 150 | 400 |
| 시설당 평균 객실 | 20실 | 25실 | 30실 |
| 월 단가(렌탈) | 5만원 | 6만원 | 7만원 |

**⑤ 유사 기기 단가 참고**
- 신생아 보육기 렌탈가: 병원 납품 업체 견적 요청
- 산후조리원 도입 기기(마사지베드 등) 단가: 인터뷰 시 함께 질문
