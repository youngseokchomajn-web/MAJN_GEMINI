## 1. 지금 무엇을 할 수 있고, 무엇은 아직 못 하는가

현재 레포의 증거만으로는 실제 MAJUNG prototype의 접촉면 진동 출력이 측정됐다고 볼 수 없다. 따라서 임상연구자에게 수치가 확정된 stimulation specification을 보내거나, 효능·안전성을 암시하는 결과를 제시하면 안 된다.

지금 가능한 일은 아래 세 가지다.

1. 실물 prototype과 현재 구성을 사진·부품·펌웨어 버전으로 고정한다.
2. 외부 센서로 ON/OFF 출력이 구분되는지 확인하고 원시 데이터를 남긴다.
3. 출력 데이터가 확보되기 전에도 연구자에게는 '효능 검증 전 단계이며, 연구질문·endpoint·안전성 검토를 함께 논의하고 싶다'는 범위로 접촉한다.

이 문서는 측정 결과를 만들어내는 문서가 아니라, 실제 측정이 시작되면 같은 절차로 재현하고 자료 누락을 줄이기 위한 실행 패키지다.

## 3. 최소 벤치 시험 순서

### M0 — 센서·환경 baseline
- 장치를 OFF로 두고 센서 영점과 방향을 확인한다.
- 주변 진동을 기록한다. 바닥, 책상, HVAC, 케이블 접촉 등 가능한 외부 진동원을 메모한다.
- 센서가 매트리스 표면에 단단히 고정됐는지 확인한다.
- 센서 보드·케이블 자체가 흔들리는 현상이 없는지 확인한다.

### M1 — ON/OFF detectability
- 조건을 바꾸지 않고 OFF → ON → steady → OFF 순서로 기록한다.
- 각 반복의 OFF 구간, 명령 ON 시점, 측정상 진동 시작, 명령 OFF 시점, 측정상 감쇠 종료를 timestamp로 남긴다.
- 동일 조건에서 최소 3회 반복한다.
- ON/OFF 신호가 분명히 분리되지 않으면 분석을 진행하기 전에 고정·샘플링·센서 범위·주변 진동을 점검한다.

### M2 — 공간 분포
접촉면의 P1 중심, P2/P3 종방향 ±25%, P4/P5 횡방향 ±25% 위치를 사용한다. 위치마다 센서 고정법과 축 방향을 같게 유지한다. 매트리스 형상 때문에 좌표를 그대로 적용할 수 없으면 사진과 치수로 실제 위치를 정의한다.

### M3 — 하중·침구 영향
무하중, 의도된 침구만, 대표 분포하중, 보수적 분포하중 조건을 구분한다. 임의의 더미 하중을 실제 영아 하중이나 안전성 대리 지표로 표현하지 않는다. 사용 하중과 배치는 시험 목적에 맞게 별도 기록하고, 임상연구자가 정한 안전 검토 없이 영아를 대상으로 시험하지 않는다.

### M4 — 소음·온도
가능하면 접촉면과 구분된 머리 위치 상당 지점에서 음향을 기록한다. 교정되지 않은 휴대전화 앱의 dB 수치는 정밀 음압 레벨로 취급하지 않는다. 장치·매트리스의 온도 변화도 별도로 기록한다. 이 시험은 임상 안전성 평가를 대체하지 않는다.

## 4. 원시 데이터 파일 규칙

원본 CSV는 수정하지 않고 보존한다. 분석용 파일은 별도로 만든다.

권장 파일명:
- `M1_<시험ID>_<조건>_rep01_raw.csv`
- `M1_<시험ID>_<조건>_rep01_events.csv`
- `M1_<시험ID>_setup_photos/`
- `M1_<시험ID>_analysis.ipynb` 또는 분석 스크립트

### 센서 원시 CSV 필드
| 필드 | 설명 |
|---|---|
| `timestamp_s` | 시험 시작 기준 단조 증가 시간(초) |
| `accel_x`, `accel_y`, `accel_z` | 센서 원시 축 값 또는 변환된 가속도. 단위 필수 |
| `unit` | 예: m/s^2 또는 g |
| `device_state` | OFF / ON / TRANSITION. command 기록과 구분 |
| `load_condition` | L0 / L1 / L2 / L3 |
| `position` | P1 / P2 / P3 / P4 / P5 |
| `repeat` | 반복 번호 |
| `notes` | 이탈·충격·케이블 접촉 등 |

시간 열은 장치 command의 타임스탬프와 맞출 수 있도록 정의한다. 시간 동기화 방법과 sampling rate를 별도 메타데이터에 기록한다. 누락값을 0으로 대체하지 않는다.

### 이벤트 CSV 필드
`event_id, timestamp_s, event_type, source, notes`

필수 event_type 후보:
- `recording_start`
- `command_on`
- `measured_onset`
- `steady_state`
- `command_off`
- `measured_decay_end`
- `sensor_repositioned`
- `load_changed`
- `test_interrupted`

`command_on`과 `measured_onset`은 서로 다른 사건이다. 두 값을 동일한 시각으로 간주하지 않는다.

## 5. 최초 분석 산출물

M1의 목적은 진동의 유익함을 증명하는 게 아니라, 장치 출력이 실제로 존재하고 반복 측정 가능한지 확인하는 것이다.

필수 산출물:
1. 시험 구성 사진 및 메타데이터
2. 원본 CSV와 체크섬 또는 버전 기록
3. 3축 시간 파형(OFF/ON 구간 표시)
4. 주파수 스펙트럼 또는 PSD와 분석 설정
5. ON/OFF 구간의 RMS·peak 요약(단위·필터·구간 정의 포함)
6. 반복 간 변동 요약
7. 측정 한계와 제외 데이터 사유
8. E0/E1 통과·보류·실패 판정

가속도에서 변위를 추정할 경우 단일 주파수 가정이 적절한지 검토하고, 필터·적분·주파수 대역을 기록한다. 계산된 변위를 직접 측정한 변위와 동일시하지 않는다. 센서의 대역폭·노이즈·교정 상태가 불명확하면 그 제한을 명시한다.

## 6. E0/E1 판정표

| Gate | 질문 | 통과에 필요한 관찰 | 실패·보류 시 |
|---|---|---|---|
| E0 Detectability | ON/OFF가 데이터에서 구분되는가? | 주변 진동 baseline과 구분 가능한 반복 패턴 | 센서·고정·샘플링·주변 진동 점검 |
| E1 Repeatability | 같은 조건에서 반복 가능한가? | 사전 정의한 지표가 반복 간 안정적이고 이탈 사유가 기록됨 | 반복 횟수·고정·구동 조건을 재검토 |
| E2 Load | 하중에 따라 출력이 달라지는가? | 조건별 변화가 정량화되고 조건이 재현됨 | 하중·침구 조건을 재정의 |
| E3 Spatial | 위치별 출력이 어떤가? | 위치·축 방향·고정법이 기록된 비교 | 좌표 및 고정법 표준화 |
| E4 Acoustic/thermal | 소음·온도 변화가 있는가? | 측정 위치·장비 한계가 명시된 기록 | 측정 장비 또는 방법 보완 |
| E5 Freeze | 설정이 재현 가능한가? | hardware/firmware/매트리스/침구/센서 설정 동결 | 구성 문서화 후 재측정 |

수치 합격 한계는 근거 없이 임의로 정하지 않는다. 연구 목적·센서 성능·위험 분석과 연결해 사전에 정의한다.

## 7. 의료연구자에게 전달할 자료 패키지

### 출력 측정 전 최초 접촉
- 1페이지 제품/개발 개요
- 기존 문헌의 직접성 및 한계 요약
- 연구 질문 후보: 표준 돌봄을 유지하면서 진동 추가가 단기 settling 또는 fussing/crying resolution에 영향을 주는지
- 현재는 실제 출력 측정 전이며 효능·안전성 주장을 하지 않는다는 명시
- 자문 요청: 적절한 대상군, endpoint, 행동 코딩, 안전성/IRB 검토 경로

### E0/E1 이후 업데이트
위 자료에 아래 항목을 추가한다.
- 장치 구성 및 시험 조건
- 접촉면 실제 출력 파형과 주파수 분석
- 반복성 결과와 불확실성
- 센서·분석 방법 및 한계
- 아직 검증되지 않은 안전성 항목
- 의료연구자가 결정해야 할 항목 목록

**연구자에게 출력 수치가 없다는 사실을 숨기지 않는다.** 초기 접촉은 가능하지만, 임상 프로토콜 확정이나 영아 노출 시험을 서두르지 않는다.

## 8. 연구 질문과 안전 경계

권장 RQ-01:
> 적절한 표준 돌봄을 유지한 상태에서 MAJUNG의 실제 측정된 진동 자극을 추가했을 때, 사전에 정의된 관찰 구간에서 settling time 또는 fussing/crying resolution이 비교 조건과 다른가?

단, 이 질문은 연구자와 함께 다듬을 초안이며 승인된 임상 프로토콜이 아니다.

- 수유, 통증, 질병, 기저귀, 체온 등 영아의 필요 대응을 측정을 위해 지연하지 않는다.
- 진동을 보호자 돌봄의 대체물로 취급하지 않는다.
- 장치 출력의 재현성은 임상 안전성이나 효능의 증거가 아니다.
- 사람 대상 연구는 적절한 임상 책임자와 윤리·IRB 검토를 거친다.
- 영아에게 실제로 노출하기 전에 위험 분석과 제품의 intended use를 명확히 한다.

## 9. 다음 행동의 우선순위

1. 실제 prototype, actuator, 매트리스, 침구, 펌웨어 버전을 확인해 Gate 0 표를 채운다.
2. 현재 사용할 수 있는 센서와 logger가 무엇인지 확정한다. 내부 IMU가 있다고 가정하지 않는다.
3. M0/M1을 실행하고 raw CSV 및 사진을 보존한다.
4. E0/E1 결과를 근거로 다음 측정으로 갈지, 셋업을 수정할지 결정한다.
5. 동시에 임상연구자에게는 효능 주장이 아닌 연구설계 자문 요청을 보낸다.
6. 출력 데이터가 생기면 본 문서의 체크리스트와 기존 연구 brief를 갱신한다.

## 10. 이번 문서에서 확정하지 않은 것

- MAJUNG의 실제 진동 주파수·변위·가속도
- 허용 가능한 영아 노출량
- 제품의 임상적 안전성 또는 효능
- 임상연구의 표본 수·무작위화·중단 기준
- 규제상 제품 분류 또는 마케팅 Claim

이 항목들은 실측 자료와 적절한 전문가·규제 검토 없이 확정하지 않는다.
