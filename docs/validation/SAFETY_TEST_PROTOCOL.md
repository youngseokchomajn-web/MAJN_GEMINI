# MAJN 안전성 검증 시험 프로토콜 (SAFETY TEST PROTOCOL)

> **과제 ID**: D-03 (안전성 시험)  
> **시험 목적**: 기동/정지 충격, 장시간 연속 발열, 전기/기구적 고장 발생 시 시스템이 즉각 안전 정지하고 위험을 원천 격리하는지 실측 검증  
> **기준 커밋**: `c63e60a`  

---

## 1. 안전성 검증의 대원칙

> [!WARNING] **영아 안전 절대 원칙**
> 자동 소프트웨어 테스트 통과가 실제 영아에 대한 물리적 안전성을 보증하지 않습니다.  
> 실제 하드웨어 고장 시 출력이 100% 안전하게 차단되는지 오실로스코프로 물리적 입증을 완료하기 전까지, 어떠한 경우에도 영아 실물 적용을 시도하거나 허용해서는 안 됩니다. 또한 모든 진동 한계치는 소아과/신생아 전문의와의 공식 연구 협의를 거쳐 확정해야 합니다.

---

## 2. 세부 안전 시험 항목

### Safety-01. 과도 진동(Transient Jerk) 및 팝노이즈 차단 시험
- **위험 요소**: 전원 투입(Power-on), 시작(START), 정지(STOP), 비상 정지(ESTOP) 순간의 급격한 변위 충격으로 인한 영아 놀람 반사(Moro reflex) 및 두부 충격.
- **시험 방법**:
  1. 매트리스 P1(중앙) 및 P2(머리)에 고속 가속도계 설치 (샘플링 2,000Hz).
  2. 전원 인가 순간, START 명령 시(소프트 스타트), STOP 명령 시(램프다운 감쇄), E-STOP(즉시 차단) 시의 가속도 파형 계측.
- **합격 기준**:
  - 전원 투입 순간 가속도 피크 < $0.02 m/s^2$ (STANDBY Hi-Z 무음 팝 억제).
  - START 시 램프업 가속도 기울기 $\frac{da}{dt} < 0.5 m/s^3$ (급격한 충격 없음).
  - STOP 시 20ms당 0.005f 감쇄 곡선 추종 확인.

### Safety-02. 장시간 연속 구동 발열 한계 시험
- **위험 요소**: 앰프/승압기 과열로 인한 목재 하우징 온도 상승(저온 화상 위험) 및 부품 수명 저하.
- **시험 조건**: 최대 허용 진폭(0.50), 주파수 40Hz로 60분간 밀폐 구동.
- **합격 기준**:
  - 아기 접촉면(매트리스 상부 및 목재 프레임 외피) 온도 < 38.0°C (체온 수준 유지).
  - TAS5805M 다이 온도 < 85°C (실리콘 내구 한계 이내).

### Safety-03. 고장 주입 시험 (Fault Injection Testing)
- **위험 요소**: 코일 쇼트, 커넥터 이탈, I2C 버스 멈춤 시 출력 폭주 위험.
- **시험 시나리오**:

| 시나리오 | 주입 방법 | 기대 동작 | 합격 기준 | 판정 |
|---|---|---|---|:---:|
| **F-01 (출력 단락)** | 채널 A 스피커 단자 금속 단락 | TAS5805M 하드웨어 OCP 트립 $\rightarrow$ `FAULT#` 로우 $\rightarrow$ E-STOP | 즉시 출력 0V, 전원 셧다운, FAULT 래칭 | [ ] |
| **F-02 (진동자 단선)** | 구동 중 J1 커넥터 강제 발거 | 비정상 부하 감지 또는 정상 차단 | 앰프 발진 없음, 타 채널 간섭 없음 | [ ] |
| **F-03 (I2C 통신선 단선)**| 구동 중 SDA 또는 SCL 핀 분리 | 100ms Supervisor의 통신 타임아웃 감지 | 즉시 비상 정지 발동 및 `AMP_FAULT` 래칭 | [ ] |
| **F-04 (PVDD 저전압)** | 12V PVDD를 7.0V로 강제 강하 | TAS5805M UVLO(저전압 차단) 동작 | 이상 잡음 없이 출력 차단 | [ ] |
| **F-05 (OTW 과열 유발)**| TAS5805M 방열판 135°C 가열 | 100ms Supervisor OTW 감지 | 즉시 진동 출력 50% 강제 디레이팅 | [ ] |

### Safety-04. 전원 차단 및 복구 시험 (Power Loss Recovery)
- **위험 요소**: 진동 동작 도중 또는 무선 OTA 진행 도중 전원이 끊겼을 때의 시스템 상태 및 안전 복구.
- **시험 시나리오**:
  1. **구동 중 전원 차단**: 40Hz 구동 중 USB 케이블 분리 후 재연결 시, 자동으로 진동이 켜지지 않고 반드시 안전 `READY` 상태로 대기하는지 확인 (자율 기동 방지).
  2. **OTA 중 전원 차단**: 펌웨어 전송 50% 시점에서 전원 차단 후 재인가 시, 기존 정상 슬롯으로 롤백되어 부팅되고 SoftAP/BLE가 정상 회복되는지 확인.

### Safety-05. 기구 및 전기 절연 안전성 시험
- **외피 감전 방지**: USB 5V VBUS 라인과 외곽 나사 및 목재 체결부 간 절연 저항 > 10 MΩ (DC 500V 메거 시험).
- **진동자 이탈 방지**: 진동자 4개에 2.0 kgf 수직 인장력 인가 시 접착면 박리 없을 것.
- **케이블 보호**: 하우징 배선 관통홀 ⌀5.5mm 부위에 실리콘 그로밋 장착 상태 확인 (케이블 피복 마모 방지).

## 3. 소아과·신생아 전문 자문 절차

1. **사전 자문 안건 구성**:
   - 매트리스 상부 5개 지점 진동 계측 데이터(가속도, 주파수, 충격량).
   - 문헌 기반 안전 한계선 (Smith 2015, Salisbury 2009/2023 연구의 진동 가속도 $0.05 \sim 0.2 m/s^2$ 범위 비교).
2. **협의 대상**: UNIST 바이오메디컬공학과 연구팀 및 협력 소아청소년과 전문의.
3. **자문 결과 확정**: 임상 연구 및 시제품 사용 승인 기준선 공식 채택.
