# MAJN 매트리스 상부 진동 계측 프로토콜 (VIBRATION TEST PROTOCOL)

> **과제 ID**: D-01 (매트리스 상부 진동 측정), D-02 (진동 전달 특성 시험)  
> **시험 목적**: 진동판 코일이 아닌, 아기가 실제 눕는 매트리스 표면의 전달 진동을 객관적으로 계측하여 진동 강도, 주파수 스펙트럼, 전달률 및 공간 균일성 평가  
> **기준 커밋**: `c63e60a`  

---

## 1. 계측 철학 및 핵심 원칙

1. **[직접 전달 진동 평가]**: 진동자 자체의 진동 변위보다 매트리스 및 하우징을 통과하여 아기 인체 접촉면에 전달되는 실제 가속도($m/s^2$)를 기준으로 평가합니다.
2. **[계측 센서 외란 최소화]**: 가속도 센서 자체의 질량이 매트리스 표면의 진동 모드를 왜곡하지 않도록 초경량 센서(< 5g) 또는 기성 교정 계측기를 사용합니다.
3. **[하중 조건 표준화]**: 신생아의 체중이 실렸을 때의 댐핑(Damping) 효과를 고려하여, 무부하(0kg), 표준 신생아 하중(3.5kg), 100일 영아 하중(5.0kg) 조건에서 각각 측정합니다.

---

## 2. 계측 위치 5개소 정의

배시넷 상부 매트리스(외경 450×250mm)를 기준으로 다음 5개 위치에 센서를 견고히 밀착 고정합니다:

```
        +----------------------------------------+
        |                 [머리]                 |
        |                  (P2)                  |
        |                                        |
        |   (P4)           (P1)           (P5)   |
        |  [좌측]         [중앙]         [우측]  |
        |                                        |
        |                  (P3)                  |
        |                  [발]                  |
        +----------------------------------------+
```

| 측정 지점 | 좌표 (상판 기준 원점 0,0) | 계측 목적 | 안전 및 성능 판정 기준 |
|:---:|:---:|---|---|
| **P1 (중앙)** | (225mm, 125mm) | 배시넷 중앙 기준 진동 강도 및 기준 스펙트럼 취득 | 40Hz 정현파 진폭 0.3 기준 RMS $0.05 \sim 0.25 m/s^2$ |
| **P2 (머리)** | (225mm, 205mm) | 신생아 두부(뇌실막하 출혈 및 전정기관 자극) 전달량 | P1 대비 감쇄율 $\ge 20\%$ (두부 충격 최소화) |
| **P3 (발)** | (225mm, 45mm) | 하지 방향 진동 전달 특성 | P1 대비 대칭성 및 과도 공진 여부 |
| **P4 (좌측)** | (75mm, 125mm) | 횡방향 좌측 진동 전달성 및 좌우 편차 평가 | \|P4 - P5\| 편차 < 15% (대칭 유지) |
| **P5 (우측)** | (375mm, 125mm) | 횡방향 우측 진동 전달성 및 좌우 편차 평가 | \|P4 - P5\| 편차 < 15% (대칭 유지) |

## 3. 계측 물리량 및 수식

1. **3축 가속도 합성치 (Vector Magnitude)**:
   $$a_{mag}(t) = \sqrt{a_x(t)^2 + a_y(t)^2 + a_z(t)^2}$$
2. **실효 가속도 (RMS Acceleration)**:
   $$a_{rms} = \sqrt{\frac{1}{T} \int_0^T a_{mag}(t)^2 dt}$$
3. **피크 가속도 (Peak Acceleration)**:
   $$a_{peak} = \max |a_{mag}(t)|$$
4. **파고율 (Crest Factor)**:
   $$CF = \frac{a_{peak}}{a_{rms}} \quad (\text{순수 정현파 이상값: } \sqrt{2} \approx 1.414)$$
5. **진동 전달률 (Transmissibility, $T$)**:
   $$T(f) = \frac{a_{mattress}(f)}{a_{housing}(f)}$$
6. **주파수 스펙트럼 (FFT)**: 30Hz ~ 65Hz 기본 주파수 외에 100Hz 이상 고조파 왜곡(Harmonics) 비율.

---

## 4. 파라미터 스위프 시험 절차 (D-02)

### Test Step 1. 주파수 스위프 (Frequency Sweep)
- **주파수 대역**: 25Hz ~ 70Hz (5Hz 간격 10단계)
- **진폭 고정**: Amplitude = 0.30
- **목적**: 기구 하우징(4.5T 자작합판) 및 매트리스 고유 공진 주파수(FRF 피크) 탐색.

### Test Step 2. 진폭 선형성 시험 (Amplitude Linearity)
- **주파수 고정**: 40Hz (수면 유도 최적 주파수)
- **진폭 단계**: $0.05 \rightarrow 0.10 \rightarrow 0.20 \rightarrow 0.30 \rightarrow 0.40 \rightarrow 0.50$
- **목적**: 펌웨어 명령 진폭과 실제 매트리스 표면 RMS 가속도 간의 선형 비례 관계 검증.

### Test Step 3. 하중 조건별 감쇄 시험 (Weight Loading)
1. **무부하 조건 (0kg)**: 매트리스 자체 진동 특성 계측.
2. **신생아 표준 하중 (3.5kg)**: 실리콘/워터백 하중(단면적 300×150mm) 적재 후 5개 지점 측정.
3. **영아 하중 (5.0kg)**: 5.0kg 하중 적재 후 전달 감쇄 및 진동 모드 변화 계측.

### Test Step 4. 진동자 조합 시험 (2-Exciter vs 4-Exciter)
- 좌/우 2개 진동자만 가동했을 때 vs 4개 진동자 전면 가동 시의 매트리스 표면 균일도 비교.

---

## 5. 계측 환경 및 장비 셋업

- **가속도 센서**: 3축 계측용 가속도 센서 (샘플링 주파수 $\ge 1,000\text{ Hz}$, 노이즈 밀도 $< 100\mu g/\sqrt{Hz}$)
- **데이터 로거**: 16-bit 이상 ADC 데이터 수집 장비 (NI DAQ 또는 ESP32 고속 DMA 로거)
- **신호 처리**: 100Hz Low-pass Butterworth 필터 적용 및 4096-point FFT.
- **기구 조립**: 4.5T 자작합판 하우징 체결 나사 M3 10개소 0.4 N·m 토크 균일 조임 상태 유지.
