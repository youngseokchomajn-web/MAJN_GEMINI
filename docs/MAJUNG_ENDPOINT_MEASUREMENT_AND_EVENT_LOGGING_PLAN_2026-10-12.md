# MAJUNG Endpoint·측정법·이벤트 기록 설계 — 2026-10-12

**상태:** 연구 설계 준비 문서. 사람 대상 시험 프로토콜이나 IRB 승인 문서가 아니다. 아래 endpoint 정의와 기록 항목은 임상·측정 전문가 검토용 후보이며 최종 임계값이 아니다.

## 1. 목적

문헌 검토에서 반복적으로 드러난 문제는 서로 다른 결과를 한데 묶거나, 보호자 보고만으로 효과를 판단하거나, 실제 전달된 자극 대신 장치 명령값만 기록하거나, 진동에 의해 움직인 센서 값을 수면으로 해석할 위험이다.

MAJUNG 연구에서는 다음을 분리해서 기록한다.
1. 장치 명령/상태
2. 접촉면의 실제 물리 출력
3. 관찰된 행동 상태
4. 보호자 개입 및 통상 돌봄
5. 임상적 안전성 이벤트
6. 분석된 endpoint와 불확실성

## 2. 결과를 섞지 않는 원칙

| Outcome family | 질문 | 측정의 핵심 | 잘못된 해석 |
|---|---|---|---|
| Settling | 사전에 정의한 안정 행동 상태로 전환되는가? | 초기 상태, 전환 시점, 상태 지속 기준 | 울음이 멈췄으니 잠들었다고 간주 |
| Crying/fussing | 울음/보챔의 시간·빈도가 달라지는가? | 행동 코드, 에피소드 시작/종료, 관찰 가능 시간 | 보호자 인상만으로 지속시간을 추정 |
| Sleep state | 수면 상태 분포가 달라지는가? | 임상팀이 검토한 상태 코딩, 필요 시 검증된 생리 측정 | 진동으로 흔들린 액티그래피를 실제 수면으로 간주 |
| Total sleep | 실제 잠든 시간의 총량이 달라지는가? | 수면 상태 판정의 타당성, 관찰 구간 | quiet sleep 비율이 늘면 총 수면시간도 늘었다고 간주 |
| Physiological response | 생리 지표가 변하는가? | 검증된 센서, 동기화, 임상적 해석 | 생리 변화가 곧 진정 효능 또는 안전성을 뜻한다고 간주 |
| Safety | 위해 신호나 중단 사유가 발생하는가? | 사전 정의한 이벤트, 노출 시간, 대응 기록 | 단기 이상사건 미보고를 안전성 입증으로 간주 |

## 3. 후보 1차 endpoint: time-to-settling

### 3.1 후보 정의

Time-to-settling은 사전 정의된 초기 행동 상태에서 시작해, 연구팀이 사전에 정의한 settling 상태에 처음 도달할 때까지의 시간으로 후보 설정한다.

최종 조작적 정의는 임상 연구자와 행동 측정 전문가가 결정해야 한다. 연구 시작 전 아래를 정한다.
- 초기 상태의 포함 기준(예: crying/fussing 상태인지, 여러 상태를 포함할지)
- settling 상태의 관찰 가능한 행동 기준
- 상태가 유지돼야 하는 최소 지속시간
- 울음은 멈췄지만 각성 상태인 경우를 settling으로 볼지 여부
- 보호자 개입, 수유, 기저귀 교체, 통증/질병 확인, 외부 방해가 발생한 경우의 처리
- 관찰 종료까지 기준에 도달하지 않은 사례의 분석 방법
- 영상 평가자 간 일치도 기준

이 문서에서는 임의의 초 단위 임계값을 확정하지 않는다.

### 3.2 권장 분석 필드

- initial_state
- observation_start_time
- settling_candidate_time
- settling_criterion_met
- settling_confirmation_duration
- caregiver_intervention_before_settling
- intervention_type
- observation_end_reason
- censoring_reason
- coder_id
- coder_blinded_to_condition

결과는 시간 차이 하나만 보고하지 않고, 도달하지 않은 사례·중단·필요 돌봄 개입을 별도로 보고해야 한다.

## 4. Crying/fussing 행동 코딩

행동 코딩 범주는 연구팀이 검증된 기준에 따라 최종 결정한다. 시작 후보는 다음과 같다.
- CRY: 뚜렷한 울음 행동
- FUSS: 울음은 아니지만 보챔/불편 행동
- AWAKE_CALM: 깨어 있으나 관찰 가능한 울음/보챔이 없는 상태
- DROWSY: 졸림으로 판단되는 상태
- SLEEP_QUIET: 조용한 수면으로 판단되는 상태
- SLEEP_ACTIVE: 활동 수면으로 판단되는 상태
- UNCERTAIN: 영상 또는 관찰로 판정 불가

이 범주는 초안이다. 연령과 임상 맥락에 맞는지 검토하고, 관찰자 교육과 평가자 간 일치도 평가를 거쳐야 한다.

### 에피소드 정의 후보
- 시작: 사전 정의한 행동 코드가 기준 지속시간 이상 나타난 최초 시점
- 종료: 행동 코드가 종료 기준을 만족한 시점
- 재발: 짧은 간격 내 다시 시작된 행동을 같은 에피소드로 볼지 별도 에피소드로 볼지 사전 정의

울음·보챔은 가능하면 별도 분석하고, 결합 지표를 사용한다면 이유를 근거와 함께 남긴다.

## 5. Sleep endpoint 설계

수면은 settling과 별개로 분석한다.

후보:
- 관찰 구간 중 총 수면시간 비율
- quiet sleep / active sleep / indeterminate sleep 비율
- 수면 시작 잠복기
- 각성 또는 상태 전환 빈도

주의:
1. SNOO 연구는 quiet sleep 비율 변화가 관찰돼도 총 수면시간과 awake/crying은 유의하게 달라지지 않을 수 있음을 보여준다.
2. 진동 중 액티그래피·가속도계 값은 장치 자극에 직접 오염될 수 있다.
3. 수면 단계가 중요한 질문이면 연구팀이 적절한 행동 코딩, EEG 등 검증된 측정 수단의 필요성을 판단한다.
4. 수면 측정 도구는 해당 연령, 환경, 자극 조건에서 타당성이 있는지 검토한다.

## 6. 실제 물리 출력과 행동 이벤트 동기화

장치의 RUNNING 또는 명령 ON 상태는 실제 접촉면 진동을 입증하지 않는다. 연구 노출 변수는 가능한 한 실측된 출력과 연결한다.

### 기록해야 할 스트림

**장치 스트림**
- 장치/펌웨어/기구 구성 버전
- 명령 ON/OFF 및 명령 시각
- 오류·재시작·통신 끊김·보호기능 작동

**물리 출력 스트림**
- 센서 모델, 식별자, 교정/검증 상태
- 측정 위치·방향·장착 방식
- 샘플링률, 단위, 범위, 필터/분석 설정
- 원시 신호, 주파수 분석 결과, 가속도/변위 계산 방법
- 하중·침구·접촉면 조건
- 데이터 품질 플래그와 누락 구간

**행동 스트림**
- 행동 코드 전환 시각
- 평가자와 판정 신뢰도
- 영상 구간 ID 및 시간 오프셋
- 관찰 불가/가림 구간

**돌봄·환경 스트림**
- 보호자 개입 시각, 종류, 이유
- 수유, 기저귀, 안기, 달래기, 통증/질병 확인 등 필요한 돌봄
- 관찰 중 외부 소음, 조명, 사람 출입 등 주요 환경 변화

**안전성 스트림**
- 이상 징후와 최초 시각
- 관찰자/보호자 우려
- 장치 중단 시각 및 이유
- 필요한 임상 평가와 후속 조치

### 시간 동기화

- 공통 시간 기준 또는 검증된 동기화 절차를 쓴다.
- 장치 로그와 측정 장치의 시간 오차를 시험 전에 측정한다.
- 영상 타임코드와 이벤트 로그의 오프셋을 기록한다.
- 장치 재부팅·시간 보정·센서 교체가 있으면 로그에 남긴다.

## 7. 측정법 feasibility 단계

임상 연구 전에 연구팀이 적절하다고 판단하면, 영아를 대상으로 하지 않는 영상 코딩 예제 또는 합성/모의 이벤트 로그로 다음을 확인할 수 있다.
- 두 평가자가 같은 구간을 일관되게 코딩하는가?
- settling과 sleep이 혼동되지 않는가?
- 행동 코드가 겹치거나 정의되지 않은 구간은 어떻게 처리하는가?
- 장치 명령 시각과 실제 출력 시각의 차이를 기록할 수 있는가?
- 중단·돌봄 개입·관찰 종료를 분석에서 추적할 수 있는가?

이는 실제 영아의 반응을 예측하거나 임상적 효능을 입증하는 시험이 아니다.

## 8. 데이터 구조 초안

한 행에 하나의 이벤트를 기록하는 long-form 구조를 권장한다.

| Field | 의미 | 예시 형식 |
|---|---|---|
| study_id | 연구 식별자 | 문자열 |
| participant_code | 비식별 참가자 코드 | 문자열 |
| session_id | 관찰 세션 | 문자열 |
| device_config_id | 장치/펌웨어/기구 버전 묶음 | 문자열 |
| event_id | 이벤트 고유 ID | 문자열 |
| event_type | 장치/출력/행동/돌봄/안전 | 범주 |
| event_start_time | 시작 시각 | ISO 8601 또는 공통 초 |
| event_end_time | 종료 시각 | ISO 8601 또는 공통 초 |
| value | 이벤트 값/코드 | 문자열·숫자 |
| unit | 단위 | 명시 |
| source_stream | 영상/장치/센서/관찰자 | 범주 |
| quality_flag | 데이터 품질 | 범주 |
| notes | 설명·제외 사유 | 문자열 |

이벤트 테이블 외에 원시 센서 신호는 별도 파일로 보존하고, 이벤트 테이블에서 원시 데이터 파일과 시간 구간을 참조한다. 직접 식별정보는 연구팀의 개인정보·접근통제 정책에 따라 분리한다.

## 9. 사전 분석계획에 포함할 사항

- primary endpoint와 estimand
- 초기 상태의 포함·제외 기준
- settling 미도달 및 관찰 중단의 처리
- 보호자 개입/필요 돌봄의 처리
- 결측·관찰 불가 구간의 처리
- 평가자 간 일치도
- 조건·순서·시간 경과 효과
- 표본 수와 최소 임상적으로 의미 있는 차이의 근거
- 안전성 이벤트의 분모 및 노출 시간
- 2차/탐색 endpoint와 다중 비교 관리
- 사전 정의와 다른 분석은 탐색 분석으로 표시

## 10. 다음 검토 질문

임상 연구자·행동 측정 전문가·통계 전문가에게 확인할 질문:
1. 최초 연구에서 가장 타당한 1차 endpoint는 time-to-settling인가, crying/fussing duration인가?
2. 대상군을 좁히는 것이 필요한가?
3. 어떤 행동 코딩 체계가 해당 연령에 타당한가?
4. 진동이 수면 측정 센서에 주는 영향을 어떻게 검증할 것인가?
5. 돌봄 개입이 발생한 세션을 어떤 분석 대상으로 처리할 것인가?
6. 독립 평가자 눈가림이 가능한가?
7. 어떤 안전성 신호가 즉시 중단과 임상 평가를 요구하는가?
8. 실제 출력의 시간·물리 특성 중 어떤 변수를 1차 노출 변수로 사용할 것인가?

## 11. 현재 결론

MAJUNG의 연구는 장치가 켜졌는지 확인하는 것에서 끝나지 않는다. 실제 접촉면의 자극, 영아의 행동 상태, 필요한 돌봄, 안전성 이벤트를 같은 시간축에서 기록하고, settling·울음·수면을 별개의 결과로 분석할 수 있어야 한다.

이 문서는 측정법 설계 초안이다. 실제 사람 대상 연구는 임상 책임자, 적절한 연구기관, 필요한 윤리·안전 검토와 승인 이후에만 진행한다.
