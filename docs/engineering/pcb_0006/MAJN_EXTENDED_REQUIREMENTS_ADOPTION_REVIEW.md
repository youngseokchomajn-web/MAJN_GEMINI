## 1. 개요 및 배경

MAJN 스마트 배시넷 차기 제어기(PCB #0006)는 선행 시제품(PCB #0005)의 12대 고장 모드(Failure Modes) 분석을 바탕으로 기존 12개 Core 요구사항(`REQ-P0-01~05`, `REQ-P1-01~07`) 외에 **3개의 신규 확장 요구사항(`REQ-P0-06`, `REQ-P1-08`, `REQ-P1-09`)**을 도출하였습니다.

Chief Authority의 통제 원칙에 따라, 본 문서에서는 각 확장 제안의 **목적, 고장 분석 근거, 적용 필요성, 검증 방법, 수용 기준, PCB #0006 설계 영향, 미채택 시 위험**을 체계적으로 기술하고, 최종 공식 요구사항 채택 여부를 Human Chief Authority의 Gate G2 의사결정 안건으로 상정합니다.

## 2. 확장 제안 요구사항별 심층 기술 검토

### 2.1 [REQ-P0-06] USB-C Dual CC 독립 5.1kΩ 풀다운 저항 분리

| 항목 | 상세 내용 |
| :--- | :--- |
| **요구사항 ID** | `REQ-P0-06` |
| **요구사항 명칭** | USB-C Dual CC Independent 5.1kΩ Pull-down Resistors |
| **안전 등급** | **P0 (Critical Safety / Power Interoperability)** |
| **요구사항 목적** | USB Type-C 표준 규격(Section 4.5.1)에 의거, CC1과 CC2 라인에 각각 독립된 $5.1\text{k}\Omega \pm 1\%$ 풀다운 저항을 배치하여 표준 C-to-C 케이블 및 USB-PD 충전기와의 100% 전원 협상 호환성을 확보함. |
| **고장 분석 근거** | **고장 모드 FM-08 (DISC-08)**: Prototype #0005 초기 설계에서 CC1과 CC2가 단일 저항으로 묶여 공유되거나 부유된 결함이 발견됨. 이로 인해 E-marked 스마트 C-to-C 케이블 연결 시 PD 충전기가 비정상 오디오/디버그 액세서리로 오인하여 VBUS(5V) 출력을 원천 차단함. |
| **적용 필요성** | 최신 부모 세대는 USB-A 레거시 충전기보다 고속 C-to-C 충전기를 주로 사용함. 제품이 C-to-C 케이블에서 켜지지 않는 문제는 치명적인 반품 및 양산 불량 사유가 됨. |
| **검증 방법** | 표준 USB-PD 65W/45W/20W C-to-C 충전기 3종 및 E-marked 케이블을 양방향(정방향/역방향)으로 체결하고, 오실로스코프로 VBUS 기동 전압을 측정함. |
| **수용 기준 (Pass Criteria)** | 케이블 플러그 체결 방향에 관계없이 체결 즉시 VBUS 전압이 $4.75\text{V} \sim 5.25\text{V}$ 범위로 인가되어야 함. |
| **PCB #0006 설계 영향** | • 부품 추가: 0402 5.1kΩ 1% 저항 2개 ($R_{CC1}, R_{CC2}$) 추가.<br>• 배선: USB-C 리셉터클 Pin A5(CC1), Pin B5(CC2)에서 GND로 독립 라우팅.<br>• 면적 영향: 약 $2\,\text{mm}^2$ 미만으로 극히 미미함. |
| **미채택 시 위험** | • 최신 USB-PD C-to-C 케이블 연결 시 제품 전원 불통.<br>• KC/USB 규격 적합성 시험 부적합 판정. |
| **독립 심사관 권고** | **[강력 추천 (P0 승격 권고)]**: 영아용 상용 제품의 기본 동작성을 위해 Gate G2에서 필히 정식 승인되어야 함. |

### 2.2 [REQ-P1-08] 3.3V LDO 벌크 커패시터 (22µF) 및 가속도 센서 비드 필터링

| 항목 | 상세 내용 |
| :--- | :--- |
| **요구사항 ID** | `REQ-P1-08` |
| **요구사항 명칭** | 3.3V LDO Power Stability Bulk MLCC and Bead Filter |
| **안전 등급** | **P1 (Reliability / Sensor Accuracy)** |
| **요구사항 목적** | ESP32 Wi-Fi/BLE RF 전송 버스트(순간 $250\sim 300\text{mA}$ 급증) 시 3.3V 전원 레일의 순간 전압 강하(Dip)를 방지하고, 고주파 스위칭 잡음이 LSM6DSOX 6축 가속도/자이로 센서로 유입되는 것을 차단함. |
| **고장 분석 근거** | **고장 모드 FM-09**: 선행 보드에서 AP2112K-3.3 LDO 출력 커패시터가 소용량($1\mu\text{F}\sim 4.7\mu\text{F}$)에 불과하여, Wi-Fi 비콘 송출 순간 3.3V 전압이 $3.0\text{V}$ 이하로 강하하며 ESP32 브라운아웃(Brownout) 리셋이 간헐적으로 발생함. 또한 센서 Z축 진동 데이터에 1MHz 스위칭 스파이크가 혼입됨. |
| **적용 필요성** | 아기 수면 상태 감지 및 낙상/위험 체위 감지 알고리즘의 신뢰성을 확보하고 통신 중 돌발 재부팅을 영구 근절하기 위해 필수적임. |
| **검증 방법** | ESP32 SoftAP 모드에서 100% 무선 패킷을 연속 송출하는 동안 오실로스코프(AC 커플링, 대역폭 20MHz)로 LDO 출력단 및 U5 VDD 전압의 과도 강하(Dip) 및 리플 전압을 측정함. |
| **수용 기준 (Pass Criteria)** | • 3.3V 전압 강하 $\Delta V \le 100\text{mV}$ ($< 3.0\%$, 최소 전압 $\ge 3.20\text{V}$ 유지).<br>• 센서 VDDIO/VDD 고주파 잡음 리플 $\le 15\text{mV}_{p-p}$. |
| **PCB #0006 설계 영향** | • 부품 변경/추가: LDO 출력 C3를 22µF 0805 X5R/X7R로 상향. 센서 공급단에 페라이트 비드(BLM18HE152SN1D, 0603) 및 로컬 100nF 디커플링 배치.<br>• 라우팅: 전원 트랙 폭 0.5mm 이상 유지. |
| **미채택 시 위험** | • 원격 모니터링 중 이유 없는 디바이스 리부팅.<br>• 아기 뒤집힘/울음 감지 센서 오탐지 및 노이즈 오류. |
| **독립 심사관 권고** | **[채택 권고 (P1 승격 권고)]**: 안정적인 센서 알고리즘 구동을 위해 Gate G2 승인 대상에 포함할 것을 권고함. |

### 2.3 [REQ-P1-09] 외장 2.4GHz FPC 안테나 임피던스 정합 및 15mm Keepout

| 항목 | 상세 내용 |
| :--- | :--- |
| **요구사항 ID** | `REQ-P1-09` |
| **요구사항 명칭** | External 2.4GHz FPC Antenna Matching and RF Keepout |
| **안전 등급** | **P1 (RF Performance / Regulatory EMC)** |
| **요구사항 목적** | ESP32-WROOM-32UE의 u.FL 커넥터로부터 외장 FPC 안테나로 연결되는 RF 급전선 및 안테나 방사체 주변에 15mm 구리 Keepout 영역을 확보하고, $50\Omega$ 특성 임피던스를 유지하여 무선 통신 거리 및 KC 전파 인증 마진을 극대화함. |
| **고장 분석 근거** | **고장 모드 FM-12 (DISC-12)**: Prototype #0005에서 안테나 급전 케이블 근접부에 금속 체결 볼트 및 GND 동박이 $2\text{mm}$ 이내로 배치되어 안테나 디튜닝(Detuning) 발생, BLE 수신 감도(RSSI)가 -85dBm 이하로 저하되어 통신 두절 빈발. |
| **적용 필요성** | 스마트 배시넷은 영아 침대 프레임(목재/금속 복합 구조) 내부에 장착되므로, 안테나 방사 성능이 떨어지면 옆방 부모 스마트폰과의 연결이 끊어짐. |
| **검증 방법** | 벡터 네트워크 분석기(VNA)로 $2.4\text{GHz}\sim 2.5\text{GHz}$ 대역 반사손실($S_{11}$) 측정 및 10m 실내 거리에서의 수신 감도(RSSI) 계측. |
| **수용 기준 (Pass Criteria)** | • $2.4\text{GHz}\sim 2.484\text{GHz}$ 전 대역에서 $S_{11} \le -10\text{dB}$ (VSWR $< 2.0$).<br>• 10m 장애물 환경 RSSI $\ge -75\text{dBm}$. |
| **PCB #0006 설계 영향** | • 4층 PCB에서 Top층 RF 트랙 밑의 Layer 2 GND 플레인 기준 $50\Omega$ 코플래너 도파관(CPW) 형상 계산 (폭 약 0.35mm, 간격 0.2mm).<br>• 안테나 방사 영역(보드 에지 및 FPC 안착부) 전 층 구리 제거(Keepout 15mm 지정). |
| **미채택 시 위험** | • 스마트폰 앱 제어 끊김 및 실시간 알림 지연.<br>• KC 무선기기 적합성(RF 방사 스퓨리어스) 시험 부적합. |
| **독립 심사관 권고** | **[채택 권고 (P1 승격 권고)]**: 통신 신뢰성 및 KC 무선 인증 통과를 위해 Gate G2에서 공식 승인할 것을 권고함. |
