## 1. 변경 사유 (Reason for Change)

1. **물리적 조립 결함 해결 (DISC-008 / RSK-004)**:
   - 현재 목재 하우징 Master DXF(`majung_bassinet_4.5T_rev2_master.dxf`) 하판에는 외곽 10개 프레임 볼트홀만 존재하며, PCB(83.82 × 62.23 mm)를 안착·고정할 나사홀이 0개입니다.
   - 시제품 #0005 역시 초기 거버 드릴 오류(E-16: ⌀0.25mm 비아 크기 타공)로 나사 체결이 불가능하여 양면 폼 테이프로 임시 부착 시험을 진행했습니다.
   - 진동 시험(30~65 Hz) 및 양산 내구성을 확보하기 위해 하판에 PCB 체결용 관통홀 4개소를 공식 추가해야 합니다.

2. **수직 적층(Stackup) 공칭 간극 및 동적 간섭 위험 분석**:
   - **캐비티 내부 공칭 높이**: $13.5\,\text{mm}$ (자작합판 4.5T 3단 적층)
   - **PCB 부품 공칭 적층 높이**:
     - 하판 스탠드오프 높이: $5.0\,\text{mm}$
     - PCB 기판 두께: $1.6\,\text{mm}$ (허용공차 ±10%)
     - 최고 부품 높이(인덕터 L1 / 커넥터): $5.5\,\text{mm}$ (L1 단품 4.5mm + 솔더 필렛 0.5mm 여유)
     - 공칭 총합 높이: $5.0 + 1.6 + 5.5 = \mathbf{12.1\,\text{mm}}$
   - **정적 공칭 간극**: $13.5 - 12.1 = \mathbf{+1.4\,\text{mm}}$
   - **⚠️ 필수 주의 (동적 간섭 위험)**:
     - 1.4mm는 **정적 계산치(Nominal Static Value)**에 불과하며 무간섭을 보증하지 않습니다.
     - 과거 4.5T 합판 재하시험 데이터에 따르면 15kg 영아 하중 인가 시 상판(진동판) 중앙 처짐량이 **1.1 ~ 1.8 mm**에 달합니다.
     - 또한 수직형 2P 스피커 헤더(J1, J2)에 수직으로 하네스를 꽂을 경우 하네스 몰드 높이(7~8mm)로 인해 즉각적인 상판 충돌이 발생합니다.
     - 따라서 본 간극은 우각(Right-angle) 커넥터 적용 및 동적 하중 시험 합격을 전제로만 성립합니다.

## 2. 변경 상세 명세 (Proposed Modifications)

### 2.1 체결 단면 구조 상세 (Fastener Cross-Section Definition)

기존 문서에서 인서트, 스탠드오프, 관통홀 용어가 혼용되던 것을 배제하고, 다음 4단계 체결 단면을 공식 표준으로 확정합니다:

```
[ 상판 (진동판, 4.5T) ]
  ▲ 1.4mm 공칭 간극 (동적 처짐 감시 구역)
[ M2.5 둥근머리 볼트 (L=4mm) + 나일론 절연 와셔 ]
[ PCB 기판 (두께 1.6mm, 마운팅 홀 ⌀2.7mm, 패드 ⌀5.0mm) ]
[ M2.5 황동 6각 스탠드오프 (H=5.0mm, 암-암 또는 암-수 나사산) ]
════════════════════════════════════════════════════════════════ 하판 내측면 (Z=0)
[ 하판 (자작합판 4.5T, ⌀2.8~3.0mm 관통홀) ]
════════════════════════════════════════════════════════════════ 하판 외측면 (Z=-4.5)
[ 90° 카운터싱크 가공 (깊이 1.5mm, 외경 ⌀5.5mm) ]
[ M2.5 접시머리 기계볼트 (Flat-head Screw, L=6~8mm, 바닥 플러시 안착) ]
```

- **하판 외측 가공**: 하판 외측 바닥면에 접시머리 볼트 머리가 완전히 매립되도록 90° 카운터싱크(깊이 1.5mm)를 가공하여 배시넷 바닥 거치 시 긁힘을 방지함.
- **내부 스탠드오프**: 높이 5.0mm, 대변 거리 4.5~5.0mm의 M2.5 황동 스탠드오프 사용.
- **상부 고정**: PCB 상부에서 나일론 와셔를 덧댄 M2.5 팬헤드 볼트로 체결하여 체결 압력에 의한 PCB 비아 쇼트 방지.

### 2.2 PCB 마운팅 홀 배치 좌표계 (하판 450.0 × 250.0 mm 기준)

PCB 거버 rev-B 드릴 파일(`Drill_PTH_Through.DRL` Tool T06, ⌀2.7mm)과 1:1 완벽 정합되는 좌표입니다:
- 홀 중심 피치:
  - 가로: $\Delta X = 68.580\,\text{mm}$ ($2.700''$)
  - 세로: $\Delta Y = 54.864\,\text{mm}$ ($2.160''$)
- 하판 좌하단 원점 $(0, 0)$ 기준 좌표 (하판 중심: $X_c=225.0, Y_c=125.0\,\text{mm}$):
  - $MH_1$ (좌하): $(225.0 - 34.29, 125.0 - 27.432) = \mathbf{(190.71, 97.57)\,\text{mm}}$
  - $MH_2$ (우하): $(225.0 + 34.29, 125.0 - 27.432) = \mathbf{(259.29, 97.57)\,\text{mm}}$
  - $MH_3$ (좌상): $(225.0 - 34.29, 125.0 + 27.432) = \mathbf{(190.71, 152.43)\,\text{mm}}$
  - $MH_4$ (우상): $(225.0 + 34.29, 125.0 + 27.432) = \mathbf{(259.29, 152.43)\,\text{mm}}$
- 하판 관통 직경: **⌀3.00 mm** (레이저 가공 공차 ±0.1mm 반영).

### 2.3 `build_rev2_dxf.py` 파라메트릭 코드 반영안 (Draft)
```python
# 하판(BOTTOM) 생성 루틴 내 PCB 체결홀 추가 블록
PCB_MOUNT_HOLE_DIA = 3.0  # mm (for M2.5 bolt clearance)
PCB_PITCH_X = 68.580  # mm (2.700 in)
PCB_PITCH_Y = 54.864  # mm (2.160 in)
BOTTOM_CENTER_X = 225.0  # mm
BOTTOM_CENTER_Y = 125.0  # mm

for sx in (-1, 1):
  for sy in (-1, 1):
    hx = BOTTOM_CENTER_X + sx * (PCB_PITCH_X / 2.0)
    hy = BOTTOM_CENTER_Y + sy * (PCB_PITCH_Y / 2.0)
    add_circle(msp, hx, hy, PCB_MOUNT_HOLE_DIA / 2.0, layer="HOLE")
```
