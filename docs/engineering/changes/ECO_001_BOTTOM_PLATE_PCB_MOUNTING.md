## 1. 변경 사유 (Reason for Change)

1. **물리적 조립 결함 해결 (DISC-008 / RSK-004)**:
   - 현재 목재 하우징 Master DXF(`majung_bassinet_4.5T_rev2_master.dxf`) 하판에는 외곽 10개 프레임 볼트홀만 존재하며, PCB(83.82 × 62.23 mm)를 안착·고정할 나사홀이 0개입니다.
   - PCB rev-B 기판의 마운팅 홀(MH1~MH4)은 정상 **⌀2.7mm 도금 관통홀(PTH)** 및 ⌀5.0mm GND 패드로 제조되었으나, **목재 하판에 체결홀이 전혀 가공되지 않아** 시제품 #0005 조립 시 양면 폼 테이프로 임시 고정할 수밖에 없었습니다.
   - 진동 시험(30~65 Hz) 및 양산 내구성을 확보하기 위해 하판에 PCB 체결용 관통홀 4개소를 공식 추가해야 합니다.

2. **수직 적층(Stackup) 공칭 간극 및 동적 간섭 위험 분석**:
   - **캐비티 내부 공칭 높이**: $13.5\,\text{mm}$ (자작합판 4.5T 3단 적층)
   - **PCB 부품 공칭 적층 높이**:
     - 하판 스탠드오프 높이: $5.0\,\text{mm}$
     - PCB 기판 두께: $1.6\,\text{mm}$ (허용공차 ±10%)
     - 최고 부품 높이(인덕터 L1 / 커넥터): $5.5\,\text{mm}$ (L1 단품 4.5mm + 솔더 필렛 0.5mm 여유)
     - 공칭 총합 높이: $5.0 + 1.6 + 5.5 = \mathbf{12.1\,\text{mm}}$
   - **정적 공칭 간극**: $13.5 - 12.1 = \mathbf{+1.4\,\text{mm}}$
   - **⚠️ 필수 주의 (동적 처짐 및 간섭 위험 - 미검증 상태)**:
     - 1.4mm는 **정적 계산치(Nominal Static Value)**에 불과하며 안전 간극으로 확정할 수 없습니다.
     - 단순 등방성 4차 스케일링 추정치(약 $0.35\,\text{mm}$)는 지지 경계조건, 영아 체중 분포, 자작합판의 직교 이방성(Orthotropic grain properties)을 반영하지 않은 참고 추정치(`ROUGH_SCALING_ESTIMATE`)입니다.
     - 또한 수직형 2P 스피커 헤더(J1, J2)에 수직으로 하네스를 꽂을 경우 하네스 몰드 높이(7~8mm)로 인해 즉각적인 상판 충돌이 발생합니다.
     - 따라서 본 간극은 우각(Right-angle) 커넥터(`C49423315`) 적용 및 CAE 구조해석과 동적 하중/진동 실측 합격을 전제로만 성립하며, 현재 상태는 **`VERIFICATION_PENDING`**입니다.

## 2. 변경 상세 명세 (Proposed Modifications)

### 2.1 상용 MPN 기반 체결 단면 구조 상세 (Fastener Cross-Section Definition)

기존 문서의 부품 조합 혼재를 정리하고, 실제 상용 조달 가능한 **Würth Elektronik M2.5 스탠드오프**를 기준으로 5단계 체결 단면과 나사산 결합 조건을 다음과 같이 명확히 정의합니다:

```
[ 상판 (진동판, 4.5T 자작합판) ]
  ▲ 1.4mm 정적 간극 (동적 처짐 감시 구역, 30~65Hz 간극 실측 필수)
[ M2.5 × 5mm 팬헤드 기계볼트 (ISO 7045 / DIN 7985, 스틸 니켈도금) ]
[ M2.5 나일론 절연 와셔 (외경 ⌀5.0mm, 내경 ⌀2.7mm, 두께 0.5mm, PA66) ]
[ PCB 기판 (두께 1.6mm, 마운팅 홀 ⌀2.7mm PTH, 패드 ⌀5.0mm GND) ]
[ Würth Elektronik 970050154 황동 육각 스탠드오프 (M2.5 암-암, L=5.0mm, 대변 AF=5.0mm) ]
════════════════════════════════════════════════════════════════ 하판 내측면 (Z=0)
[ 하판 (자작합판 4.5T, ⌀3.0mm 레이저 관통홀, 잔여 두께 3.0mm) ]
════════════════════════════════════════════════════════════════ 하판 외측면 (Z=-4.5)
[ 90° 카운터싱크 가공 (가공 깊이 1.5mm, 입구 외경 ⌀5.5mm) ]
[ M2.5 × 6mm 접시머리 기계볼트 (ISO 10642 / DIN 7991, 90° Flat-head, 바닥 플러시 안착) ]
```

#### 세부 부품 사양 및 체결 역학 조건:
1. **스탠드오프 상용 MPN**:
   - **제조사**: Würth Elektronik
   - **MPN**: **`970050154`** (시리즈: WA-SBRII)
   - **사양**: 황동(CuZn39Pb3) 니켈도금, 육각(Hexagonal), 암-암(Female-Female) 나사산 관통형, 전장 $L = 5.0\,\text{mm}$, 대변 거리 $AF = 5.0\,\text{mm}$, 내부 나사산 M2.5 × 0.45mm. (구버전 문서에 기재된 `971050244`는 M2 수-암 부품이므로 사용 불가 판정 및 기각).
   - **대체 가능 상용 부품**:
     - 스테인리스 스틸 대체품: Würth Elektronik **`970050151`** (시리즈: WA-SSTII, M2.5 F-F, L=5.0mm, AF=5.0mm).
     - LCSC 조달품: **`C2915832`** (M2.5×5mm F-F 황동 스탠드오프).
     - ⚠️ **주의**: 이전 문서에 인용되었던 RAF Electronic Hardware `2059-256-AL`은 #2-56 인치 나사산 부품으로 판명되어 사용 불가 판정 및 완전 배제함.
2. **하판 외측 체결 및 잔여 두께**:
   - **볼트**: M2.5 × 6mm 접시머리 볼트 (ISO 10642). 머리 높이 약 1.5mm, 머리 외경 ⌀4.7mm.
   - **가공**: 하판 외측 바닥면에 90° 카운터싱크(깊이 1.5mm, ⌀5.5mm) 가공하여 배시넷 바닥 거치면과 완전 플러시(Flush) 안착.
   - **하판 잔여 두께**: $4.5\,\text{mm} - 1.5\,\text{mm} = \mathbf{3.0\,\text{mm}}$.
   - **나사산 맞물림 깊이 (Thread Engagement)**:
     - 6.0mm 볼트 축이 3.0mm 잔여 합판을 관통한 후 스탠드오프 하부 암나사에 $\mathbf{3.0\,\text{mm}}$ 맞물림.
     - 기계적 권장 체결 깊이($\ge 1.0 \times d = 2.5\,\text{mm}$)를 충분히 만족하여 인발 강도(Pull-out strength) 확보.
3. **상부 PCB 체결 및 절연·보호 조건**:
   - **볼트**: M2.5 × 5mm 팬헤드 머신 볼트 (ISO 7045).
   - **나일론 와셔**: 두께 0.5mm, 외경 ⌀5.0mm 나일론 와셔를 볼트 머리와 PCB 상부 패드 사이에 삽입. 볼트 체결 시의 회전 마찰로 인한 솔더 레지스트 박리, 랜드 파손 및 미세 배선 단락 방지.
   - **PCB 패드 접촉 및 접지**:
     - PCB rev-B의 MH1~MH4 패드는 ⌀5.0mm 도금 패드로 내부 GND 플레인과 연결되어 있습니다.
     - 황동 스탠드오프(AF=5.0mm) 상면이 기판 하면의 ⌀5.0mm GND 패드와 직접 접촉하여 기구 섀시 접지(Chassis GND) 경로를 형성합니다.
   - **상부 나사산 맞물림 깊이**:
     - 5.0mm 볼트 축이 0.5mm 와셔 + 1.6mm PCB = 2.1mm를 통과한 후 스탠드오프 상부 암나사에 $\mathbf{2.9\,\text{mm}}$ 맞물림.
     - 체결 깊이($2.9\,\text{mm} > 2.5\,\text{mm}$) 안전 기준 만족.
4. **체결 토크 및 목재 압축 안전성**:
   - M2.5 황동 암나사 권장 체결 토크: **$0.25 \sim 0.30\,\text{N}\cdot\text{m}$**.
   - 3.0mm 목재 부위에 인가되는 볼트 머리 원뿔형 면압이 자작합판 섬유 직각 압축 항복강도($\approx 4\sim 6\,\text{MPa}$)를 초과하지 않도록 조립 작업 표준서(SOP)에 토크 드라이버 사용 의무화 명시.

### 2.2 PCB 마운팅 홀 배치 좌표계 (하판 450.0 × 250.0 mm 기준)

PCB 거버 rev-B 드릴 파일(`Drill_PTH_Through.DRL` Tool T06, ⌀2.7mm)과 1:1 완벽 정합되는 좌표입니다:
- 홀 중심 피치:
  - 가로: $\Delta X = 68.580\,\text{mm}$ ($2.700''$)
  - 세로: $\Delta Y = 54.864\,\text{mm}$ ($2.160''$)
- 하판 좌하단 원점 $(0, 0)$ 기준 좌표 (하판 중심: $X_c=225.0, Y_c=125.0\,\text{mm}$):
  - $MH_1$ (좌하): $(225.0 - 34.29, 125.0 - 27.432) = \mathbf{(190.71, 97.57)\,\text{mm}}$
  - $MH_2$ (우하): $(225.0 + 34.29, 125.0 - 27.432) = \mathbf{(259.29, 97.57)\,\text{mm}}$
  - $MH_3$ (좌상): $(225.0 - 34.29, 125.0 + 27.432) = \mathbf{(190.71, 152.43)\,\text{mm}}$
  - $MH_4$ (우상): $(225.0 + 34.29, 125.0 + 27.432) = \mathbf{(259.29, 152.43)\,\text{mm}}$
- 하판 관통 직경: **⌀3.00 mm** (레이저 가공 공차 ±0.1mm 반영).

### 2.3 PCB 외곽 중심과 체결홀 중심 간의 편심 분석 (X축 +1.27mm Offset)

거버 외곽선 파일(`Gerber_BoardOutlineLayer.GKO`)과 드릴 파일(`Drill_PTH_Through.DRL`)의 정밀 파싱 결과, 기판 외곽 중심과 4개 마운팅 홀 기하 중심 간에 편심이 존재합니다:
1. **PCB 기판 외곽 치수 및 중심**:
   - $X$ 범위: $-2.54\,\text{mm} \sim +81.28\,\text{mm}$ (총 전폭: $83.82\,\text{mm}$)
   - $Y$ 범위: $0.00\,\text{mm} \sim +62.23\,\text{mm}$ (총 전고: $62.23\,\text{mm}$)
   - 외곽 기하 중심: $(X_{\text{pcb\_center}}, Y_{\text{pcb\_center}}) = (39.37, 31.115)\,\text{mm}$
2. **마운팅 홀(MH1~MH4) 위치 및 중심**:
   - $X$ 좌표: $3.81\,\text{mm}, 72.39\,\text{mm}$ (중심: $X_{\text{hole\_center}} = 38.10\,\text{mm}$, 피치 $68.58\,\text{mm}$)
   - $Y$ 좌표: $3.556\,\text{mm}, 58.42\,\text{mm}$ (중심: $Y_{\text{hole\_center}} = 30.988\,\text{mm}$, 피치 $54.864\,\text{mm}$)
3. **편심량 (Offset)**:
   - $\Delta X = X_{\text{pcb\_center}} - X_{\text{hole\_center}} = 39.37 - 38.10 = \mathbf{+1.27\,\text{mm}}$
   - $\Delta Y = Y_{\text{pcb\_center}} - Y_{\text{hole\_center}} = 31.115 - 30.988 = +0.127\,\text{mm}$ (미소량)
4. **하판 중심 대칭 타공 시 PCB 실제 안착 위치 및 여유 공간**:
   - 하판 중심 $(225.0, 125.0)\,\text{mm}$에 홀 패턴을 정대칭으로 타공할 경우:
     - PCB 외곽 $X$ 좌표 범위: $[225.0 - 38.10 + (-2.54), 225.0 - 38.10 + 81.28] = \mathbf{[184.36, 268.18]\,\text{mm}}$
     - 하판 좌측단($X=0$)에서 PCB 좌측단까지 거리: $184.36\,\text{mm}$
     - PCB 우측단에서 하판 우측단($X=450.0$)까지 거리: $450.0 - 268.18 = 181.82\,\text{mm}$
     - 좌우 여유 공간 비대칭 편차: $184.36 - 181.82 = \mathbf{2.54\,\text{mm}}$ ($2 \times 1.27\,\text{mm}$)
   - 하우징 내부 캐비티 전폭($450\,\text{mm}$) 대비 양측 여유($>181\,\text{mm}$)가 극히 충분하므로 기구적 간섭은 발생하지 않으나, CNC/레이저 작업자 및 조립 검사자가 "기판이 중심에서 $1.27\,\text{mm}$ 우측으로 치우쳐 조립된다"는 사실을 도면 주기사항으로 인지해야 합니다.

### 2.4 `build_rev2_dxf.py` 파라메트릭 코드 반영안 (Draft)
```python
# 하판(BOTTOM) 생성 루틴 내 PCB 체결홀 추가 블록
PCB_MOUNT_HOLE_DIA = 3.0  # mm (for M2.5 bolt clearance)
PCB_PITCH_X = 68.580  # mm (2.700 in)
PCB_PITCH_Y = 54.864  # mm (2.160 in)
BOTTOM_CENTER_X = 225.0  # mm
BOTTOM_CENTER_Y = 125.0  # mm

for sx in (-1, 1):
  for sy in (-1, 1):
    hx = BOTTOM_CENTER_X + sx * (PCB_PITCH_X / 2.0)
    hy = BOTTOM_CENTER_Y + sy * (PCB_PITCH_Y / 2.0)
    add_circle(msp, hx, hy, PCB_MOUNT_HOLE_DIA / 2.0, layer="HOLE")
```

## 3. 영향 평가 및 필수 검증 게이트 (Verification Gates)

1. **상판 처짐 CAE 및 실물 계측 필수 (종료 기준)**:
   - **CAE 구조해석**: 단순 등방성 스케일링 추정치(0.35mm)를 배제하고, 실제 하우징 조립 경계조건(10볼트 체결 및 레일 지지)과 자작합판 직교 이방성($E_L \approx 9\sim 11\,\text{GPa}, E_T \approx 4\sim 5\,\text{GPa}$)을 반영한 3D 유한요소해석(FEA) 수행 필수.
   - **하중 조건 대조**: 15kg 영아 등분포 하중 vs 둔부/두부 집중 하중 조건의 처짐 형상 비교.
   - **실물 변위 계측**: 실제 시제품 상판에 15kg 정하중 인가 시 다이얼 게이지/레이저 변위 센서로 중앙부 최대 처짐량 실측.
2. **동적 처짐 및 바터밍(Bottoming) 시험 필수**:
   - 30~65Hz 최대 출력 진동 가진 시, 상판 진동판 내측면과 PCB 최고 부품(L1 인덕터, 우각 단자) 간의 최소 동적 클리어런스가 **$\ge 0.5\,\text{mm}$** 이상 유지되는지 고속 카메라 또는 간극 게이지로 실측 검증해야 함 (1.05mm 안전 판정 보류 해제 조건).
3. **커넥터 인출 각도 통제**:
   - J1/J2 스피커 헤더는 수직형이 아닌 **우각(Right-angle) 커넥터(`C49423315`)** 사용을 의무화하여 배선이 기판 표면과 평행하게 인출되도록 제한함.
4. **카운터싱크 깊이 가공성 및 목재 강도**:
   - 4.5T 자작합판 레이저/CNC 가공소와 1.5mm 카운터싱크 깊이 공차(±0.2mm) 및 잔여 3.0mm 두께 인발 강도 시험 합격 필수.
5. **CAD/DXF 반영 통제 규칙**:
   - 본 ECO는 제안 초안(`PROPOSED_DRAFT`)이며, 상기 CAE 및 동적 간극 시험 게이트를 통과하고 인간 엔지니어의 최종 서명이 완료되기 전까지 **실제 CAD 소스(`build_rev2_dxf.py`) 및 DXF 파일 수정을 엄격히 금지**함.
