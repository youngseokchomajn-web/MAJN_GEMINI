## 1. 변경 사유 (Reason for Change)

1. **물리적 결함 해결 (DISC-008 / RSK-004)**:
   - 현재 목재 하우징 Master DXF(`majung_bassinet_4.5T_rev2_master.dxf`) 하판에는 외곽 10개 볼트홀만 존재하며, PCB(83.82 × 62.23 mm)를 고정할 나사홀이 전혀 없습니다.
   - 시제품 #0005 역시 기판 마운팅 홀이 ⌀0.25mm 비아 홀로 잘못 뚫려(E-16) 양면 폼 테이프로 기판을 부착하여 시험했습니다.
   - 신뢰성 및 안전성 확보를 위해 하판에 M2.5 황동 스탠드오프(5.0mm)를 체결할 수 있는 4개소 나사홀을 공식 가공해야 합니다.

2. **수직 적층(Stackup) 간극 검증**:
   - 캐비티 내부 높이: $13.5\,\text{mm}$ ($4.5\text{T} \times 3$)
   - 스탠드오프(5.0mm) + PCB(1.6mm) + 최고 부품 인덕터/커넥터(5.5mm) = **$12.1\,\text{mm}$**
   - 상판(진동판)과의 여유 공간: **$+1.4\,\text{mm}$** 확보 (간섭 없음).

## 2. 변경 상세 명세 (Proposed Modifications)

### 2.1 PCB 마운팅 홀 좌표계 및 규격
PCB 거버 드릴 파일(`Drill_PTH_Through.DRL` Tool T06)과 1:1 매칭되는 4개 홀 좌표입니다:
- 홀 중심 피치:
  - 가로: $\Delta X = 68.580\,\text{mm}$ ($2.700''$)
  - 세로: $\Delta Y = 54.864\,\text{mm}$ ($2.160''$)
- 하판(450.0 × 250.0 mm) 중심 기준 배치 좌표 (하판 좌하단 원점 기준):
  - 중심점: $(X_c, Y_c) = (225.0, 125.0)\,\text{mm}$
  - $MH_1$: $(225.0 - 34.29, 125.0 - 27.432) = \mathbf{(190.71, 97.57)\,\text{mm}}$
  - $MH_2$: $(225.0 + 34.29, 125.0 - 27.432) = \mathbf{(259.29, 97.57)\,\text{mm}}$
  - $MH_3$: $(225.0 - 34.29, 125.0 + 27.432) = \mathbf{(190.71, 152.43)\,\text{mm}}$
  - $MH_4$: $(225.0 + 34.29, 125.0 + 27.432) = \mathbf{(259.29, 152.43)\,\text{mm}}$
- 홀 직경: **⌀3.00 mm** (M2.5 황동 인서트/스탠드오프 관통용, 하판 외측 카운터싱크 깊이 1.5mm 가공 권장).

### 2.2 `build_rev2_dxf.py` 코드 반영안 (Draft)
```python
# 하판 생성 블록 (라인 72~83 부근)
PCB_HOLE_DIA = 3.0
PCB_DX = 68.58
PCB_DY = 54.864
PCB_CX = 225.0
PCB_CY = 125.0

# 4개 마운팅 홀 추가
for sx in (-1, 1):
  for sy in (-1, 1):
    hx = PCB_CX + sx * (PCB_DX / 2.0)
    hy = PCB_CY + sy * (PCB_DY / 2.0)
    add_circle(msp, hx, hy, PCB_HOLE_DIA / 2.0, layer="HOLE")
```

## 3. 영향 평가 및 검증 계획 (Impact Analysis)
