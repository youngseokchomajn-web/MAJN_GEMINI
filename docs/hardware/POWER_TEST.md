# MAJN 전원부 검증 시험 계획 및 성적서 (POWER TEST)

> **과제 ID**: HW-02 (전원 검증)  
> **시험 대상**: PCB #0005 전원 회로망 (USB-C 5V, AP2112K/TLV75733 3.3V LDO, MP3426 12V Boost)  
> **기준 커밋**: `c63e60a`  

---

## 1. 시험 개요 및 안전 한계

스마트 배시넷의 전원부는 5V USB-C 입력을 받아 ESP32-WROOM-32UE에 안정적인 3.3V를 공급하고, MP3426 승압 컨버터를 통해 TAS5805M 오디오 앰프에 12V PVDD를 공급합니다.
본 시험은 전압 강하, 리플, 발열, 과도 응답 및 외장 보조배터리 호환성을 체계적으로 검증합니다.

### 안전 허용 기준
- **3.3V 레일 허용 전압**: 3.20V ~ 3.40V (Wi-Fi 송신 피크 350mA 발생 시에도 리셋 전압 2.7V 미만 강하 금지)
- **12V PVDD 레일 허용 전압**: 11.5V ~ 12.6V (40Hz 진폭 0.5 최대 진동 구동 시)
- **최대 소비 전류**: USB 5V 기준 < 2.0A (PPTC F1 정격 3.0A 보호 마진 확보)
- **부품 표면 온도**: 30분 연속 구동 시 < 65°C

### Test 3. MP3426 12V Boost 컨버터 부하 특성 시험
- **피드백 계산 공식**: $V_{OUT} = 1.222V \times (1 + \frac{R_1}{R_2})$
  - #0005 실물: $R_1 = 143k\Omega, R_2 = 16k\Omega \rightarrow V_{OUT} = 12.14V$
  - Rev_C 제조형: $R_1 = 150k\Omega, R_2 = 16k\Omega \rightarrow V_{OUT} = 12.45V$
- **스위칭 주파수**: $R_{FSET} = 100k\Omega \rightarrow \approx 600kHz$

### Test 4. 보조배터리 호환성 및 자동 셧다운 방지 시험
시중 시판되는 5V USB-C 보조배터리는 소모 전류가 50mA 이하로 일정 시간(약 10~30초) 지속되면 전원을 자동 차단합니다.
1. Xiaomi/Anker 5V USB-C 보조배터리에 PCB #0005 연결.
2. 기기 IDLE(대기) 상태에서 5분간 전원 유지 여부 관찰.
3. 달래기 세션 종료 후(IDLE 복귀 시) 자동 슬립으로 전원이 꺼지는지 확인.
