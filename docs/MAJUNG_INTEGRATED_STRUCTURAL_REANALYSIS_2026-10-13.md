# MAJUNG 통합 자료 구조 재분석 및 불일치 감사

작성일: 2026-10-13  
대상 저장소: https://github.com/youngseokchomajn-web/MAJN_GEMINI  
목적: 기존 문헌·공학·임상·규제·FTO·협업 산출물을 하나의 의사결정 구조로 재분류하고, 문서 간 상태 충돌과 과도하게 확정된 내용을 찾아 다음 작업 순서를 고정한다.  
상태: 내부 구조 검토. 특허 법률의견, 규제기관 분류 결정, 시험 성적서, 임상 효능·안전성 검증을 대체하지 않는다.

## 1. 경영진 요약

현재 프로젝트 자료는 여섯 영역을 다룬다.

1. 임상 효능·안전성 문헌
2. MAJUNG 자체 물리 출력·공학적 위험
3. Endpoint 및 측정 타당성
4. 제품 분류·KC/EMC·표시광고
5. FTO·특허 및 리콜 신호
6. 연구기관 협업·프로젝트 관리

문서가 많이 만들어졌다는 것과 검증이 끝났다는 것은 다르다. 현재 가장 큰 문제는 조사 범위가 부족한 것이 아니라 **문서 간 상태가 서로 맞지 않고, 일부 계획 문서의 잠정 수치가 확정 합격 기준처럼 적혀 있다는 점**이다.

### 현재 결론

- **일반 건강 만삭 영아에 대한 MAJUNG 자체의 진정·울음 감소·수면 개선 효과:** 입증되지 않음.
- **기존 연구:** 특정 집단·endpoint에 관한 결과는 있으나 건강 영아의 일반적인 진정/수면 Claim에 직접 적용하기 어렵다. 건강 영아 관련 소규모·주관적 자료도 존재하므로 “관련 연구가 전혀 없다”보다 “MAJUNG과 유사한 진동 단독중재의 고품질 직접 근거가 충분하지 않다”가 정확하다.
- **MAJUNG의 물리 출력과 공학적 안전성:** 현재 문서 세트에서 실제 접촉면 계측 결과를 확인하지 못했다. 시험계획서는 존재하지만 시험 결과가 아니다.
- **FTO:** 검토 가설만 있으며 특허 자유실시 결론은 없다.
- **규제 분류 및 적용 규격:** 제품의 intended purpose, 구조, 판매 시장을 기준으로 확인해야 하며 최종 결정이 없다.
- **임상 연구:** synopsis와 접촉 패키지가 준비됐지만 연구자 검토·IRB·규제 절차 이전의 초안이다.
- **WP-0 원문 locator 감사:** 실행 로그와 마스터 추출표는 완료로 표현하지만 기존 표준 상태 매트릭스에는 추가 검토가 남아 있다. 상태를 단일 기준으로 조정하기 전에는 “완료”로 종결하지 않는다.

## 2. 올바른 의존 구조

작업은 아래 흐름으로 관리한다. 한 단계의 문서가 작성됐다고 다음 단계가 자동 통과되는 것은 아니다.

Intended use / target population  
→ 제품 Claim과 금지 Claim  
→ 문헌 evidence map  
→ 실제 장치 출력·위험 분석  
→ 측정법 타당성  
→ 제품 분류·적용 규격 확인  
→ 연구자/기관 검토  
→ 윤리·규제 절차  
→ 사람 대상 연구  
→ 결과·불확실성·재현성  
→ Claim 및 출시 결정

FTO는 별도의 병렬 게이트다. 제품 구조·제어·파형·용도 정의가 구체화될 때마다 claim chart를 업데이트하고, 판매 국가별 전문 검토 전까지 결론을 보류한다.

## 3. 자료 상태 네 가지

### A. 현재 근거가 뒷받침하는 결론
- 미숙아의 호흡 생리, NOWS 위험 신생아의 약물치료/울음, 시술 통증 등 특정 집단·endpoint를 다룬 연구가 존재한다.
- 결과는 연구집단, 자극 방식, comparator, endpoint에 제한된다.
- Singh et al. 연구는 계획 표본에 못 미쳐 조기 종료됐고, 1차 비교 및 울음 하위집단 분석에서 유의한 차이가 확인되지 않았다. 주관적 수용도는 객관적 효능과 분리해야 한다.
- 진동, rocking, whole-body cradle motion, local procedural vibration, white noise 및 복합중재는 동일한 중재가 아니다.
- MAJUNG 자체 접촉면 출력 측정과 건강 영아 효능 입증은 별개의 검증 과제다.

### B. 유용하지만 아직 계획·가설인 내용
- 벤치 시험 장비 사양, 하중 조건, 출력 균일도 시험, 음향·온도·내구성 시험.
- 1차 endpoint로 settling latency를 검토하는 임상 synopsis.
- 국내 연구자/계측기관 shortlist와 첫 연락 초안.
- closed-loop control, 다른 파형, 기계적 decoupling 등 특허·설계 아이디어.
- DSP의 ODR·anti-aliasing·필터·적응형 제거 설계.

이 항목들은 시험/전문가 검토의 출발점이지 입증된 효과나 확정 사양이 아니다.

### C. 출처·조건 확인 후에만 채택할 내용
- 특허 패밀리, 국내 권리상태, 유효 청구항 및 design-around 결론.
- 45°C/50°C, 45 dBA, 37°C, 3°, 13 mm, 10–25 μm RMS, 온도상승 2°C, Kappa 0.85 등 수치.
- 제품의 KC 분류, 적용 표준, FDA/MFDS 경로, IRB 유형과 기간.
- 센서/알고리즘이 실제 영아 수면·각성 상태를 타당하게 분류한다는 주장.
- 후보 연구자들의 현재 소속·전문분야와 실제 협업 가능성.

각 수치에는 출처, 해당 제품/표준의 적용성, 시험조건, 판정 근거가 있어야 한다. 근거가 없으면 TBD 또는 전문가/시험기관 결정 항목으로 바꾼다.

### D. 현재 사용하면 안 되는 결론
- “특허 침해가 없다 / 회피 설계 완료.”
- “MAJUNG이 영아를 진정시키거나 수면을 개선한다.”
- “이상사건이 없었으므로 안전하다.”
- “비의료기기이므로 IRB나 다른 규제 검토가 필요 없다.”
- 실제 결과·성적서가 없는 상태에서 “벤치 테스트 완료”, “인증 기준 충족”, “출력 보증”.
- 문헌의 30–60 Hz 또는 10–20 μm를 MAJUNG의 확정 파형이나 보편적 영아 안전 한계로 사용하는 것.

## 6. 가장 먼저 할 일: 자료를 더 늘리지 말고 정본 상태를 맞춘다

### P0 — 문서 정합성 복구
1. E001-A~F에 대해 수치별 locator status를 Verified / Partial / Unresolved로 통일한다.
2. Verified는 정확한 원문 위치와 수치가 실제로 대조된 항목에만 사용한다. 문헌 전체를 한 번 읽었다는 의미로 쓰지 않는다.
3. Internal extraction checked와 Independently reviewed를 분리한다.
4. WP-0 완료 표현을 모든 문서에서 일치시킨다.
5. Source Register의 “직접 근거 전무”를 “고품질 직접 근거 부족”으로 정밀화하고 Contours Vibes 등 자료를 품질·직접성 한계와 함께 등록한다.

### P1 — 실측과 사양의 경계
1. 실제 actuator, driver, power, firmware SHA, mattress/support construction, contact surface를 기록한다.
2. 효능·안전 한계를 주장하지 않고 먼저 물리 출력 특성화와 측정 불확도를 확인한다.
3. 측정 장비·센서의 대역폭, ODR, anti-aliasing, 교정 유효성, 장착 조건을 확정한다.
4. 실제 측정 전 Gate 0는 Not run으로 유지한다. 계획서 작성이나 기기 부팅은 Gate 0 통과가 아니다.

### P2 — 법률·규제 불확실성
1. intended use, target age, installation, use scenario, marketing claim을 1-page product definition으로 통일한다.
2. 특허 패밀리/한국 등록 상태/독립항/MAJUNG 구성요소 비교표를 만든다.
3. 안전 기준 수치별 출처와 적용성을 공인 시험기관에 확인한다.
4. 제품 분류와 사람 대상 연구 윤리·규제 경로는 별개의 질문으로 처리한다.

### P3 — 연구팀 협업
1. 미검증된 벤치 성능이나 인증을 주장하지 않는 concept note로 교체한다.
2. 첫 접촉은 “효능 검증 완료”가 아니라 “직접 근거의 한계와 연구 설계 자문 요청”을 목적으로 명시한다.
3. 연구팀에 제공할 장치·원자료·동기화 기능은 실제 구현/검증 여부를 체크한 뒤 약속한다.

## 7. Claim과 게이트의 올바른 구분

### 현재 문서로 말할 수 있는 것
- MAJUNG은 영아용 배시넷에 진동 모듈을 통합하는 개발 프로젝트다. 제품 실제 구조와 현재 버전에 대한 설명으로 한정한다.
- 기존 문헌에는 특정 신생아 집단의 생리학적 또는 임상 결과를 다룬 연구가 있지만, 건강한 만삭 영아의 진정·수면 효능에 대한 직접 적용은 제한적이다.
- 프로젝트는 출력 특성화와 위험 평가, 연구자 검토를 계획하고 있다. 실제 수행 전에는 계획이라고 표시한다.

### 현재 문서로 말하면 안 되는 것
- 진정/수면 개선이 임상적으로 검증됨.
- 안전한 진동 범위가 확립됨.
- KC/ASTM/MFDS 요건을 충족함.
- FTO가 확보됨.
- 벤치 테스트 완료 또는 출력 보증.
- 무사고 소규모 파일럿만으로 안전성 입증.

### Gate 설계 원칙
- Gate 수치는 출처와 적용성, 위험기반 근거, 승인 책임자가 명확한 경우에만 pass criterion으로 사용한다.
- 통계적 유의성만으로 임상적 유용성이나 안전성을 확정하지 않는다.
- 안전성, 출력 일관성, 행동 효능, 수면 효능, 규제 적합성, FTO는 별개의 게이트다.
- 시험 실패 또는 결과 불명확 시 Hold / Redesign / Retest를 허용한다.

## 8. 2주 실행 순서

### 1–2일차: 정합성
- WP-0 상태표·마스터 테이블·run log를 claim/locator별로 대조.
- 직접/간접/약한 근거 구분 및 null 결과 보존.
- 연구자 접촉 패키지에서 실측 완료/성능 보증 문구 제거.

### 3–5일차: 제품 정의·위험
- intended purpose, target age, use environment, installation, claim 목록 고정.
- 현재 프로토타입의 하드웨어/펌웨어/기구 버전과 액추에이터 명세 기록.
- 규격 수치별 source/applicability/owner/status 표 작성.

### 6–9일차: bench 준비
- 계측기·센서·DAQ의 실제 사양 및 교정 상태 확인.
- 빈 조건/하중/침구 조건과 시험 반복 수를 정의.
- 원자료 보존·분석 스크립트·판정자·시험 ID 체계 마련.
- 실제 측정 후에만 Gate 0 판정.

### 10–14일차: 외부 검토
- 특허 전문가에게 preliminary claim chart 검토 요청.
- 시험기관에 제품 구성과 사용 시나리오를 제공해 적용 규격 질의.
- 연구자에게 정확한 현 상태와 미확정 항목이 표시된 concept note를 보내 endpoint·윤리·연구 설계 자문 요청.
- 회신·결정·근거를 decision log에 남긴다.

## 9. 문서 운영 규칙

- Evidence Extraction Master Table은 문헌별 source facts와 claim별 locator를 연결하는 정본으로 관리한다.
- Research Source Register는 출처 카탈로그와 범위/직접성 안내에 집중한다.
- Gemini Research Run Log는 작업 이력이지, 결과가 자동으로 검증됐다는 인증서가 아니다.
- Decision Gates & Claim Rules에는 출처가 검증되지 않은 수치를 고정 pass criterion으로 두지 않는다.
- Researcher Outreach Package에는 실제 확인된 데이터와 계획 중인 기능을 분리한다.
- 원문 자료 수정은 변경 이유, source locator, 날짜 및 검토 상태를 기록한다.
- 상태 용어를 통일한다: Not started / In progress / Partial / Internally checked / Independently reviewed / Passed / Hold.

## 10. 최종 구조 판정

프로젝트는 문헌 조사만 하는 단계에서 증거·시험·규제·협업을 연결하는 연구개발 시스템을 구성하는 단계로 이동했다. 다음 성과는 새 문서 개수가 아니라 아래 네 가지로 측정해야 한다.

1. 문서 간 충돌 없는 단일 상태표.
2. MAJUNG 자체 출력에 대한 추적 가능한 실제 시험 데이터.
3. FTO/규제/적용 표준에 대한 전문가 또는 공식 출처 기반 판단.
4. 효능을 미리 전제하지 않는 연구자 검토용 프로토콜과 윤리적 연구 경로.

이 네 항목이 갖춰지기 전까지 효능, 안전성, 규제 적합성, FTO는 모두 최종 미확정이다.
