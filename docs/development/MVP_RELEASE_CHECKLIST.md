## 항목별 상세 검증 프로토콜

### 1. 실물 진동 구동 검증
- **합격 기준**:
  - 4개 진동자의 코일 저항이 모두 7.2Ω ~ 8.8Ω 범위에 있을 것.
  - 채널 A/B 개별 출력 및 4개 동시 출력 시 이상 잡음(Clipping, 버징) 없이 순수 진동이 유도될 것.
- **실행 명령**:
  - `python3 /Users/youngseok/Desktop/majn/tools/test_command_parser.py`

### 2. 전원 안정성 검증
- **합격 기준**:
  - USB 5V 인가 시 TLV75733 출력 3.30V ± 0.05V 유지.
  - MP3426 12V Boost 출력 부하 시 11.8V 이상 유지 (전압 강하 < 0.65V).
  - 30분 연속 구동 시 표면 온도 55°C 미만 유지.

### 3. 스마트폰 제어 검증
- **합격 기준**:
  - 아이폰에서 Wi-Fi `MAJN-BASSINET-XXXX` 접속 시 캡티브 포털 UI 자동 호출.
  - BLE 페어링 시 MITM 본딩 키 정상 입력 및 연결 지속.
  - START 누름 즉시 진동 개시, STOP 누름 즉시 20ms당 0.005f 램프다운.

### 4. 세션 안정성 검증
- **합격 기준**:
  - 15분 세션 START 후 즉시 아이폰 전원 버튼을 눌러 화면을 잠금.
  - 15분이 경과할 때까지 배시넷 진동이 끊김 없이 유지되고, 15분 정각에 자동으로 감쇄 정지할 것.

### 5. 고장 대응 및 ESTOP 검증
- **합격 기준**:
  - 앰프 I2C 오프라인 시 START 명령 즉시 거부(`status: "fault"`).
  - 구동 중 E-STOP 누름 시 지연 없이 즉각 진폭 0V 강제 셧다운.
  - 물리적 결함 해소 전에는 `RESET_FAULT` 명령이 거부될 것.

### 6. 진동 계측 데이터 검증
- **합격 기준**:
  - 매트리스 상부 5개 지점 모두에서 유의미한 가속도 신호(Signal-to-Noise Ratio > 20dB) 취득.
  - 두부(머리) 전달 진동이 안전 한계치를 초과하지 않음을 입증.

### 7. 출력 반복성 검증
- **합격 기준**:
  - 10회 재기동 반복 시험 시 측정된 RMS 가속도의 변동 계수(CV) < 10%.

### 8. 제품 완성도 검증
- **합격 기준**:
  - 450×250×22.5mm 4.5T 자작합판 하우징 내부에 간섭 없이 안착.
  - 캐비티 13.5mm 높이 내에 TEAX14C02 및 진동 유격(+3.24mm 이상) 확보.
