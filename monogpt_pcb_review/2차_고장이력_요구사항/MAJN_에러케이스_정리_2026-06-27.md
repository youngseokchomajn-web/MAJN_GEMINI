## 🔴 진짜 결함 — 확실 (high confidence)

### E-01. IC EP 써멀비아가 GND 평면과 단절 → ✅ 해결(2026-06-27)
- **원 결함**: U4(TAS5805M, 10W Class-D) EP 밑 비아 12개 전부 net='' → GND pour(Inner1)가 void 처리 → 평면 본딩 안 됨. U3(MP3426 부스트) EP 밑 비아 0개.
- **영향**: 앰프 주 방열경로 손상 + EP 접지 고임피던스. 부스트 IC 방열 부재.
- **근본원인 규명(실증)**: 풋프린트가 EP의 net='' 비아를 **리로드마다 재생성**. → ① net 할당이나 ② 삭제 모두 영속 안 됨. 특히 "net='' 삭제 + 같은 위치에 GND비아 추가(방법 B)"는 **리로드 시 풋프린트가 net=''를 grid 원위치에 재생성 → 내 GND비아와 같은 좌표 겹침 = 이중드릴 제조결함**. (리로드 테스트로 실측 확인: net=''=12 재생성, 겹침쌍 발생 → 기각.)
- **✅ 해결책 = 중간점 독립 GND비아**:
  - **U4 EP**: 풋프린트 net='' grid(x:1504/1551/1599/1645, y:1646/1693/1740) **사이 6개 중간점**(1527·1575·1622 × 1670·1717)에 독립 GND비아(dia20) 추가. 클리어런스 12.4~13.1mil. **독립비아라 영속, 위치가 grid와 달라 무겹침** — 리로드 테스트로 6개 전부 생존·겹침0 실증. EP가 GND 평면에 본딩됨.
  - **U3 EP**: 언더-EP inner/bottom 배선이 빽빽(후보 18곳 중 17곳 -1~-10mil) → **0→2개**(기존1+신규724,1672). 더는 부스트 재라우트 필요라 보류.
  - net='' 비아 12개는 **그대로 둠**(삭제하면 재생성+겹침). 코스메틱 클리어런스 13건(E-12) 잔존하나 무해, EP→바닥층 열전달은 함.
- **잔여(발열검증)**: U3 EP는 2비아로 제한 → 시제품 발열 실측 권장(뜨거우면 부스트부 재라우트로 EP 확장 또는 7×7 인덕터화).

### E-02. 안테나가 보드 내부를 향함 → ✅ -32UE 외장안테나로 해결(2026-06-27)
- **정정된 진단(핀 매핑으로 확정)**: 안테나는 U1 **왼쪽 변(-x, 패드없는 유일변)**. 그 존(x[925,1220])에 **U2(LDO)·C4·GND평면·트레이스 35개(VBUS6/GND13/VCC12/ESP_EN4)** 가 있음. 모듈 25.5mm라 U2가 안테나 밑/근접장. (처음 "y0엣지 8트레이스"는 엉뚱한 존 오판—정정.) 원 SSOT 의도는 상단엣지 y≈47mm였으나 autoroute 재배치가 y=18mm 내부로 옮김(P-24).
- **영향**: PCB안테나가 LDO·전원부·접지 빽빽한 내부를 정면 → BLE 거리↓·KC 리스크. **구리 void만으론 해결 불가**(U2 등 실부품이 남음).
- **✅ 해결**: **U1 → ESP32-WROOM-32UE-N8(C701345, 핀투핀 호환·외장 u.FL).** PCB안테나 제거 → 키프아웃 불필요·U2간섭 해소(모듈 6.3mm 짧아짐)·외장안테나 케이스 자유공간 부착. **PCB 재라우트 불필요(패드 동일).** SSOT v1.9.1 반영.
- **발주전 잔여**: ①EasyEDA에서 U1 풋프린트를 -32UE로 교체(패드동일·바디outline/실크/**u.FL 커넥터 클리어런스** 확인) ②외장안테나+피그테일 BOM추가 ③**KC 인증서 호환 안테나(게인 한도내)** 사용 ④케이스에 안테나/케이블 배치.

### E-03. R13이 U1 22번핀 패드 침범 (배치오류) → ✅ 해결(2026-06-27, 브릿지)
- 원 결함: U1.22(=SD1/IO8 내부플래시핀, NC) ↔ R13.2(VCC_3V3) **x축 13.65mil 겹침**. VCC가 플래시핀에 솔더브릿지되면 모듈 부팅손상 위험.
- **핵심교훈**: R13은 U1 패드끝(x1970.8)과 R6.1(x2001) **사이 36mil 틈에 끼어** 단순 nudge 불가(geometric contradiction). 직선 재라우트 전부 채널 한가운데 **VCC 비아(1991,839)에 단락**. → "안 된다"가 아니라 **멀티레이어 격자 라우터**로 풀어야 함.
- **✅ 해결**: R13 (1973,859)→**(1995,770)** 이동 + **AMP_PDN을 Inner2(L16)로 비아 우회**(막힌 VCC비아 회피, 비아2개) + VCC는 Top 직결. R13.2↔U1.22 −13.65 → **+8.35mil 클리어**. 단락0·전넷연결·새비아 ≥6.4mil·패드겹침0. (88곳 스캔+경로검증+실측 후 실행.)
- **★교훈: 빽빽한 코너의 2핀 부품 재배치는 "직선/단일레이어"로 막혀도 멀티레이어(Inner2/Bottom) 비아 우회로 풀린다. 격자 라우터로 가능성을 정의적으로 판정.**

### E-04. 부스트 스위칭 노드가 대면적 구리 pour (EMI)
- 증거: U3 SW핀(689,1750) ↔ L1.2(812,1969) 6.1–6.6mm, ↔ D3.2(858,1693) 4–5mm / BOOST_SW pour rect 250×330mil(6.4×8.4mm).
- **영향**: 고 dv/dt 대면적 구리 = EMI 방사체. KC 방사 리스크 + SW 링잉.
- **수정방향**: L1·D3을 U3에 근접 재배치해 SW 노드 면적 축소.

### E-05. 디커플링 캡이 IC 전원핀에서 멈 (PI/EMI)
- 증거: C21(MP3426 VCC=BOOST_VDD 바이패스) ↔ U3.7 **6.8mm** (권장<2mm) / U4 PVDD 최근접 캡 C8 **6.7mm** / C1·C11(VCC) 4.1–4.2mm.
- **영향**: SMPS 바이어스 바이패스 부실 → 불안정·노이즈 / Class-D PVDD 디커플링 멀어 PSRR·THD 저하.
- **수정방향**: C21을 U3.7 핀에, PVDD 캡을 U4 PVDD핀에 국소 이동.

### E-06. 전원부 GND 스티칭 희박
- 증거: GND 비아 5개가 전부 (1231,411)(1321,501)(2166,624)(2292,620)(2386,560) — U3/U4(y1693)에서 **1100mil+ 이격**. 전원부 GND는 173개 top 트레이스로 연결되나 평면 본딩점이 멀다.
- **영향**: 전원부 접지귀환 경로 길어 인덕턴스↑ → EMI/PI (특히 Class-D·부스트 스위칭 귀환).
- **수정방향**: U3/U4 GND 핀·EP 근처에 GND 스티칭 비아 추가.

### E-07. 부스트 인덕터 L1 포화전류 마진 부족
- 증거: L1 = 4.7µH ±20% **Isat 5.5A** / 부스트 피크 입력전류 ~5A(풀로드 5V→12V).

## 🟡 조건부 / 시스템 (사실이나 의도·정량화 필요)

### E-08. 전원 pour 잠식 (전류용량)
- 증거: VBUS pour를 다른넷 트레이스 **143개**, PVDD pour를 **100개** 관통 → 유효 전원동박 단면 감소. (SSOT의 VBUS 1.2mm 폭이 광폭트레이스 아닌 pour로 구현 — 실 트레이스는 전부 10mil.)

### E-09. USB-C 전력 한계 (시스템)
- 증거: CC에 Rd 5.1k(R3/R4)만 있고 **PD 컨트롤러 없음** → 표준 USB-C 최대 3A@5V=15W. 20W RMS 오디오는 ~25W 필요.
- **영향**: 풀볼륨이 USB-C 공급한계 초과 → 브라운아웃 가능. 메모상 "펌웨어 SPL 하드리밋"으로 대응 계획 → **의도된 트레이드오프 추정**.
- **수정방향**: 펌웨어 SPL 제한 확정, 또는 PD 컨트롤러 추가(5A엔 e-marked 케이블 필요).

### E-10. 마운팅홀 0개

- **불확실**: 케이스가 다른 방식(스냅·접착)으로 고정하면 의도. 유아제품이라 기구강도 확인 권장.

### E-16. 마운팅홀 4개 드릴 미완성 — M2.5 삽입 불가 ⚠️기구
- **실측**: MH1~4 (3.81,58.42)·(72.39,58.42)·(3.81,3.56)·(72.39,3.56)mm, 패드 Ø3.1mm(GND, plated)인데 **홀 Ø0.25mm** (드릴파일 0.249936mm 확인). M2.5 나사(축 2.5mm)는 **2.7mm 홀** 필요 → 10배 작아 통과 불가.
- **원인**: 2026-06-30 E-10 수정 때 브릿지로 독립 패드 생성하며 hole 파라미터를 기본값(0.25mm)으로 방치. 의도는 M2.5 (C21개선 기록 §2·FW계약 §5-5 명기).
- **못 잡힌 이유**: DRC는 의도 무지·JLC DFM엔 0.25mm PTH 합법·육안은 패드링만 보임. 7-05 Gerber에도 동일(오늘 회귀 아님, 잠복).
- **영향**: 전기 기능·브링업 무영향. **외함 나사고정 불가** → §5-2 열영상 실측(외함+매트리스) 시 임시고정 필요.
- **수정안(공간 검증 완료)**: 홀 0.25→2.7mm + 패드 3.1→5.0mm(GND plated 유지). 전 모서리 나사머리 Ø5 공간 ✓(최근접 MH4↔UART_HDR 3.17mm)·엣지여유 2.21mm+ ✓. MH는 독립 pad라 modify 영속, **Gerber만 재출력**(BOM/CPL 무영향).
- **✅ 해결(2026-07-08)**: 브릿지 `pcb_PrimitivePad.modify()`로 MH1~4 pad=196.9mil(5.0mm)·hole=106.3mil(2.7mm)·net=GND 영속. **권위 UI DRC=0** 확인, Gerber 재출력(드릴 T06=2.700mm×4홀 @네 모서리 검증), 저장 완료.
- **★교훈(중대)**: MH 확대 후 GND 플레인을 **브릿지 `rebuildCopperRegion()`으로 재-pour한 게 8개 GND 패드 써멀 스포크를 떨어뜨려 "Connection Error 8건" 유발**(CLAUDE.md §5-D 경고한 함정, 내가 스스로 위반).
